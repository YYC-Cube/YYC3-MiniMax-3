## 📖 项目概述

> **YYC³ AI Family · Comic Drama** 是一套面向创作者与工作室的 **AI 驱动工业化漫剧生产平台**，
> 覆盖「小说立项 → 剧本分镜 → 图像生成 → 视频合成 → 成片交付 → 运营反哺」六阶段全链路，
> 由 **8 位 AI Family Agent** 平等协同驱动，以 ReAct-C 九步闭环引擎统一编排。

| 属性 | 值 |
| ---- | ---- |
| **产品代号** | AI Family · Comic Drama `v2.4 PRO` |
| **应用形态** | 全功能交互原型（38+ 页面视图 · 五大业务域） |
| **Agent 体系** | 8 成员时钟环协同（ReAct-C 九步闭环引擎） |
| **门禁体系** | G0-G5 六级质量门禁 |
| **驱动模式** | L0 全自动 / L1 半自动 / L2 人工主导 |
| **设计体系** | 四域色 + 认知语义色双令牌红线体系 |

### 🏛️ 五维驱动 · 五高五标五化

本项目以 YYC³ 核心行业理念为架构纲领：

- **五高架构**：高可用 · 高性能 · 高安全 · 高可扩展 · 高智能
- **五标体系**：标准化 · 规范化 · 自动化 · 可视化 · 智能化
- **五化转型**：流程化 · 数字化 · 生态化 · 工具化 · 服务化

## ✨ 核心特性

- 🎬 **全链路六阶段流水线**：小说立项 → 剧本分镜 → 图像生成 → 视频合成 → 成片交付 → 运营反哺，每阶段由专属 Agent 编排
- 🕐 **8 Agent 时钟环中枢**：1.5 小时间隔环形布局的全屏沉浸式协同大屏，真实走时 + 全息数据流 + 认知探针
- 🧠 **ReAct-C 九步闭环引擎**：安全过滤 → 意图路由 → RAG注入 → 分析预测 → 报告润色 → 全局决策 → 质量校验 → 审计脱敏 → 画像更新
- 🚦 **G0-G5 六级门禁**：版权确权 → 分镜就绪 → 资产一致 → 音画合规 → 成片质检 → 发布就绪
- 🎚️ **三档驾驶模式**：L0 全自动（5s 内可撤销）/ L1 半自动（置信度 < 0.9 自动阻塞）/ L2 人工主导
- 📊 **置信度阶梯**：高置信（≥0.9 直接采纳）/ 中置信（0.6-0.9 人工复核）/ 低置信（<0.6 触发议事厅仲裁）
- 🔐 **Auth 全域九页面**：登录 / 注册 / 找回 / 重置 / 双因子 / 邀请 / 引导 / 会话过期 / 账号锁定
- 🎛️ **五态状态机**：每个页面内置 normal / empty / loading / error / forbidden 五态模拟与 Dev Mode Inspector
- ⚡ **⌘K 全局命令面板**：资产、分镜、指令的全局搜索与导航

## 🚀 快速开始

### 环境要求

| 工具 | 版本 |
| ---- | ---- |
| Node.js | ≥ 22（见 [.mise.toml](.mise.toml)） |
| pnpm | ≥ 10 |

### 安装与启动

```bash
# 1. 安装依赖
pnpm install

# 2. 启动开发服务器（团队规范：端口 3030 起，被占用则顺延）
PORT=3030 pnpm dev
# ➜ Local: http://localhost:3030/

# 3. 生产构建
pnpm build

# 4. 预览生产构建
pnpm preview

# 5. 代码格式化
pnpm format
```

### 质量门禁（提交前必检）

```bash
npx tsc --noEmit   # 类型检查：0 errors（或 pnpm typecheck）
pnpm build         # 生产构建：成功（主 chunk < 500KB）
pnpm test          # 单元测试：全部通过（Vitest 5）
pnpm test:coverage # 覆盖率门禁：tokens/data/api ≥ 80%
pnpm audit         # 依赖安全：无高危漏洞
```

### 后端接入（API 契约层）

页面数据统一经 [src/api/](src/api/) 契约层获取（Mock 优先策略）：

```bash
# .env.local 配置真实后端后，所有服务零改动切换
VITE_API_BASE_URL=https://api.example.com
```

```ts
import { scriptService } from '@/api';
const scripts = await scriptService.list(); // 未配置后端时自动回退演示数据
```

## 🧱 技术栈

| 层级 | 技术 | 版本 | 用途 |
| ---- | ---- | ---- | ---- |
| 框架 | React | 19 | UI 渲染（StrictMode） |
| 语言 | TypeScript | 5.x strict | 全量类型安全（`noEmit` 检查） |
| 构建 | Vite | 8 | 开发服务器 + 生产构建（Rolldown） |
| 样式 | Tailwind CSS | v4 | `@tailwindcss/vite` 插件，CSS-first 配置 |
| 图标 | lucide-react | 1.x | 全站图标体系 |
| 测试 | Vitest + coverage-v8 | 5.x | 单测与覆盖率门禁（≥80%） |
| 包管理 | pnpm | 11 | 依赖管理与脚本编排 |
| 工具链 | mise / oxfmt | - | Node 版本锁定 / 代码格式化 |

> 说明：本原型运行于 Figma Make 环境（`vite.config.ts` 含 Figma Make 插件集），核心业务代码零锁定，可平滑迁移至任意 Vite + React 19 宿主。

## 🎨 设计体系

### 四大功能域色（全局一致性红线）

仅允许以「**顶边 3px 色条 / 16×16 圆角标 / 图表系列**」形式出现，禁止大面积铺色：

| 域 | 色值 |
| -- | ---- |
| 生产全链路 | `#00e0b8` 青绿 |
| 剪辑合并 | `#9d7cd8` 流程紫 |
| 平台管理 | `#00b4d8` 信息蓝 |
| 一键推送 | `#FF7A5C` 珊瑚红 |

仅允许以「**左侧 3px 认知条 / 16×16 认知圆点 / 图表辅助线**」形式出现：
思考 `#7B8CFF` · 确认 `#22C55E` · 存疑 `#FFB020` · 拒绝 `#FF4422` · 学习 `#B57BFF` · 记忆 `#00B4D8` · 降级 `#5C697A`
