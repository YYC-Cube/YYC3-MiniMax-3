# 🫧 R10 渲染域降级单点化专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md) 五高架构「高可用」条款；R9（[10 方案](10-R9类型逃逸清除专项方案.md)）实锤渲染路径可崩后，渲染域**兜底缺位**成为最后一处可用性单点。
> 解耦五部曲（R5-R9）后本专项定位：**降级路径单点化**——错误捕获、遥测上报、降级 UI、重试/返航四件事从「不存在」收敛为「一个组件」。

## 一、背景与目标

2026-10-11 实测（grep 全仓 `ErrorBoundary|componentDidCatch|getDerivedStateFromError` = **0 命中**）：

| # | 缺口 | 位置 | 影响 |
| ---- | ---- | ---- | ---- |
| 1 | 页面 chunk 懒加载失败（弱网/部署窗口旧 chunk 失效）无兜底 | [App.tsx](../../src/App.tsx) 两处 `<Suspense>` 直接包裹 `getPageEntry().render()` | Promise reject → 无错误边界 → **白屏**，且零遥测（用户卡死但本地环形缓冲无感知） |
| 2 | 页面渲染期运行时异常无兜底 | 同上 | 任何页面 bug 崩溃即整树白屏 |
| 3 | Suspense + fallback 模式在 App 重复两处（auth 分支 / 主分支） | App.tsx | `PageFallback` 定义 + 两段样板，R10 收敛后 App 再瘦身 |
| 4 | 演示数据步迹 agentId 与智能体目录无契约 | [data/tasks.ts](../../src/data/tasks.ts) 两条 MOCK_TASKS × 9 步 | 目录 codeName 变更 → 步迹头像静默消失（R8/R9 同型风险在 data 域的残余） |

**目标**：`RouteErrorBoundary`（捕获 → recordEvent error 遥测 → 降级 UI → 重试/返航）+ `PageSlot`（Boundary ⊃ Suspense ⊃ 页面）单点；App 接线两分支；data 域步迹契约测试；tests 95 → 99（+4）。

## 二、方案与不执行项

**方案**：

1. **R10-A**：新建 [components/common/RouteErrorBoundary.tsx](../../src/components/common/RouteErrorBoundary.tsx)——默认导出边界类组件（`getDerivedStateFromError` 置降级态；`componentDidCatch` 走 recordEvent('error','RouteBoundary',…) 进既有遥测链路；降级 UI 含「重试」（复位边界态）+「返回工作台」（`navigate('dashboard')`））；具名导出 `PageSlot`（Boundary ⊃ Suspense ⊃ children，`PageFallback` 自 App 迁入）；App 两分支换 `<PageSlot navigate={handleNavigate}>` 接线并删除本地 PageFallback。
2. **R10-B**：[data/index.test.ts](../../src/data/__tests__/index.test.ts) +1——MOCK_TASKS 全部 stepsTrace 的 agentId ∈ AGENTS_MAP（防数据-目录漂移）。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| 每页面独立错误边界（43 个） | 不执行 | 单点边界已满足「不白屏 + 可恢复 + 有遥测」；页面级细粒度是过度设计 |
| chunk 加载失败自动重拉（window.location.reload） | 不执行 | 降级 UI「重试」按钮等价且可控；自动 reload 丢失本地状态（违背不破坏前端状态红线） |
| 边界状态持久化/上报远端 | 不执行 | 本地优先原则；遥测已有环形缓冲出口，远端上报待后端联调阶段 |
| useApiData 网络层重试 | 不执行 | 已有快照降级链路（F3），网络层重试属服务层主题 |

## 三、分阶段执行步骤

### R10-A 渲染边界单点化

1. 新建 RouteErrorBoundary.tsx（类组件；file 标头合规；PageSlot + PageFallback 同文件）。
2. 新建 [**tests**/RouteErrorBoundary.test.tsx](../../src/components/common/__tests__/RouteErrorBoundary.test.tsx) 3 用例（零 DOM）：`getDerivedStateFromError` 纯静态返回降级态；`componentDidCatch` 记录 error 遥测（vi.mock telemetry）；`PageSlot` 无错误透传 children（元素 type === Boundary）。
3. App.tsx：两处 `<Suspense fallback={<PageFallback/>}>` → `<PageSlot navigate={handleNavigate}>`；删本地 PageFallback；清理冗余导入（Suspense 若无他处消费）。

**验收**：tsc 0 errors；3 用例绿；App 再瘦身 ≥8 行；Dev Server 断网刷新 → 页面降级 UI 出现且 DevModeDrawer 遥测面板出现 error 事件（链路实证）。
**回滚**：revert 三文件（边界为纯新增，删除即回到无边界现状）。

### R10-B 数据-目录契约

[data/index.test.ts](../../src/data/__tests__/index.test.ts) 新增导入 `AGENTS_MAP`（'../../tokens'）+1 用例：MOCK_TASKS 步迹 agentId 全 ∈ 目录。

**验收**：tsc 0 errors；99 passed。
**回滚**：单测试文件 revert。

## 四、风险与缓解

| 风险 | 等级 | 缓解 |
| ---- | ---- | ---- |
| 类组件与 React 19 兼容 | 已排除 | 错误边界是官方在 React 19 中保留的 class-only 能力，兼容性即其存在理由 |
| componentDidCatch 开发态双调用致遥测重复 | 低 | 环形缓冲容量 100 容忍；生产构建仅一次 |
| 边界吞错掩盖开发期 bug | 低 | 降级 UI 明示错误消息；开发期控制台仍由 React 打印原始错误 |
| App 接线遗漏 auth 分支 | 低 | 两分支同 PR 处理 + grep 验证 Suspense 残留 = 0 |
