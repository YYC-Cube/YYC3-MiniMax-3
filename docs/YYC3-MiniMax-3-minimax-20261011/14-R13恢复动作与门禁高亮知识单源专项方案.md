# 🔁 R13 恢复动作与门禁高亮知识单源专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md)「领域知识单源」主线；R8（智能体字面量）/R12（快照键位单源）同型问题的**调用点形态**收口。
> 定位：解耦九部曲之九。R12 单源化了「键位知识」，本专项单源化两处散落在调用点的**行为知识**：错误恢复动作（reload）与门禁高亮判定（G3）。

## 一、背景与目标（2026-10-11 实测）

| # | 事实 | 证据 |
| ---- | ---- | ---- |
| 1 | **30 处 / 30 文件**完全相同的恢复动作知识 `onAction={() => window.location.reload()}`——「出错后如何恢复」的决策散落全部页面；恢复策略变更（如改 refetch 不丢状态）需改 30 文件 | grep `window.location.reload()` 精确计数 30；全部为 `<ErrorState title=… onAction={reload}/>` 形态（Storyboard3DPage 额外带 fallbackManualPath） |
| 2 | 无任何调用点依赖「无按钮」形态（30/30 均传 onAction）——ErrorState 默认化 onAction 后 DOM 零变化 | 同上逐行核对 |
| 3 | `'G3'` 门禁高亮魔法 ×2：DashboardPage L254 / ScriptListPage L252 `active={script.gateLevel === 'G3'}`——「当前主检门禁是哪级」的知识无 tokens 锚点（R8 同型） | grep `'G3'` 全仓：tokens 定义体 + 测试 + data 值 + 2 页面字面量 |
| 4 | W1 种子消息残留 `'gewu-zongshi'` 字面量（L78，R8 漏网）+ 同文件 2 处完全相同的时间戳表达式（L108/L123） | R8 收口时仅处理了 `AGENTS_MAP[...]` 消费形态，种子数据内嵌字面量未覆盖 |

**目标**：ErrorState `onAction` 默认 reload（恢复动作单源），30 处调用点删 prop；tokens 导出 `GATE_CURRENT_ID`（当前主检门禁唯一锚点）+ 2 页消费；W1 字面量收口 + `nowTime()` 本地单点；tokens.test +1；tests 103 → 104。

## 二、方案与不执行项

**方案**：

1. **R13-A**：[States.tsx](../../src/components/common/States.tsx) ErrorState 解构默认值 `onAction = () => window.location.reload()`（按钮渲染条件 `{onAction && …}` 结构保留，默认后语义不变）；30 页删除该 prop——**DOM 与交互零变化**（30/30 原本就传同值）。恢复策略未来变更只改组件一处。
2. **R13-B**：[tokens/index.ts](../../src/tokens/index.ts) GATE_LEVELS 后导出 `GATE_CURRENT_ID = 'G3'`（注释锚定语义「当前产线主检门禁·音画合规」）；DashboardPage（既有 tokens 行扩展）/ScriptListPage（新增 tokens 导入）消费；tokens.test +1（∈ 门禁阶梯 且为 'G3'，防高亮判定漂移）；W1 `agentId: 'gewu-zongshi'` → `COUNSEL_ROLE_AGENT_IDS.quality`（tokens 导入行扩展）+ 文件头部 `nowTime()` 本地 helper 收敛 2 处时间戳。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| GateBadge 内部派生 active（`level === GATE_CURRENT_ID`） | 不执行 | **会改变现有视觉**：ScriptListPage L292 预览与 ProjectSeriesPage L178 两处无 active 传参的调用点会被意外点亮；显式 prop 语义保持 |
| 30 处恢复动作改 refetch（替代 reload） | 不执行 | 行为变更（reload 丢组件态 vs refetch 保态），属后端联调后的 UX 决策；本专项仅单源化**现有行为**，变更时改 States.tsx 一处即可 |
| AgentAvatar fallback 对象单源化 | 不执行 | 组件内合法兜底默认（未知 agentId 的显示降级），非跨文件知识 |
| 新增门禁规则（pages 层禁 reload 字面量） | 不执行 | R13-A 后字面量已物理消失；规则无新拦截对象（R12-C 门禁均有存量拦截对象才立规则） |
| QA 页等 ConfidenceBadge 硬编码演示值（0.54/0.92） | 不执行 | 展示性演示内容（特定镜头的分数值）非架构知识；入 data 域是内容治理非解耦议题 |
