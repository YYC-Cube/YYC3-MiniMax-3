# 🔌 R12 快照降级激活与键位单源专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md)「断网可降级读快照」目标条款；F3 建成 [useApiData](../../src/api/useApiData.ts) 快照链路（SnapshotStore 端口 / degraded 位 / 写读遥测全备），本专项处理**最后一公里未通电**问题。
> 命名说明：新门禁规则编号 R9 沿用门禁内部序列（R1-R8 后继），与专项编号 R9（[10 方案](10-R9类型逃逸清除专项方案.md)）同名不同物——两命名空间正交（08/09 已有同型声明）。

## 一、背景与目标（2026-10-11 实测）

| # | 事实 | 证据 |
| ---- | ---- | ---- |
| 1 | **21 处 `useApiData` 调用 0 处传 snapshotKey**——快照降级链路生产调用点全未启用，「断网可降级」数据侧实际不生效 | grep src/pages 全量（21 行单行调用，17 文件） |
| 2 | hook 文档推荐用法 `{ snapshotKey: ENDPOINTS.tasks }` 从未被采纳；手写键位存在**跨域错配污染**风险（如 taskService.list 配 ENDPOINTS.assets 即互相覆盖快照） | [useApiData.ts L8](../../src/api/useApiData.ts) 示例 vs 现实 |
| 3 | 健康项（不动）：TopNav 仅 3 处直达（onNavigate 签名编译期校验）；services 传输已收口 apiRequest（可注入 fetch + ApiError 分类）；ViewState 为页面级渲染策略 | 本节审计记录 |

**目标**：`SNAPSHOT` 常量（12 个方法级键位条目，值全部派生自 ENDPOINTS 单源）落 services 层；21 处调用点接线；契约测试锁定「SNAPSHOT ↔ ENDPOINTS 一一对应全覆盖」；门禁新增 **R9**（pages 层 useApiData 必绑 SNAPSHOT）；tests 101 → 103（+2）；**「断网可降级读快照」数据侧全链通电**。

## 二、方案与不执行项

**方案**：

1. [services.ts](../../src/api/services.ts) 导出 `SNAPSHOT`（`satisfies Record<string, UseApiDataOptions>`，12 条目 scriptList/shotList/assetList/batchItems/taskList/timelineClips/videoTemplates/accounts/publishMatrix/learningSamples/memories/comments，值逐一引用 ENDPOINTS 成员）——键位与服务方法在同文件同源定义，页面零键位知识。
2. 21 处调用点 `useApiData(x.list)` → `useApiData(x.list, SNAPSHOT.xxx)`（纯值替换；随后统一扩展 17 文件既有 services 导入行加入 SNAPSHOT——值轮与导入轮**分两个消息**执行，规避 IDE 剥离）。
3. 契约测试 [snapshot-bindings.test.ts](../../src/api/__tests__/snapshot-bindings.test.ts)：表驱动断言 12 条目逐一等于对应 ENDPOINTS 成员 + 键集合 ≡ ENDPOINTS 值集合（无遗漏/无多余/无重复）。
4. [check-boundaries.mjs](../../scripts/check-boundaries.mjs) 新增规则 **R9-pages-snapshot-binding**：src/pages 层含 `useApiData(` 的行必须同时含 `SNAPSHOT.`（全部调用点已实证单行形态）+ 探针注入实证拦截。
5. useApiData.ts 文档示例同步 SNAPSHOT 形态（注释级）。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| 服务方法自带快照（defineService 工厂/方法挂载 options） | 不执行 | 工厂泛型与方法挂载均增抽象层；SNAPSHOT 表驱动 12 行已同源且可测，复杂度收益比为负 |
| 门禁校验「loader↔键」配对正确性 | 不执行 | 行级正则无法解析语义配对；配对正确性由契约测试表驱动锁定（12 行显式映射），且 SNAPSHOT 命名即方法语义 |
| mock 模式下的降级触发 | 不执行 | client Mock 优先使 loader 在未配置后端时永不 reject（即时兜底）——快照降级在**真后端接入后**网络失败时激活；键位现装即插即用，本地演示行为零变化 |
| TopNav 3 处直达常量化 | 不执行 | 字面量经 onNavigate: (page: PageId) 签名编译期校验，无常量化的门禁增益 |

**验收**：tsc 0 errors；契约 2 用例绿（12 映射逐一相等 + 集合恒等）。

### R12-B 21 调用点接线（两消息串行）

值轮（17 文件 21 行替换，无导入变动）→ 导入轮（17 文件既有 `from '../../api/services'` 行加入 SNAPSHOT，用法已在位不惧剥离）。

**验收**：tsc 0 errors；grep pages `useApiData\(` 行 100% 含 SNAPSHOT。

### R12-C 门禁 R9 + 探针

**验收**：探针违规点名探针文件；复位后 R1-R9 全 0。

### 收尾

`pnpm verify` 全链 + 文档回写（本节执行记录、02 执行日志 +2、03 总结 v1.9.0）。

**插曲三则**：

1. **编辑吞行事故**：SNAPSHOT 块替换时 old_str 含 `export const scriptService = {` 而 new_str 漏带——tsc 即刻抓获（TS1005/2304），单点补回。教训：**大块替换的 new_str 必须复核边界行完整性**。
2. **barrel 发现**：预设「页面直连 services」与实际「barrel 统一出口」不符——grep 实测纠正后，反而获得「导入轮 = 既有行纯扩展」的零剥离红利（R10 铁律的意外最优解：barrel 让跨文件导入扩展无需新增 import 语句）。
3. **type 导入剥离复发**：services.ts 的 `import type { UseApiDataOptions }` 在「定义未落盘」间隙被剥一次，补导一次即稳。

**快照降级链路终态**：页面 `useApiData(xService.list, SNAPSHOT.xxx)`（键位知识单源 api 层，门禁 R9 强制）→ 成功即写快照 → 网络失败降级读快照（degraded=true + warn 遥测）→ 无快照才 error。**「断网可降级读快照」目标数据侧全链通电**；mock 优先模式下 loader 即时兜底不触发降级，真后端（VITE_API_BASE_URL）接入后网络失败即激活——键位现装，即插即用。
