# 🏗️ 架构健康度诊断与迁移计划

> 审计口径：全部结论基于今日（2026-10-11）实测与代码证据，实测命令：`npx tsc --noEmit` / `pnpm test` / `pnpm test:coverage` / `pnpm build` / `pnpm audit --prod`。禁止虚构项均已标注「待确认」。

## 一、架构诊断摘要

**总体判定：有条件通过（健康度 B+，82/100）。** 契约层（api/）骨架正确、类型纪律优秀（src/ 内 0 any / 0 ts-ignore / 0 越层 fetch）、测试与构建门禁全绿。但存在 4 个 P0：① docs 模板目录真实密钥入库；② ENDPOINTS 注册表与 41 处页面 DevModeMeta 端点双源漂移（12 个已迁移页面对齐率仅 1/12）；③ 硬约束引用的《05-监控告警与Runbook》在仓库内不存在；④ 49 处 unsplash 外链违反本地优先。架构级问题集中在：App.tsx 上帝模块（677 行三重注册）、业务阈值散落 UI 层、断网快照降级缺失、无架构边界静态门禁。

## 三、目标架构（分层 + 包边界）

```mermaid
flowchart TB
    subgraph L5["app 壳层（组合/编排）"]
        NAV["src/navigation<br/>routeRegistry + NavigationContext<br/>PageId→{组件, meta} 同源注册"]
    end
    subgraph L4["UI 层 pages/* components/*（按域分包）"]
        P1["production"] ; P2["editing"] ; P3["publishing"] ; P4["management"] ; P5["auth"] ; P6["special"]
    end
    subgraph L3["契约层 src/api（端口）"]
        HOOK["useApiData<br/>三态+快照降级"] --> SVC["services 域服务×8<br/>ENDPOINTS 唯一注册表"]
        SVC --> CLIENT["client apiRequest<br/>超时/Abort/ApiError"]
        HOOK -.失败降级.-> SNAP["snapshot 适配器<br/>Port + localStorage"]
    end
    subgraph L2["领域层 src/domain"]
        RULES["rules.ts<br/>SyncNet/置信度/门禁阈值"]
        TYPES["types 按域拆分<br/>production/editing/publishing/..."]
    end
    subgraph L1["基础设施"]
        TOKENS["tokens 设计令牌<br/>GATE_LEVELS/DRIVE_MODES"]
        DATA["data 按域快照<br/>mock 兜底事实源"]
        ENV["env<br/>VITE_API_BASE_URL（唯一环境读取点=client.ts）"]
        OBS["observability<br/>本地环形缓冲（无公网 APM）"]
    end
    L4 --> NAV
    L4 -->|"只经 @/api"| L3
    L4 -->|"只读"@/domain --> L2
    L2 --> TOKENS
    L3 -->|"mock 兜底"| DATA
    CLIENT --> ENV
    L3 -.事件.-> OBS
```

**包边界规则（依赖只允许自上而下）**：

- `pages/*` 互不 import（跨页通信只经 navigation 导航或 api 数据层）；`pages/*` 禁止直接 import `data/*`（唯一合法消费者 = `api/services.ts` 与测试）。
- `api/*` 是唯一 fetch/env 读取点；`domain/*` 不依赖 React 与 DOM；`tokens` 为零依赖叶节点。
- 跨域共享仅限：`tokens`（视觉/枚举常量）、`domain/rules`（业务阈值）、`types`（模型）。
