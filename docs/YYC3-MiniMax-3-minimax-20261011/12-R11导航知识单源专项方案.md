# 🧭 R11 导航知识单源专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md)「单源注册」主线收口；R6-B 已单源化 auth 顶栏切换器（AUTH_PAGE_ITEMS 派生），本专项处理**同型问题的最大残余**——侧边栏分组导航（第二页面清单）。
> 定位：解耦七部曲之七；R9 修「类型谎言」、R11 修「清单失联」——新页面漏配导航从「静默不可达」变「门禁红」。

## 一、背景与目标（2026-10-11 实测）

| # | 事实 | 位置 |
| ---- | ---- | ---- |
| 1 | AppSidebar 内联 `groups` **5 组 39 项**（prod 12 / edit 6 / mgmt 9 / push 3 / auth 9），含 label+badge+icon | [AppSidebar.tsx L84-164](../../src/components/layout/AppSidebar.tsx) |
| 2 | GlobalCommandMenu `commands` 为**策展清单**（~20 项，title/subtitle 与侧栏刻意不同文案，如「多轨道时间线剪辑」≠ 侧栏「时间线编辑器」） | [GlobalCommandMenu.tsx L63-100](../../src/components/layout/GlobalCommandMenu.tsx) |
| 3 | 清单外页面 3 个：`family`、`figma-tokens`、`figma-components`（仅 ⌘K/直达可达）；39 侧栏 + 10 auth + 3 = **43 对账成立** | registry |
| 4 | **无覆盖完备性门禁**：新增页面注册进 REGISTRY 后漏配侧栏 = 静默不可达（无测试可拦） | — |

**目标**：`NAV_GROUPS`（5 组 39 项纯数据：id/label/badge/color）迁入 [registry.tsx](../../src/navigation/registry.tsx) 单源；AppSidebar 消费之（图标映射本地化，DOM 零变化）；registry.test +2 完备性契约（**PAGE_IDS ≡ 侧栏 39 ∪ auth 10 ∪ 清单外 3**）；tests 99 → 101（+2）。

## 二、方案与不执行项

**方案**：

1. registry：`NAV_ITEM_SPEC/NAV_GROUP_SPEC` 类型 + `NAV_GROUPS` 常量（39 项原样平移，色彩经 `DOMAIN_COLORS[domainKey].color` 在注册表层定型、auth 组固定色 `#00e0b8` 保留）；registry 新增 tokens 值导入（navigation→tokens 单向，无环——tokens 仅依赖 types+domain/rules）。
2. AppSidebar：删本地 NavGroup 接口与 39 项内联清单；`NAV_ICONS: Partial<Record<PageId, ReactNode>>` 本地图标映射（键保持 PageId 编译期校验）；`groups = NAV_GROUPS` 直用，渲染处 icon 取自映射——**DOM 结构与类名零变化**。
3. registry.test +2：导航完备性（漏配页面点名报红）+ 数据契约（5 组 39 项、label/color 合法）。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| ⌘K 清单并入 NAV_GROUPS | 不执行 | 策展清单文案刻意差异化（UX 意图）；page 字段已被 PageId 联合编译期校验，合并反而破坏文案自由度 |
| AUTH_LABELS（顶栏短标）与侧栏 A01-A09 标签合并 | 不执行 | 同页双位展示（顶栏紧凑 / 侧栏编号）是设计意图，非同源重复 |
| ⌘K 完备性测试 | 不执行 | ⌘K 本就是子集快入口，全覆盖会摧毁「快捷」语义 |
| 图标迁入 NAV_GROUPS | 不执行 | icon 是表现层 JSX；注册表保持纯数据（R6-B 同裁决） |

## 三、分阶段执行步骤

### R11-A NAV_GROUPS 迁移 + 完备性契约

1. registry：tokens 导入 + NAV_GROUPS 类型与常量（39 项 verbatim）。
2. registry.test +2（完备性漏配点名 + 数据契约）。

**验收**：tsc 0 errors；101 passed；侧栏外清单若有出入由完备性测试点差集暴露（自校验）。
**回滚**：registry 与测试两文件 revert（AppSidebar 未动前互不影响）。

### R11-B AppSidebar 消费改造

1. 删 NavGroup 接口 + 39 项内联 groups；增 registry 导入 + NAV_ICONS 映射；渲染 icon 取映射。
2. 消费后跑全量门禁。

**验收**：tsc 0 errors；grep 侧栏文件不再含 `'剧本工作台'` 等 label 字面量（仅 NAV_ICONS 键）；Dev Server 侧栏视觉与交互零变化。
**回滚**：AppSidebar 单文件 revert 即回内联形态。

### 收尾

`pnpm verify` 全链（101 tests / R1-R8 全 0 / coverage ≥80 / chunk <500KB）+ 文档回写（本节执行记录、02 执行日志 +2、03 总结 v1.8.0）。

## 四、风险与缓解

| 风险 | 等级 | 缓解 |
| ---- | ---- | ---- |
| 39 项平移抄录错漏（label/badge 漂移） | 中 | verbatim 平移 + 数据契约测试锁定组数/项数；Dev Server 视觉抽检 |
| registry→tokens 导入触发门禁误报 | 已排除 | R4 仅限 tokens 的 react 导入；无 navigation 相关禁边 |
| NAV_ICONS 漏键渲染 undefined | 低 | Partial 类型 + 39 键与清单逐一对齐（本次同一 PR 内对照迁移）；React 对 undefined 子元素安全跳过但不会发生（完备性由项数契约护航） |
| IDE 中间态剥离导入（R8-R10 三度复发） | 高 | 铁律执行：先落全部用法、验证命令与编辑分消息串行；被剥则单独补导 |
