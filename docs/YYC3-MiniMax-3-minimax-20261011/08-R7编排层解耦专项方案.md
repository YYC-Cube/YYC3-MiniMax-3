# 🎛 R7 编排层解耦专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md)「上帝模块」治理主线（App 677→331 后的第三阶段收敛）；[07 R6 专项](07-R6架构解耦专项方案.md) 完成模块依赖域解耦，本专项收口**编排层**——App.tsx 的四种混居职责。
> 命名说明：本专项编号 R7 沿用 R5/R6 专项序列，与门禁规则 `R7-file-header-required`（[check-boundaries.mjs](../../scripts/check-boundaries.mjs)）同名不同物，互不相关。
> 执行原则：App 保持本地状态机（不引入 Context/全局 store——9 个 state 规模下 Context 是过度设计）；只做「职责归位」，不改任何交互行为。

## 一、背景与目标

R6 后 App.tsx（271 行）仍混居四种职责：

| # | 职责 | 现状 | 问题 |
| ---- | ---- | ---- | ---- |
| 1 | 浮层编排 | 6 个布尔 useState + selectedAgentId，互斥规则散落在 JSX 回调（openCognition 关 W1 开 W2、onSwitchToW1 反向、仲裁回调关自己+导航） | 编排规则无法单测；规则阅读需在 270 行里跳跃拼图 |
| 2 | DevMode 元数据加载 | fallback 常量 + effect 加载 + 失败遥测（L33-44/L82-97） | `DEV_META_FALLBACK` 是 navigation 域知识却住在 App；加载逻辑不可测 |
| 3 | auth 域专属 UI | 返回按钮 + auth 切换条 + DevMode toggle 内联（L112-148，~40 行） | auth 头部不可复用不可测；App 为 auth UI 细节买单 |
| 4 | 布局组合 | 8 浮层 + TopNav/Sidebar 接线 | 唯一应留的职责 |
| 附 | DevModeDrawer 双接线 | auth 分支与主分支 8 props 完全重复（仅 pageTitle 异） | 接线重复，漏改风险 |

**目标**：App.tsx 收敛为纯布局组合（预期 271 → ≤180 行）；编排规则与元数据加载进入可单测的零 DOM Hook；auth 头部组件化；tests 80 → 91（+11）。

## 二、现状盘点（2026-10-11 实测）

- 浮层互斥规则 3 处内联：`handleOpenCognition`（L74-78）、W2 `onSwitchToW1`（L217-220）、`AgentCounselModal.onAdoptArbitration/onHumanOverride`（L229-240）——后两处含导航副作用，与浮层开关纠缠。
- `DEV_META_FALLBACK`（L33-44）唯一消费者是 App 自身；其 apiEndpoint `/api/v2/factory/telemetry` 在 [ENDPOINTS](../../src/api/services.ts#L53-L66) 无对应键（遥测面板端点未定型），**按契约不虚构原则原样迁移、不新增 ENDPOINTS 键**。
- auth 头部三元素（返回 / 切换条 / toggle）与 `AUTH_PAGE_ITEMS` 派生渲染（R6-B 成果）整体可平移。
- App 仅被 [main.tsx](../../src/main.tsx) 消费；`DEV_META_FALLBACK` 无第二引用——两项迁移均为低风险。

## 三、方案选型

| 候选 | 裁决 |
| ---- | ---- |
| 浮层状态收进 Context/全局 store | ❌ 过度设计：单消费方（App），9 state 无跨树共享需求 |
| **编排逻辑抽自定义 Hook（零 DOM 可测）** | ✅ 复用 useApiData.test 已验证的 `vi.mock('react')` 最小 Hook 模拟栈 |
| auth 头部留在 App 仅折叠注释 | ❌ 未解决可测性与职责混居 |
| DEV_META_FALLBACK 迁 types | ❌ 它是实现细节（fallback 值）非类型契约；归 registry（meta 知识单源）最贴切 |

## 四、分阶段执行步骤

### R7-A useAppOverlays 编排 Hook（浮层互斥规则单点化）

**目标**：6 浮层布尔 + selectedAgentId + 全部互斥/导航规则收进 [src/hooks/useAppOverlays.ts](../../src/hooks/useAppOverlays.ts)，规则 100% 可单测。

**操作**：

1. 新建 `src/hooks/useAppOverlays.ts`：签名 `useAppOverlays(navigate: (page: PageId) => void)`，返回 `{ overlays, actions }`；actions 承载：toggleDevMode / togglePrototype / toggleCommand / toggleFamilyWidget / openCognition(agentId)（关 W1 开 W2 + 记 agentId）/ closeCognition / switchToW1（关 W2 开 W1）/ openCounsel / closeCounsel / adoptArbitration(toInbox)（关议事厅 + navigate(toInbox ? 'admin-agents' : 'production')）/ humanOverride()（关议事厅 + navigate('storyboard')）。
2. 新建 `src/hooks/__tests__/useAppOverlays.test.ts`（零 DOM 模拟栈）：初始态、openCognition 互斥与 agentId 记录、switchToW1 反向互斥、adoptArbitration 双分支导航、humanOverride 导航——6 用例。

**验收**：tsc 0 errors；6 用例绿；互斥规则在 App JSX 中归零。

**回滚**：删除 hooks 两文件 + App revert（App 行为无变化，双向安全）。

### R7-B useDevModeMeta Hook + fallback 归位 registry（meta 知识单源）

**目标**：元数据加载生命周期 Hook 化；fallback 常量归位 navigation/registry（meta 知识与页面注册表同源）。

**操作**：

1. [registry.tsx](../../src/navigation/registry.tsx)：`DEV_META_FALLBACK` 从 App 平移至 registry 并 `export`（apiEndpoint 字符串原样保留 + 注明「ENDPOINTS 无对应键，遥测端点未定型」）。
2. 新建 `src/hooks/useDevModeMeta.ts`：签名 `useDevModeMeta(currentPage: PageId): DevModeMeta`；内部 = 原 effect 逻辑（fallback 复位 → meta() 加载 → active 守卫 → 失败 recordEvent）。
3. 新建 `src/hooks/__tests__/useDevModeMeta.test.ts`（`vi.mock('../navigation/registry')` 提供 stub getPageEntry + 真 fallback 值）：初始 fallback、加载成功落位、失败记遥测保持 fallback——3 用例。

**验收**：tsc 0 errors；3 用例绿；App 不再含 meta effect 与 fallback 常量。

**回滚**：registry 保留导出无副作用；删 hooks 两文件 + App revert。

### R7-C AuthHeader 组件抽取 + Drawer 接线收敛 + App 收敛

**目标**：auth 域 UI 组件化；App 收敛为纯布局组合。

**操作**：

1. 新建 [src/components/layout/AuthHeader.tsx](../../src/components/layout/AuthHeader.tsx)：props `{ currentPage, onNavigate, isDevModeOpen, onToggleDevMode }`；内容 = 现内联三元素（返回按钮 / AUTH_PAGE_ITEMS 切换条 / DevMode toggle）原样平移。
2. 新建 `src/components/layout/__tests__/AuthHeader.test.tsx`：render 冒烟（返回元素对象断言，含 10 切换按钮子元素计数）——2 用例。
3. App 重写：meta/浮层状态与 effect 换 Hook 调用；auth 分支换 `<AuthHeader />`；DevModeDrawer 双接线收敛为共享 props 对象（`const drawerProps = {...}` 两分支复用，pageTitle 按分支展开）；删除 ArrowLeft/Layers/recordEvent/useState 冗余导入。

**验收**：

- [ ] App.tsx ≤180 行；`grep -n "useState\|useEffect" src/App.tsx` → 0 命中（编排全出）
- [ ] tsc 0 errors；tests 91 passed（80+6+3+2）
- [ ] Dev Server 手检：auth 切换 10 项、W1⇄W2 互斥、议事厅仲裁导航、DevMode 面板行为不变

**回滚**：AuthHeader 平移是纯搬移——revert 三文件即回内联形态。
