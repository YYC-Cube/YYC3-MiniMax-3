# 🛡 R9 类型逃逸清除专项方案

> 上游依据：[05 报告](05-架构健康度诊断与迁移计划.md) 健康度门禁「禁止类型逃逸」条款的执行收口；R5-R8 四部曲（[06](06-R5白名单清理专项方案.md)/[07](07-R6架构解耦专项方案.md)/[08](08-R7编排层解耦专项方案.md)/[09](09-R8领域知识单源专项方案.md)）后全仓扫描发现的**类型断言掩盖潜伏运行时 bug**。
> 命名说明：专项编号 R9 沿用序列，与门禁规则 `R9-*`（如有）无关。

## 一、背景与目标

2026-10-11 全仓扫描实测三类残留：

| # | 问题 | 位置 | 严重度 |
| ---- | ---- | ---- | ---- |
| 1 | **潜伏 P0 运行时 bug**：`onNavigate(stg.route as PageId)`，而 `PIPELINE_STAGES.route = '/script'`（带斜杠）≠ PageId `'script'`（无斜杠）。点击 S1-S6 任一卡片 → `currentPage='/script'` → `getPageEntry()` 返回 undefined → `.render()` TypeError → Suspense 无错误边界 → **白屏**。`as PageId` 断言掩盖了编译期本可发现的不兼容 | [DashboardPage.tsx L181](../../src/pages/production/DashboardPage.tsx) + [tokens/index.ts L266](../../src/tokens/index.ts) | 🔴 P0（潜伏） |
| 2 | **R8 漏网魔法下标**：`AGENTS_MAP[selectedAgentId] \|\| AGENTS_LIST[4]`（R8 修了 L267 同型处，L92 遗漏） | [W1AIFamilyWidget.tsx L92](../../src/components/widgets/W1AIFamilyWidget.tsx) | 🟡 P2 |
| 3 | **议事厅角色字面量**：`AGENTS_MAP['gewu-zongshi']` / `AGENTS_MAP['chuangxiang-lingyun']`——目录 codeName 变更即静默 undefined（渲染崩或空卡） | [AgentCounselModal.tsx L43-44](../../src/components/counsel/AgentCounselModal.tsx) | 🟡 P2 |

**目标**：全仓 `as PageId` 谎言断言清零；`PIPELINE_STAGES.route` 编译期锁定 PageId；`AGENTS_LIST[N]` 魔法下标清零；议事角色常量化 + 目录联动断言；tests 93 → 95（+2）。

## 二、方案与不执行项

**方案**：

1. **R9-A**：`PIPELINE_STAGES` route 值去斜杠对齐 PageId 真键（`'/script'`→`'script'`…`'/analytics'`→`'analytics'`，后者已是合法 PageId）；`as const` 数组加 `satisfies ReadonlyArray<{ route: PageId; … }>` 编译期锁定；DashboardPage 删除 `as PageId` 断言直传；type-only 导入（tokens → types 无运行时环）；契约断言入 [registry.test.tsx](../../src/navigation/__tests__/registry.test.tsx)（**不放 tokens.test**——tokens 导 registry 会与 registry→tokens 形成环）。
2. **R9-B**：W1 L92 fallback 改 `AGENTS_MAP[DEFAULT_AGENT_ID]`（与 L267 同口径）；tokens 导出 `COUNSEL_ROLE_AGENT_IDS = { arbiter: DEFAULT_AGENT_ID, quality: 'gewu-zongshi', creator: 'chuangxiang-lingyun' }`（议事厅常驻三角色的唯一字面量锚点）；AgentCounselModal 消费；tokens.test +2 断言（三 id ∈ AGENTS_MAP 且 role 匹配「全局调度/质量校验/创意生成」）。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| 全仓其余 `as` 断言逐个清除 | 不执行 | 仅存合法窄化断言（如 `as const`/事件断言），无跨型谎言；已 grep 确认无第二处 `as PageId` |
| DashboardPage 加 ErrorBoundary 兜底 | 不执行 | 治标；route 类型化后失配在编译期即不可能；错误边界属独立主题另行规划 |
| AGENTS_LIST 全员角色常量化（8 个） | 不执行 | 仅议事厅三角角色有跨文件引用语义，其余 5 员仅目录自渲染；全量化是无消费的过度抽象 |
| `@/` 路径别名统一 | 不执行 | 诊断报告已明确跳过（低价值高 churn） |

## 三、分阶段执行步骤

### R9-A 流水线路由类型安全化（潜伏 P0 清除）

1. tokens：`import type { PageId } from '../types'`（type-only）；PIPELINE_STAGES 六条 route 去斜杠；数组尾部 `satisfies` 锁型。
2. DashboardPage：`onNavigate(stg.route)`（删 `as PageId`）；确认 PageId 导入仍被其他处消费（否则同步清理）。
3. registry.test +1：`PIPELINE_STAGES.map(s => s.route)` 全部 ∈ PAGE_IDS（防路由漂移回归）。

**验收**：tsc 0 errors；`grep -n "as PageId" src/` = 0；Dev Server 点击 S1-S6 卡片导航正常（原白屏路径消除）。
**回滚**：revert tokens + DashboardPage + registry.test 三文件。

### R9-B 智能体引用收口（R8 漏网 + 议事角色常量化）

1. W1 L92：fallback 改 `AGENTS_MAP[DEFAULT_AGENT_ID]`。
2. tokens：导出 `COUNSEL_ROLE_AGENT_IDS`（as const，arbiter 复用 DEFAULT_AGENT_ID 不重复字面量）。
3. AgentCounselModal：agentA/agentB 改常量消费。
4. tokens.test +2：三角色 id ∈ AGENTS_MAP；role 分别为 全局调度/质量校验/创意生成。

**验收**：tsc 0 errors；`grep -n "AGENTS_LIST\[" src/ --include='*.tsx' | grep -v __tests__` = 0；95 passed。
**回滚**：revert tokens + W1 + Modal + 测试四文件。

### 收尾

`pnpm verify` 全链（93→95 tests / R1-R8 全 0 / coverage ≥80 / chunk <500KB）+ 文档回写（本节执行记录、02 执行日志 +2、03 总结 v1.6.0）。

## 四、风险与缓解

| 风险 | 等级 | 缓解 |
| ---- | ---- | ---- |
| route 去斜杠改变现有（未暴露的）导航行为 | 低 | 原 route 带斜杠点击即崩（无「正常行为」可破坏）；契约断言 + Dev Server 手检双护航 |
| satisfies 与 as const 组合的类型推断兼容 | 低 | TS 5.7 完整支持（4.9+ 特性）；tsc 即时验证 |
| tokens → types type-only 导入触发门禁误报 | 已排除 | R4 仅禁 react 导入；R8 仅禁 observability；type-only 编译期消除无运行时边 |
| COUNSEL_ROLE_AGENT_IDS 与未来目录调整漂移 | 低 | tokens.test role 匹配断言联动（目录改名 = 测试红） |
