| pnpm ERR_SQLITE_ERROR（沙箱禁写家目录） | store-dir 项目内化 | 沙箱环境优先把可写目录限制在 cwd 内 |

| `file` 命令沙箱 I/O error | 用 xxd 校验文件头 | 校验手段需准备降级方案 |
| `pnpm add` 安装 devDeps 被沙箱拦截（store 禁写，`--store-dir` 亦拦 projects 登记） | Hook 测试改零依赖方案：vi.mock('react') 最小语义模拟 | 沙箱环境新增依赖前先评估替代测试策略 |
| Linter 自动剥离「编辑中间态」新增导入（DashboardPage 全部新导入被清） | 统一「先改用法 → 后补导入」编辑顺序 | 批量重构时让导入在被引用后再落盘，规避 auto-fix 误删 |
| 新增 useApiData.ts 拉破覆盖率门禁（Branch 71.42%/Funcs 72.22%） | 补 5 Hook 用例 + 3 barrel 用例 | coverage include 范围变更必须同步补测试再过门禁 |
| 边界脚本 R5 正则缺陷：字符类 `\\s` 被解析为「反斜杠或 s」，host 截断为 `image` 致 49 误报 | 改为 `\s` 字面量类 | 正则字符类中 `\s` 与 `\\s` 语义天差地别，写后必须实测 |
| 边界脚本 R2 漏报：barrel 根路径 `'../../data'` 解析为 `data`（无尾斜杠）不匹配 `startsWith('data/')` | `inDir()` 统一判定（`rel === dir \|\| rel.startsWith(dir + '/')`） | 目录前缀判定必须同时覆盖「根目录本身」与「子路径」；门禁上线前用探针验证 |
| registry 覆盖缺口：43 个 lazy loader 闭包从不执行（render 冒烟不挂载） | React.lazy 载荷预触发用例 + meta 契约 43 项全遍历 | 「渲染冒烟」只覆盖元素创建，code-split 加载路径需显式触发 |
| 烟囱首跑 46 失败：带空格路径 %20 未 decode（3 图标 404 假阳性）+ 42 chunk `document is not defined` | `decodeURIComponent(req.url)` + 判据收紧 >100 bytes；jsdom 垫片 + **window 成员批量挂载**（MutationObserver 等不会自动暴露到 Node 全局） | 静态服务器必须做 URL decode；jsdom 实例 ≠ Node 全局，主 chunk 顶层 createRoot 需要完整浏览器全局面 |
| 测试文件局部 SSR helper `render(): string` 遮蔽 RTL render，jsdom 用例首跑 6 失败同源（解构 undefined + effect 未执行） | 局部 helper 改名 `renderHtml` | 同名工具在升级测试环境时会静默变义；文件级 helper 命名避开测试库导出名 |
| RTL act 环境告警（jsdom 下未声明 act 支持） | 4 文件统一 `(globalThis as Record<string, unknown>).IS_REACT_ACT_ENVIRONMENT = true` | React 19 + RTL 的 act 依赖显式全局标志，宁可显式声明不留 stderr 噪音 |
