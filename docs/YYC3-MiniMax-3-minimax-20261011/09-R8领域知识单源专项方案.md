> 命名说明：专项编号 R8 沿用 R5-R7 序列，与门禁规则 `R8-logic-no-observability`（[check-boundaries.mjs](../../scripts/check-boundaries.mjs)）同名不同物（同 [08 第一节声明](08-R7编排层解耦专项方案.md)）。

## 三、方案与不执行项

**方案**：

1. tokens 导出 `DEFAULT_AGENT_ID`（置于 AGENTS_LIST 之前，注释语义「全局调度默认智能体·仲裁主持」）；13 处消费点替换为常量引用（对象键用计算属性 `[DEFAULT_AGENT_ID]`）；W1 魔法下标 `AGENTS_LIST[4]` 改 `AGENTS_MAP[DEFAULT_AGENT_ID]`（语义等价——下标 4 即天枢）。
2. tokens 顶部 `import { REF_CONSISTENCY_PASS, SYNCNET_PASS } from '../domain/rules'`，G2/G3 threshold 改模板串派生；rules.test 既有粘合断言保留（派生后语义恒真，作回归护航）；3 处页面文案改 JSX 表达式引用常量。

**明确不执行项**（防过度工程）：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| AGENTS_LIST / REACT_C_STEPS 数据本体字面量 | 不改 | 定义处即单源本体；二次常量化是循环引用抽象 |
| `getConfidenceMeta` 0.6/0.9 分档 | 不改 | 置信度阶梯与 SyncNet 泳道**数值巧合、语义不同源**，合并制造假单源 |
| G4 `'≥ 85 分'` | 不改 | 与 `QUALITY_CHECK_PASS = 80` 语义不同（宗师综合质检 ≠ 页面质检），当前无 rules 常量对应，不虚构 |
| [types/production.ts](../../src/types/production.ts) L74 注释 `≥0.75` | 不改 | 注释级；类型文件引用运行时常量改注释无门禁价值 |
| REACT_C_STEPS agentName 中文名 | 不改 | 与 AGENTS_LIST.name 展示重复属数据快照，提取收益低于 churn |
