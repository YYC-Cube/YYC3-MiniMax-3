# 🧪 R15 交互级组件测试专项方案

> 承接 03 总结 TOP 2「交互级组件测试」。目标：在零新依赖约束下，把测试层级从 R14 的「渲染正确」推进到「交互行为正确」——事件回调真实调用、参数断言、条件分支覆盖。

## 一、盘点事实（全部经代码实证）

1. **依赖安装第三次实证被沙箱拦截**（2026-10-12 实测）：`pnpm add -D jsdom @testing-library/react @testing-library/dom @testing-library/user-event` → `EACCES permission denied, symlink → /Users/yanyu/.pnpm-store/v11/projects/...` + `TRAE Sandbox Error: hit restricted`。与 R14 前会话双重实证一致，**零依赖路线确认为唯一路线，不再重试**。
2. **纯无状态交互组件（无 hooks，可安全直调拿元素树）**：`ConfirmSheet`（3 按钮：X/取消/确认 + isDestructive 分支 + children 槽）、`BatchActionBar`（N 动作 + onClear + 三变体样式）、`DriveModeSwitch`（L0/L1/L2 三键 → onChange）、`AgentAvatar`（可选 onClick + AGENTS_MAP 联动 + 6 状态色）。`ConfidenceBadge` 无任何事件（纯展示，非交互组件）。
3. **含状态 overlay（useState 禁直调）但 SSR 渲染安全**：`DevModeDrawer`（useState(copied) 仅影响复制图标）、`GlobalCommandMenu`（useState(query) + useEffect 挂 window keydown——**renderToStaticMarkup 不执行 effect，window 安全**；且二者均为 App 级 overlay，未被 R14 的 43 页冒烟覆盖，属渲染冒烟盲区）。
4. **键盘事件面全仓仅 2 处**（grep onKeyDown）：W1/W2 widgets 的 Enter 派发，二者均含多个 useState，零依赖无法驱动。GlobalCommandMenu 的 Esc 关闭走 window 监听（effect 期），同样不可驱动。
5. **telemetry 模块级单例**导出 `recordEvent / getRecentEvents / clearTelemetry / TELEMETRY_CAPACITY(100)` → DevModeDrawer 遥测区可测「空缓冲」与「有事件」两态，但需 beforeEach 清理防用例间污染。
6. **React 19 类型约束沿用 R14 结论**：`ReactElement.props` 为 unknown，元素树断言前须窄化；含 useState 组件禁渲染器外直调（invalid-hook-call）。

## 二、零依赖「交互级」的能力边界（本专项的认知基准）

| 能力 | 路线 | 本专项 |
| --- | --- | --- |
| 事件回调真实调用 + 参数断言 | 元素树派发：`el.props.onClick(...)` | ✅ A 层核心（较 R14「断言 onClick 存在」升级为「调用并断言行为结果」） |
| 条件交互分支（如 Enter 才触发、isOpen 门卫） | 同上 + props 组合 | ✅ A/B 层 |
| 联动单源（tokens/AGENTS_MAP/文案矩阵） | 元素树 style/文本对账 | ✅ 沿用 R14 模式 |
| 状态迁移（点击 → setState → 重渲染） | 需 DOM + react-dom/client + act（jsdom/RTL） | ❌ 记录升级路径，不硬造 |
| 真实焦点/键盘事件流 | user-event | ❌ 同上 |

### 执行插曲（三则，均已沉淀为经验）

1. **collectButtons 累加器污染**：首版把「累加器 out + flatMap」混用，数组子节点导致结果重复计入（3 按钮收到 8 项）。修复 = 回退 R14 已验证的纯函数式版本（无累加器，`[].concat` 递归）。教训：**元素树收集器必须纯函数式，勿混用两种归并策略**。
2. **SSR 实体转义**：DriveModeSwitch 的 token desc 含 `<`（"置信度 < 0.9"），renderToStaticMarkup 转义为 `&lt;` 导致 toContain 失配。修复 = 期望串同规则转义（`replace(/</g, '&lt;')`；`replaceAll` 因 tsconfig lib < es2021 不可用）。
3. **断言与 title 属性解耦**：AgentAvatar 默认态 title 已含 name/role 文案，裸文本 not.toContain 误报；另 GlobalCommandMenu 的 onNavigate 为回调 prop 不进 SSR HTML，断言无意义。修复 = 文案断言锚定 DOM 结构（`>text</span>`），回调 prop 不做 HTML 断言。教训：**HTML 断言必须区分「渲染文本」「属性文本」「不渲染的 prop」三类来源**。
