## 二、方案与不执行项

**方案**（三层递进，全部零新依赖）：

1. **R14-A common 层契约**：
   - [States.test.tsx](../../src/components/common/__tests__/States.test.tsx)：四态组件全默认文案 + 按钮分支矩阵 + onAction 绑定——**ErrorState 零 prop 仍渲染重试按钮 = R13 恢复动作单源的行为级契约**（改默认值不同步保按钮 = 测试红）；
   - [Thumb.test.tsx](../../src/components/common/__tests__/Thumb.test.tsx)：无 src 降级占位（data-degraded/role/aria-label/4 字符标签/渐变）↔ 有 src img（lazy）双分支；
   - [GateBadge.test.tsx](../../src/components/common/__tests__/GateBadge.test.tsx) / [StatusDot.test.tsx](../../src/components/common/__tests__/StatusDot.test.tsx) / [MetricCard.test.tsx](../../src/components/common/__tests__/MetricCard.test.tsx)：设计系统原子三件套（门禁徽章联动 tokens 单源、脉冲/尺寸映射、指标卡 ↑↓ 正负分支）。
2. **R14-B layout 层契约**：
   - [AppSidebar.test.tsx](../../src/components/layout/__tests__/AppSidebar.test.tsx)：**NAV_GROUPS 单源 ↔ 渲染 DOM 39+5 项逐一对账**（R11 完备性门禁的 DOM 级验证：改清单不同步渲染 = 红）、active 高亮唯一性、按钮结构计数（3 特殊 + 39 导航 = 42）；
   - [TopNav.test.tsx](../../src/components/layout/__tests__/TopNav.test.tsx)：品牌区/全局搜索/通知徽章默认值/Dev Mode 文案。
3. **R14-C pages 层渲染冒烟**（本专项核心增量）：
   - [page-render.test.tsx](../../src/navigation/__tests__/page-render.test.tsx)：**43 页全量 `renderToStaticMarkup` 真实渲染**（复用 registry 测试已实证的 lazy 载荷预触发取组件，再以 registry 绑定的 props 渲染）——「渲染冒烟只覆盖元素创建」缺口闭合，R9 类渲染期崩溃从「点击时白屏」提前到「测试即红」；
   - 错误分支抽检：`viewState='error'` 渲染 publish 页 → 断言降级文案（R13 ErrorState 默认化的**页面级端到端实证**）。

**明确不执行项**：

| 候选项 | 结论 | 理由 |
| ---- | ---- | ---- |
| 安装 @testing-library/react + jsdom | 不执行 | 沙箱 `pnpm add` 双重拦截（事实 #6）；零依赖方案已覆盖本轮声明范围（渲染契约 ≠ 交互模拟）；真实点击模拟留待沙箱外环境补充 |
| coverage 口径扩入 components 层 | 不执行 | 本轮为渲染冒烟/结构契约，非逻辑覆盖；43 页 + 大型交互组件入口径必破 80% 四维门槛（DevModeDrawer/InteractivePrototypeRunner 等重交互组件无法静态覆盖） |
| GlobalCommandMenu / DevModeDrawer / widgets 测试 | 不执行 | ⌘K 键盘监听与剪贴板为真实 DOM/组合根接线行为，零依赖渲染无法触达；W1/W2 属展示型 demo 组件，契约价值低 |
| ConfirmSheet / BatchActionBar / DriveModeSwitch / AgentAvatar 独立用例 | 不执行 | 随 TopNav/页面冒烟间接覆盖渲染路径；行为均为交互型，独立契约收益低 |
| AuthHeader 既有 3 用例强化 | 不执行 | 已有结构契约；避免为改而改 |

## 四、风险与缓解

| 风险 | 等级 | 缓解 |
| ---- | ---- | ---- |
| react-dom/server 在 vitest node 环境解析失败 | 低 | R14-A 首批即探针；失败降级回「组件函数调用 + 元素树」既有范式（AuthHeader 模式） |
| 43 页真实渲染暴露潜在渲染期 bug（如 null 数据分支） | 中 | 属测试价值本身——发现即修复并单独立项记录；冒烟仅断言非空 HTML，不锁具体 DOM 细节 |

## 五、执行记录（2026-10-12 全链落地 ✅）

### R14-A/B 组件契约层（common 5 件 + layout 2 件）

- **零依赖渲染基建**：`react-dom/server` 的 `renderToStaticMarkup` 首次启用——Node 下真实渲染整棵树（子组件递归 + hooks 初始态），较既有「组件函数直调」范式升级（盘点事实 #2 缺口闭合）；含 useState 组件渲染器外直调会触发 invalid-hook-call（TopNav 首版实证），契约断言统一经渲染器。
- States ×7：**ErrorState 零 prop 重试按钮 = R13 恢复动作单源行为级契约**；EmptyState 零 action 零按钮（与 ErrorState 对照锁「默认化仅 ErrorState」）；Loading/NoPermission 分支矩阵。
- Thumb ×2（降级占位 ↔ lazy img 双分支）、GateBadge ×2（与 tokens 门禁阶梯单源联动）、StatusDot ×2、MetricCard ×3（涨跌正负分支）。
- AppSidebar ×3：**NAV_GROUPS 39+5 项 DOM 级对账**（R11 完备性门禁的渲染层验证，改清单不同步渲染 = 红）+ active 唯一高亮（border-l-2 ×1 + 组色边框）+ 42 按钮结构契约；TopNav ×2（文案矩阵 + 11 按钮结构 + 徽章分支）。

### R14-C 43 页渲染冒烟

- [page-render.test.tsx](../../src/navigation/__tests__/page-render.test.tsx)：lazy 载荷解析 + registry 绑定 props 真实静态渲染——**「渲染冒烟只覆盖元素创建」缺口闭合**，R9 类渲染期崩溃从点击期前置到测试期；载荷结构变化硬失败（与 registry 测试静默守卫差异化，渲染保证不容跳过）。
- error 分支端到端：publish 页直出 ErrorState 默认降级文案（R13 单源页面级实证）。
