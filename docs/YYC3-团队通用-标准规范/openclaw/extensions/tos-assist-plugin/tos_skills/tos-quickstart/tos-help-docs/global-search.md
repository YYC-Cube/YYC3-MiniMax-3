# 全局搜索

全局搜索是一款专为 TNAS 开发的强大检索工具。通过构建文件夹索引数据库，支持快速搜索 TOS 功能、应用程序、文件夹及各类文件（如 Office 文档、图片、音频等），大幅提升查找效率与使用体验。

## 搜索

>### 管理与操作
- **搜索**：启用全局搜索功能，可在顶部搜索栏输入关键词，快速查找已索引目录中的文件与文件夹。
- **筛选**：根据文件类型、修改时间、大小等条件过滤搜索结果。
- **视图**：切换搜索结果的显示方式，支持列表、预览两种视图模式。
- **设置**：进入索引管理页面，可添加或删除索引目录，并配置搜索历史的保留规则。

:::info 注意
当搜索结果超过 1,000 条时，系统将默认展示匹配度最高的前 1,000 条结果，其余匹配项将不再显示。如需更精确的搜索结果，建议您细化搜索关键词或结合筛选条件进一步缩小范围。
:::

## 文件索引
为实现对文件夹及其内容的快速、精准搜索，系统需预先建立文件索引。未被索引的文件夹将无法进行内容搜索。

>### 管理与操作
- **添加**：将选中的目录加入索引列表，并创建对应的索引数据库。
- **删除**：从索引目录列表中移除选定目录，同时清除其所有索引数据。
- **重建索引**：重新生成或修复指定目录的索引数据库。

>### 如何添加索引文件夹 
1. 点击右上角的“设置”按钮。
2. 前往“索引目录”页面，点击“添加”按钮。
3. 选择需要索引的目录，确认并应用设置。

:::info 注意
1.应用默认索引登录用户的个人文件夹，无需单独添加。
2.最多支持添加 500 个索引目录。
3.索引操作可能会占用系统资源，建议在非高峰时段执行大规模索引任务。
4.若在目录正在索引过程中执行搜索，结果可能不完整或滞后，建议等待索引完成后进行精确查询。
:::

## 历史关键词
启用此功能后，系统将自动保存您的搜索关键词记录，方便快速复用历史搜索关键词。最多可保留 300 条搜索记录，超出后最早的关键词条目将自动被新记录覆盖。

:::info 注意
禁用此功能时，所有已保存的搜索记录将被立即清除，且无法恢复。如需保留历史数据，请在关闭前做好记录。
:::
