# 应用中心

您可以在应用中心安装符合您需求的 TerraMaster 团队设计的应用程序或第三方应用程序。如 Duple Backup 是一款具有备份与还原功能的灾备工具、CloudSync 能快速实现 TNAS 和云盘之间的数据同步、Terra Photos 能够智能的对照片进行识别与分类、Docker Manager 是以图形界面的方式实现镜像管理的工具等。

## 安装应用

- **在线安装:** 您可在应用中心的【推荐应用】、【所有应用】、【社区应用】中，查看所有应用，或使用搜索框查找您需要的应用，点击安装即可。如需安装或下载【社区应用】中的应用，部分应用可能需要您注册该应用商的帐户。
- **手动安装:** 点击手动安装按钮，通过上传 .tpk 或 .deb 格式的应用安装文件手动安装应用。您可在应用中心中点击“下载”按钮，或前往“社区应用”获取对应的 .tpk 或 .deb 安装包。

>###  Docker 应用
- **镜像:** Docker 应用默认拉取并使用镜像的 latest（最新） 版本。
- **重要提示:** 部分 Docker 应用可能需要额外的声明或配置信息，如账号、密码等，请按照应用说明完成相关设置。
- **Docker 容器配置:** 请根据应用要求填写相应参数，务必配置数据卷路径和端口信息，否则可能导致容器构建或运行失败。

:::info 注意
1. Beta 版本应用是为测试用途而设计的应用程序。目的是用来确保正式版的软件质量，因此软件可能会有 bug 或执行不顺的情况发生。若您想测试这些应用程序，欢迎您下载安装应用程序，并提供您的建议。
2. 安装 Docker 应用前，需要先安装并启用 Docker Engine 及 Docker Manager 应用程序。通过 Docker Manager，您可以管理容器并自定义容器配置。
3. 如果您无法找到所需的应用，请联系 TerraMaster 团队开发者以了解更多信息。
:::

## 管理应用

- **启用/停用:** 点击已安装的应用程序进入应用详情页，点击“停用”或“启用”来改变应用程序的运行状态。
- **更新:** 当已安装的应用程序有新版本发布时，桌面的“应用中心”图标将会提示可更新的应用数量，进入 应用中心 > 已安装 找到您需要更新的应用，点击更新按钮即可更新应用程序。
- **下载:** 下载后缀名为 .tpk 或 .deb 的应用安装文件。如您在无法连接网络的情况下，可以通过手动方式安装后缀名为 .tpk 的应用安装文件，从而使用该应用。
- **卸载:** 在应用详情中，点击卸载按钮即可卸载该应用。


## 应用设置

- **安装位置:** 当您管理多个存储池或卷时，您可以根据实际需求和应用特性来灵活配置应用程序的安装位置。
- **应用程序：** 在“应用中心”的“已安装”页面，您可以通过“应用程序设置”查看已安装应用程序的存储位置、端口号以及当前的启用状态。同时，您还能迅速执行启用、停用或卸载应用程序的操作。
- **应用日志:** 应用日志能够记录您安装应用的时间、类别、状态、等级，同时捕获执行安装操作的用户信息。您可根据需要自定义日志的存储容量和时长。应用日志支持将所有的日志数据导出到您的本地电脑。

:::info 注意
1. 日志等级分为三级: Info 代表常规信息，Error 记录运行时错误，而 Warning 则警示可能影响系统运行或安全性的较严重事件。
2. 日志类别分为三类: Install 表示安装成功，Start 表示启用成功，Stop 表示停用成功。
3. 日志保留天数，默认为 30 天,日志保留条数，默认为 10000 条。
:::
