# 安全顾问

安全顾问是一款高效的系统配置扫描工具，旨在彻底检查您系统的安全设置。它能够准确识别潜在的安全风险，并提供针对性的解决方案。系统初始化后，安全顾问将自动启动第一次扫描。扫描完成后，安全顾问将根据扫描结果提供安全建议和应对措施。

## 扫描与应对措施

>### 扫描

点击扫描按钮开始手动扫描。要停止扫描，请点击停止按钮。

>### 扫描结果

扫描完成后，系统将以直观的图标显示结果，点击风险项即可快速查看详情，帮助您及时了解和处理安全风险。

- **绿色：** 代表检测项安全无忧。
- **红色：** 代表检测项存在潜在风险，建议您立即采取对策。

>### 应对措施

在详细页面，您可以查看应对当前风险的策略。点击“立即设置”，即可快速跳转到相应页面进行必要的设置。

:::info 注意
1. 系统初始化后，在初次扫描期间，您无法将其暂停。如果您将页面关闭，安全指导仍会在后台继续进行，扫描结果将保留至下一次执行扫描。
2. 可以通过状态标记，查看检测模块的详细情况并通过点击“立即设置”，快速跳转到对应的功能进行设置。
:::
