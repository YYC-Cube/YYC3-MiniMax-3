# 终端

终端是一款内置于 TOS 系统的原生命令行管理工具，为管理员提供直接访问系统底层的权限。管理员可直接打开终端应用，无需二次身份验证即可获得完整的系统控制权，其使用体验与通过 SSH 登录系统后台完全一致。

1. 直接系统访问: 管理员登录系统后可直接启动终端，无需再次输入密码或进行其他认证操作。
2. 完整命令行支持: 支持所有 Linux 命令与系统工具，包括文件操作、进程管理、服务控制、网络配置等，与通过 SSH 登录系统后台可执行的操作完全相同。
3. 管理员专属权限: 仅管理员有权限可使用，确保系统底层操作的安全性，防止普通用户执行高风险命令。
