# 桌面
TOS (TerraMaster Operating System) 是专门为 TNAS 设备设计的基于网页界面的操作系统。通过 TOS 操作系统，您可以快速方便地完成修改系统设置、安装及打开应用程序、管理存储空间等任务。

## 登录与登出

>### 登录
当您的 TNAS 设备安装完 TOS 系统并完成初始化后，您便可以使用 TNAS PC 应用程序登录 TOS 系统。或者通过 TNAS PC 应用程序查看 TNAS 的 IP 地址，在浏览器中输入该地址登录 TOS 系统。

*   **忘记/重置密码：** 若您忘记密码，系统将发送验证码至邮箱以验证您的身份。验证通过后，您便可以重置密码。
*   **保持登录：** 启用保持登录功能，浏览器将保存您的登录信息，以便下次快速访问和使用 TOS 系统。但请注意，在公用设备上登录时，请谨慎操作，以确保账户安全。

:::info **注意**
1.  在初始化设置过程中，您已经为 TOS 系统设置了 IP 地址、管理员名称及密码。如果您无法登录 TOS 系统，请通过 `http://tnas.local` 或前往 TNAS PC 应用程序选择对应的设备重新设置。
2.  清除浏览器的缓存或 Cookies ，可能会使您失去当前的登录状态，建议您在清理后重新登录，以确保账户安全和正常使用。
:::

>### OTP 二次验证
OTP 通过提供额外的身份验证步骤和动态密码机制，为您的账户提供更高级别的保护。请前往 **TOS 桌面 > 开始 > 用户设置**，启用 OTP（一次性密码）二次验证功能。

![TOShlep_Tosdesktop_Desktop_001cn.jpg](https://s2.loli.net/2025/12/12/Slc53zhToXLrdB6.jpg)
*   **启用 OTP：** 请在您的移动设备上下载并安装 TNAS Mobile App。在 APP 中打开 OTP 验证应用程序，根据系统中 OTP 设置向导的指示，完成启用 OTP 二次验证的功能。
*   **管理信任设备：** 勾选“将此终端添加为受信任设备”，即可在信任设备列表中查看和管理您的登录设备。当您从信任的设备登录时，TNAS 不会提示您进行 OTP 二次身份验证。
*   **停用 OTP：** 点击停用按钮，输入用户密码即可关闭 OTP 二次验证功能。

:::info **注意**
1.  请确认您的移动设备和 TOS 的系统时间同步，以避免时间差异导致的验证问题。
2.  OTP 验证码每隔一分钟更新一次，请确保输入的验证码未过期。
3.  如您同一账户在不同的浏览器上登录、清除浏览器的 Cookie 数据、同一浏览器中登录其他需要 OTP 二次验证的用户，即使您之前已将某台设备标记为受信任设备，在以上情形中，仍需要进行 OTP 二次验证。
:::

>### 登出
手动登出系统请前往 **TOS 桌面 > 开始**，点击右上角的登出、重启、关机按钮，根据您的需求选择“登出”选项。管理员用户可以启用系统超时自动登出功能，当达到您设定的超时时间后，系统将自动登出当前用户。

## TOS 桌面
您成功登录 TOS 系统后会进入 TOS 桌面。TOS 桌面包含顶端导航栏、主菜单及右侧工具栏。

![TOShlep_Tosdesktop_Desktop_002cn.jpg](https://s2.loli.net/2025/12/12/EMwp1VgqizYyHZ5.jpg)

>### 导航栏
顶端导航栏集成多个固定功能入口，如**开始菜单**、**文件管理**、**所有应用**、**备份**、**控制面板**、**应用中心**、**Docker Manager (Docker 管理器)**、**支持与帮助**等，同时支持将常用应用程序固定在导航栏上，以便您快速访问和使用。

>### 主菜单
您可以在主菜单中创建 URL 快捷方式以及编辑用户设置，快速启动或卸载已安装的应用程序。

*   **创建 URL 快捷方式：** 请输入一个完整且有效的网页访问路径（如 `http://192.168.1.1:5443`）。
*   **编辑用户设置：** 修改用户账号信息及自定义系统外观显示（如将系统外观显示设为暗黑模式）。

![TOShlep_Tosdesktop_Desktop_003cn.jpg](https://s2.loli.net/2025/12/12/KUyIXYcfTbEexna.jpg)
:::info **注意**
由于安全原因，修改密码将会中断所有正在进行中的任务并需要重新登录，请谨慎操作。
:::

>### 工具栏
工具栏的作用是帮助您快速的使用 TOS 的一些常用功能。如系统看板、消息通知、蜂鸣器开关及帮助支持。

*   **系统看板：** 系统看板是一个浮动菜单，用于快速展示 TOS 系统与 TNAS 设备的关键信息，如设备名称、TOS 版本、运行时间、网络连接状态和存储空间等，您可以通过拖动操作调整这些信息组件的排序。如您需要自定义展示菜单内容，请点击该菜单右上角的“设置”按钮。
*   **消息通知：** 接收系统安全、应用程序安装、状态更新、电源等通知。如需设置您想要接收的消息类型，请点击该菜单右上角的 “设置” 按钮。
*   **蜂鸣器开关：** 当 TNAS 发生异常时，蜂鸣器会发出警报声。您可以通过点击铃铛图标来关闭蜂鸣器。
*   **帮助：** 如您需要帮助或支持，请点击“帮助”联系我们。
*   **后台任务：** 当有任务在后台运行时，单击此图标可查看更多详细信息，如进度和上传速度。
