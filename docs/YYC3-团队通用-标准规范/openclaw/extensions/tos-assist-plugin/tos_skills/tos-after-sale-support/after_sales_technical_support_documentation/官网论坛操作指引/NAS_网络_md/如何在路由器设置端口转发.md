# 如何在路由器设置端口转发

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4832&sid=51493c53a160f99b97633ae2f702b6b5

适用版本: 所有版本

适用机型：所有机型

操作步骤：
一、登录路由器管理界面：

1、打开浏览器，输入路由器的IP地址（通常可以在路由器底部标签上找到，如192.168.0.1或192.168.1.1），按下回车键。

2、输入用户名和密码（默认情况下通常是admin，具体取决于你的路由器品牌和型号）。如果忘记了用户名和密码，可以查阅路由器说明书或尝试常见的默认用户名和密码组合。

二、配置端口转发规则

1、找到端口转发设置：

1.1 在路由器管理界面中，找到“高级设置”或“设置”选项。

1.2 选择“端口转发”或类似的选项。不同路由器的界面“端口转发”的名称与位置可能不同。

2、添加端口转发规则（以下步骤不分先后）：

2.1 输入服务名称，以便识别该端口转发规则

2.2 外部端口：这是你想要从外部网络访问的端口号 (通常与内部端口相同)。

2.3 内部端口：通常是内部设备上服务运行的端口号，例如：plex端口32400

2.4 输入内部设备的IP地址: 接收外部访问请求的内部设备的IP地址。

2.5 选择协议类型: 根据你的需求选择TCP、UDP或TCP/UDP。

三、注意事项

确保所选的端口没有被其他应用程序占用。并且内部设备的防火墙也允许外部访问。如果路由器具有动态IP地址，当IP地址更改时需要更新端口转发规则。

通过以上步骤，你应该能够在大多数路由器上成功设置端口转发。如果遇到任何问题，请查阅路由器说明书或联系路由器制造商的技术支持部门以获取帮助。
