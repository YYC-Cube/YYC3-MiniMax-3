# 关于Time Machine 配额.

**关键词：TOS、TNAS、控制面板、共享文件夹、独立的存储配额设置、**

**解决方案：**

Time Machine配额设置因TOS版本而异：

TOS 6：
- 时间机器有独立的存储配额设置，与共享文件夹配额可能冲突
- 如需限制时间机器备份大小：在时间机器备份的授权目录中单独设置配额
- 不建议同时启用时间机器配额和共享文件夹配额，避免冲突

TOS 7：
- 已取消时间机器的独立存储配额设置
- 统一使用共享文件夹配额来管理时间机器备份空间
- 前往 TOS Web > 控制面板 > 共享文件夹 > 编辑时间机器共享文件夹 > 配额

注意事项：
- 启用文件夹配额会增加一定系统开销
- 建议为时间机器分配充足空间（至少2-3倍Mac硬盘容量）
