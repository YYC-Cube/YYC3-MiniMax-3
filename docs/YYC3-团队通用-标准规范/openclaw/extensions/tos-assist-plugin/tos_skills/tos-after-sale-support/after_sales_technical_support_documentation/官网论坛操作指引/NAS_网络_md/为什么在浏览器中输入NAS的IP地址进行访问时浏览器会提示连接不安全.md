# 为什么在浏览器中输入 NAS 的 IP 地址进行访问时，浏览器会提示连接不安全

原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4953&sid=51493c53a160f99b97633ae2f702b6b5

适用版本:

所有版本

适用机型：

所有机型

故障现象：

通过浏览器（如Chrome、Edge等）访问铁威马TOS系统管理界面时，可能会收到“不安全”或“您的连接不是私密链接”的警告提示。

故障原因：

由于浏览器对未配置官方HTTPS证书，并且本地IP地址采用默认安全策略，导致访问本地设备时出现“不安全”警告。浏览器要求网站通过HTTPS协议提供服务，但多数家用NAS设备在出厂时未强制配置HTTPS证书，而是通过本地IP（如http://192.168.1.100）进行访问。虽然这种访问在局域网内并没有实际安全风险，但浏览器仍会将未加密的HTTP连接标记为不安全。不同品牌的NAS设备都有类似现象，用户需要手动信任证书或配置HTTPS来解决此问题。

解决方案:

1.忽略警告：点击浏览器”高级 “ >“继续访问 ”

2.绑定域名并配置证书：通过配置DDNS、tnas.online进行访问
