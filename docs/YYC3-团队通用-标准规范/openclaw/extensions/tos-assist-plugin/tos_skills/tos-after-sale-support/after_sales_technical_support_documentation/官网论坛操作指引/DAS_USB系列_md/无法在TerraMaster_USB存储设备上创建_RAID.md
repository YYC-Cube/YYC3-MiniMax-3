# 无法在TerraMaster USB存储设备上创建 RAID？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=498

故障排除

适用型号:
D2-310
D5-300C

如果已将硬盘安装到 TerraMaster USB 存储设备中，且硬盘指示灯呈绿色，并且所有驱动器均显示正常，但是创建 RAID 失败了，请尝试以下解决方案：

步骤1：将开关指针旋转到 SINGLE 模式；
步骤2：按住复位按钮约5秒钟，直到硬盘指示灯从绿色变为红色；
步骤3：大约3秒钟后，硬盘指示灯会从红色自动变为绿色，此时，将开关的指针旋转到所需的 RAID 模式；
步骤4：按住复位按钮约5秒钟，直到硬盘指示灯由绿色变为红色；
步骤5：大约2秒钟后，硬盘指示灯将自动从红色变为绿色。RAID 创建完成。
