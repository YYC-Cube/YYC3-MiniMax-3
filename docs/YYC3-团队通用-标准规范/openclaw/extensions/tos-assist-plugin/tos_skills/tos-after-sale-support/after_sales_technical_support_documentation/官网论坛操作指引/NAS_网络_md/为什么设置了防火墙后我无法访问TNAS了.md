# 为什么设置了防火墙后，我无法访问TNAS了？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3583&sid=51493c53a160f99b97633ae2f702b6b5

故障排除

适用型号
所有 TNAS 机型

适用系统
所有 TOS 版本

故障现象
在 TOS > 控制面板 > 安全 > 防护墙创建规则时，由于误操作或对防火墙规则的了解不足或有误，导致当前用于访问 TOS 的电脑也被防火墙阻止了。

原因分析
根据以往用户提供的反馈和复现验证，我们总结出以下一些原因。
一方面，一直以来我们缺少对该防火墙的必要的说明。TOS 的防火墙是通过 Linux 的 iptables 命令行实现的，并将复杂的命令行简化成您所看见的防火墙 UI。其中的“允许”规则实际上的作用是“只允许”，这也是有的用户搞错的地方。我们已计划增加相关描述以帮助更多用户。
另一方面，有的用户将 Windows 防火墙的部分使用习惯沿用到 TOS 的防火墙上。在设置需要开放端口的服务或应用时，用户可能会认为 TOS 没有向某些 IP 地址开放某些端口，于是设置了一个“允许”某些IP地址的某些端口的某些协议的规则，导致其余所有 IP 地址、端口和协议无法被访问。实际上, Linux 的 iptables 默认情况下是开启的，但也默认没有任何规则限制，允许所有的网络流量通过。

解决方法
1. 如果您创建的只是“允许”某个 IP 地址或某个IP地址段的规则，您可以将您的 TNAS 直接连接到电脑上，然后将您的电脑的网卡配置成某个“允许”的IP地址。然后您就能访问 TOS 并重新配置。

2. 如果您创建的是“允许”某个端口或端口范围的规则，或者允许某个协议的规则，或者您甚至已经忘记了规则，很遗憾，请您通过重新安装 TOS 来重置配置：https://forum.terra-master.com/cn/viewt ... f=85&t=241
