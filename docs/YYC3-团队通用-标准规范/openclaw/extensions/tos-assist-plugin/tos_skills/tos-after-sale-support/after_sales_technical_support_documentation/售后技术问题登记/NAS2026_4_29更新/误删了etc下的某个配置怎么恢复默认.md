# 误删了/etc/下的某个配置, 怎么恢复默认?

**关键词：TOS、控制面板、etc、**

**解决方案：**

恢复方法：

方法一：从默认配置恢复单个文件（推荐）
1. 打开Terminal（SSH或TOS Web > 控制面板 > 终端）
2. 查看 /etc.default/ 目录，找到误删配置的默认版本
   ls /etc.default/
3. 复制到 /etc/ 对应位置
   cp /etc.default/xxx.conf /etc/xxx.conf
4. 重启相关服务或重启系统使配置生效

方法二：重置所有系统配置
1. 前往 TOS Web > 控制面板 > 系统 > 配置
2. 点击「重置系统配置」
3. ⚠️ 注意：此操作将重置所有系统配置为默认值，不包括用户数据
4. 若有自定义配置，建议先备份 /etc/ 下的自定义配置文件

建议：重要配置修改前，先备份原配置文件（如 cp xxx.conf xxx.conf.bak）
