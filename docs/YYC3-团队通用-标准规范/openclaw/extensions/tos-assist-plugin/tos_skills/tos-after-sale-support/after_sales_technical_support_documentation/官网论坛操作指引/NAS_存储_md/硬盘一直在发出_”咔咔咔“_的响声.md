# 硬盘一直在发出 ”咔，咔，咔“ 的响声？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1856&sid=2853efb328304e05736fc85f61407238

为什么TNAS 系统安装完后硬盘一直在发出 “嗒，嗒，嗒” 的响声？

常见问题解答
适用型号：所有 TNAS

当 TNAS 新安装完系统后，硬盘会持续发出 “嗒，嗒，嗒” 的响声，表明系统正在访问硬盘，属于正常现象。以下是系统持续访问硬盘的原因：

1.  新安装的系统在重启后，系统将对硬盘的数据及多媒体文件进行扫描以建立数据库供后续文件访问用；在扫描期间，系统将持续访问硬盘从而发出声音。扫描时间将从几分钟到几小时不等，视数据量大小而定。

2.  新创建的硬盘阵列需要进行同步，同步期间硬盘将持续工作并发出 “嗒，嗒，嗒”，持续时间从几小时到几十小时不等，视硬盘容量大小而定。

请耐心等待。
