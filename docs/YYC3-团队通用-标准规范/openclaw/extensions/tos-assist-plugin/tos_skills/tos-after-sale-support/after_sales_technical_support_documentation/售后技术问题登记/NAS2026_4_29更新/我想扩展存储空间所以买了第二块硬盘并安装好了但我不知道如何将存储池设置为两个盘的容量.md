# 我想扩展存储空间，所以买了第二块硬盘并安装好了，但我不知道如何将存储池设置为两个盘的容量.

**关键词：TOS、控制面板、存储池、RAID、格式化、想把两个硬盘做成一个**

**解决方案：**

目标：将两块硬盘合并为一个存储池，获得两块盘的总容量。

所需RAID类型：JBOD 或 RAID0
- JBOD：容量=两块盘之和，数据安全性低（一块盘坏则部分数据丢失）,如果是单盘JBOD可以无限添加硬盘，扩大容量
- RAID0：容量=两块盘之和，读写性能提升，但一块盘坏则全部数据丢失，并且无法添加硬盘，若需要扩大容量只能删除后重新创建。

操作前重要提示：此操作会格式化硬盘，请务必先备份所有数据！

操作步骤：
1. 备份所有重要数据
2. 前往 TOS Web > 控制面板 > 存储管理 > 存储池
3. 删除当前存储池（数据将丢失，确认已备份）
4. 点击「创建存储池」，勾选两块硬盘
5. 选择 RAID 类型：JBOD 或 RAID0
6. 完成创建后，再创建卷即可使用
