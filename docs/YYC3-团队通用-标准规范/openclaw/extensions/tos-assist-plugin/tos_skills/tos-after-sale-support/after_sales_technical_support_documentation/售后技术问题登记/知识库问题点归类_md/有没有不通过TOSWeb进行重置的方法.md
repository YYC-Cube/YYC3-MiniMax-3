# 有没有不通过 TOS Web 进行重置的方法？

一般可以在不安装盘的情况下启动 TNAS，从而运行初始化进程。

如果您的 TOS 安装于M.2 SSD 内，请根据 TNAS 型号选择适合的处理方式：

- **223/423 (清除系统分区的元数据)**
  
    - **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=7179
      
    - **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=4742
    
- **424/424 Pro/424 Max/425 Plus（Reset 按钮）**
  
    - **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=9523
      
    - **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=5233
