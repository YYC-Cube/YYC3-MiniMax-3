# 无法在带有雷电2接口的计算机上工作？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=294

故障排除

适用机型：
TerraMaster D2 Thunderbolt 3 / TD2 Thunderbolt 3（D2-330）
TerraMaster D4 Thunderbolt 3（D4-330）
TerraMaster D5 Thunderbolt 3（D5-330）
TerraMaster D8 Thunderbolt 3（D8-330）

如果要在具有Thunderbolt 2接口的Mac计算机上使用TerraMaster Thunderbolt 3设备，则需要注意以下几点：

1. TerraMaster Thunderbolt 3设备与Thunderbolt 2接口不兼容。您需要购买Thunderbolt 3转Thunderbolt 2适配器并准备经过认证的Thunderbolt 2电缆；
2.仅允许使用Apple提供的Thunderbolt 3至Thunderbolt 2适配器。其他适配器将无法工作；
3.仅允许使用经过认证的Thunderbolt 2电缆，任何其他未经认证的电缆都可能导致连接失败。

如何使用Thunderbolt 3转Thunderbolt 2适配器
1.将适配器的Thunderbolt 3连接器插入TerraMaster设备上的Thunderbolt 3接口连接；
2.将Thunderbolt 2电缆的一端连接到适配器的Thunderbolt 2连接器；
3.将Thunderbolt 2电缆的另一端连接到Mac计算机上的Thunderbolt 2连接器。
