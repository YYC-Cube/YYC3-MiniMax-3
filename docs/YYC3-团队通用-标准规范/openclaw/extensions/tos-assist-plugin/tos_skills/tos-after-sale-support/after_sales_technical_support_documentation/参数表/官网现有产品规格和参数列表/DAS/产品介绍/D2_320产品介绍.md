# 铁威马 D2-320 产品介绍

## 产品概述

铁威马D2-320是一款2盘位USB3.2 10Gbps外接硬盘盒，专为需要高性能存储和灵活阵列配置的用户设计。

## 核心特性

### 高速传输性能

- 采用USB3.2 Gen2协议，提供10Gbps数据传输带宽
- 2个硬盘RAID 0模式下读写速度可达521MB/s (Seagate Eoxs 22TB X2 RAID 0)
- 2个SSD RAID 0模式下读取速度可达1075MB/s（SAMSUNG 870QVO 1TB SSD X2 RAID 0）

### 超大存储空间

- 支持安装多达2个硬盘
- 支持最大硬盘容量高达22TB（更大容量硬盘尚未验证兼容性）
- 最大可提供44TB（22TB x 2）存储空间

### 硬盘兼容性

- 兼容3.5寸SATA硬盘
- 兼容2.5寸SATA硬盘
- 兼容2.5寸SATA SSD
- 备注：不兼容的硬盘可能导致设备连接中断、速度慢、无法识别硬盘，购买前请务必查询铁威马硬盘兼容性列表

### 多种阵列模式

- 支持RAID 0、RAID 1、JBOD、Single Disk四种模式
- 专业人士可根据应用场景随意选择其中一个甚至多个

### 更换硬盘更方便

- 采用免工具的硬盘支架设计，无需任何工具可装卸硬盘
- 采用铁威马全新的Push-lock独特设计，插入硬盘时硬盘支架自动上锁避免硬盘脱落或掉线
- 安装一块硬盘仅需不到10秒钟，为需要频繁更换硬盘交换数据的用户提供了极大的便利

### 接口兼容性

- 采用USB Type-C接口
- 配备USB Type-C to Type-C线一根（长度1米）
- 兼容多种电脑接口：USB 3.0/USB 3.1/USB 3.2/Thunderbolt 3/Thunderbolt 4

### NAS存储扩展

- 可连接到铁威马NAS的USB接口
- 通过铁威马TOS可在D2-320上创建阵列与存储池以扩展NAS存储空间
- 备注：仅在运行TOS 5.1系统或以上版本的铁威马NAS才支持该功能

### 硬盘智能休眠

- 支持休眠功能，可跟随电脑系统休眠
- 有效减少硬盘工作的时间，减少硬盘电量的消耗，延长硬盘使用寿命

### 安全保护

- 采用电源保护设计
- 当接入错误电源时，设备将启用自动保护机制
- 防止设备与硬盘因电源错误而损坏

### 安静运行

- 采用智能温控低噪声风扇
- 风扇转速随硬盘温度自动调节，确保硬盘处于最佳工作温度
- 设备内部结构经过专门优化，有效增加内部风压降低硬盘工作温度
- 大大降低设备部件与硬盘的共振
- 即使在满负荷工作环境下，仍能保持令人满意的低噪音
