# 支持快照备份吗?

**关键词：TOS、TNAS、控制面板、HTTPS、btrfs、快照功能在哪里配置**

**解决方案：**

支持快照备份功能。

功能说明：
- 快照可记录某一时刻的数据状态，支持快速恢复
- 可设置定时快照计划，自动创建快照
- 快照占用空间较小，仅记录变化的数据块

配置方法：
- 详细教程：https://toshelp.terra-master.com/cn/docs/TOS7/backup/snapshot

简要步骤：
1. 前往 TOS Web > 应用中心 > 快照（或控制面板 > 存储管理 > 快照）
2. 选择目标卷，点击「创建快照」或「设置快照计划」
3. 配置快照保留数量和计划时间
4. 需要恢复时，选择对应快照进行还原

注意：快照功能需要Btrfs文件系统支持
