# 系统迁移无法选择某个盘.

**关键词：TOS、SSD、**

**解决方案：**

系统盘迁移规则说明：

基本原则：
- 系统盘仅允许设置在同一类型的磁盘上
- 新增系统盘：只能选择与当前系统盘类型一致的磁盘
- 更换系统盘类型：需勾选当前所有系统盘，一起迁移到新类型

详细规则：
1. 非当前系统盘：指该磁盘系统分区上安装有非当前运行的TOS系统，此类磁盘在删除该系统前，无法新增或迁移为系统盘
2. 已用于Hyper Cache的SSD：无法再作为系统盘使用
3. 磁盘状态为错误：出于数据安全考虑，无法作为系统盘

操作建议：
- 迁移前确认目标盘类型与当前系统盘一致
- 如需更换类型（如从HDD迁移到SSD），需同时勾选所有当前系统盘进行迁移
- 迁移成功后，原系统所在磁盘将无法单独作为系统盘进入系统
