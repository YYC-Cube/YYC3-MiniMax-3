# 铁威马 D4-320U 产品介绍

## 产品概述

铁威马D4-320U是一款4托架机架式硬盘盒，专为需要大容量存储和高速数据传输的用户设计。

## 核心特性

### 精巧设计，轻松部署

- 机身深度仅 241 毫米（9.5 英寸），比标准机箱短 50%
- 重量仅 3.2 千克
- 无需导轨即可轻松装入服务器机架
- 节省空间的造型适用于数据中心、设备间或办公环境
- 为中小企业及家庭办公用户提供集中式存储方案

### 高速传输

- 采用 USB 3.2 Gen2 协议
- 数据传输速率高达 10Gbps
- 实测性能：
  - 四块硬盘时读写速度可达 1016MB/s
  - 单块固态硬盘时可达 510MB/s

### 超大存储空间

- 支持最多四块 3.5 英寸或 2.5 英寸 SATA 硬盘 / 固态硬盘
- 单盘最大容量 30TB
- 总容量可达 120TB
- 注：本硬盘盒为独立硬盘模式，不支持 RAID 阵列

### NAS 扩展扩容

- 通过 USB 连接至搭载 TOS 5.1 及以上系统的 TerraMaster NAS
- 可直接在 TOS 界面创建存储池
- 有效扩展 NAS 容量

### 即插即用，广泛兼容

- 免驱设备，开箱即用
- 兼容 Windows、macOS、Linux 系统
- 配备 USB-C 对 C、USB-C 对 A 数据线（各 0.8 米）
- 支持 USB 4.0、3.2、3.1、3.0 及雷电 5/4/3 接口
