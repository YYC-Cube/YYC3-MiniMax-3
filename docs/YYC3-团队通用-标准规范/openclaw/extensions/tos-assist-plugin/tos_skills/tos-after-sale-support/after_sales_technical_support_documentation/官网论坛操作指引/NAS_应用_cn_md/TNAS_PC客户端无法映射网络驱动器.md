# TNAS PC客户端无法映射网络驱动器

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=644&sid=2830252e3f49fda663c79a41b721ea52

**关键词**：PC客户端、tnas pc、映射驱动器、电脑客户端、网络驱动器

---

故障排除

如果您无法使用TNAS PC映射网络驱动器，或者映射成功后，重启电脑访问网络驱动器，输入正确的用户名与密码无法访问。请按照以下步骤进行排查：（注意：如果您使用的电脑是Win7系统，则该问题主要是TNAS PC客户端与Win7系统的兼容性问题，请直接查看第 6 条）

1. 确保您已使用与 TOS 版本适配性最好的 TNAS PC 版本：
TOS 4.x：https://download2.terra-master.com/Terr ... .2.0.6.zip
TOS 5.x：https://download2.terra-master.com/TNAS ... 5.0.35.exe

2. SMB服务是否已启用。请前往TOS控制面板–网络服务–文件服务– SMB/CIFS服务，取消选中，然后单击“应用”，然后再次对其进行勾选，然后单击“应用”。然后请尝试再次映射驱动器。

3.您的TOS登录密码中可能含有特殊字符，例如“#%@”。请通过单击TOS网页右上角的“ admin”来修改密码，以删除特殊字符，然后尝试重新映射驱动器。

4.输入密码时，需要选中“记住我的凭据”，否则重新启动计算机后，映射的驱动器将消失。

5.您必须具有对所选文件夹的“读写”完全权限，否则系统将提示您“配置失败错误代码1202”。您可以在TOS控制面板–访问权限–共享文件夹 中更改权限。

6.请前往Windows的“凭据管理器”，删除当前记住的TNAS的凭据，然后重试。

7.如果以上方法均无效，请通过在 Windows 文件资源管理器中输入\\ TNAS IP 地址（如\\192.168.1.25）来访问TNAS，右键单击TNAS中的共享文件夹，然后从列表中选择“映射网络驱动器”。
