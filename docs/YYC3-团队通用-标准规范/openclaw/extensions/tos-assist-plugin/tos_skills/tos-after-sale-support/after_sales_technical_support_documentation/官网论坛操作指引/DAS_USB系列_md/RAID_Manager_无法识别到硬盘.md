# RAID Manager 无法识别到硬盘

故障排除

适用机型：
D5-300

RAID Manager是 TerraMaster USB 存储设备的硬件阵列控制器的配置工具。 如果要创建硬件阵列，则需要在计算机上安装 RAID Manager。如果您安装有数据的硬盘并希望使用“SINGLE”模式，则可以直接使用而无需更改任何设置。

如果已将硬盘安装到 TerraMaster D5-300中，但是 RAID Manager 无法识别硬盘，请尝试以下解决方案：

1. Windows Defender可能阻止了RAID Manager。因此，请转到Windows Defender的设置，取消对RAID Manager阻止。
2. 您的硬盘可能已在其他设备上使用。请格式化硬盘，然后重试。
3. 硬盘故障，请更换硬盘再重新尝试。
