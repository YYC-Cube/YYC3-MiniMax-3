# TNAS已经没有空的插槽了. 如何能增加更多插槽以实现扩容?

**关键词：TOS、TNAS、存储池、DAS（硬盘盒）接USB DAS扩展硬盘**

**解决方案：**

场景一：TNAS内无空插槽扩容

TOS6及以上版本支持通过USB连接DAS（HDD扩展盒）扩容：
1. 将DAS（硬盘扩展盒）通过USB连接到TNAS
2. 注意：必须在TNAS启动前将DAS通电并启动完成
3. DAS内的硬盘可被识别为扩展SATA，像内置硬盘一样创建存储池和卷

重要限制：
- DAS内的硬盘无法与TNAS内置硬盘参与同一个存储池
- DAS需要单独创建存储池

场景二：DAS盘与NAS盘能否同一存储池
→ 不支持。DAS硬盘只能创建独立的存储池，无法与内置硬盘合并为同一存储池
