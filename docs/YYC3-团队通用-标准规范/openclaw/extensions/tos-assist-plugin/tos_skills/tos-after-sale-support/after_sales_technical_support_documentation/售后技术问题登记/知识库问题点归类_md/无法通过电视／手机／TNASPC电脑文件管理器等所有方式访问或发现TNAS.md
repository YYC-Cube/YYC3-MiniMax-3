# 无法通过电视／手机／TNAS PC/电脑文件管理器等所有方式访问或发现 TNAS。



首先，我们乐观猜测有可能是系统负载较高，堵塞影响您寻找和访问它。请先尝试重启NAS，再观察一下。
如果重启后问题依然存在，可能是启动不成功或系统未正常运行。请尝试在不安装任何盘的情况下启动TNAS，看看是否能成功搜索到TNAS并打开初始化网页。

* 如果在不安装任何盘的情况下成功启动，说明TOS系统损坏或TOS系统所在的盘存在异常。
* 如果在不安装任何盘的情况下也启动失败，可能是硬件或USB Init boot问题。您可以尝试重新烧录新的USB Init boot：
  * **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=6433
  * **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=4399

如果您有HDMI显示器，可以在启动NAS前接上，观察它最终停留在什么画面。
