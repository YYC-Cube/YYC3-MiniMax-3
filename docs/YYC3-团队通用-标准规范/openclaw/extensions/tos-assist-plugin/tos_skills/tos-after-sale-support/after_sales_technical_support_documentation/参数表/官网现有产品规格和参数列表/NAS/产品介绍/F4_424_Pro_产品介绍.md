# F4-424 Pro 产品介绍

## 产品概述

**F4-424 Pro**  
**巅峰性能 4 盘位 NAS**

释放 F4-424 Pro NAS 存储的强大性能，搭载 3.8GHz（睿频）英特尔 N305 CPU、1.25GHz 集成 UHD GPU、32GB DDR5 4800MHz 内存（非 ECC，不可升级）、双 2.5G 以太网端口以及用于 SSD 缓存的双 M.2 NVMe 插槽。是中小型企业用户理想的巅峰性能 NAS 存储解决方案。

### 巅峰硬件配置

- 搭载 3.8GHz（睿频）英特尔 N305 CPU
- 1.25GHz 集成 UHD GPU
- 32GB DDR5 4800MHz 内存（非 ECC，不可升级）
- 双 2.5G 以太网端口
- 双 M.2 NVMe 插槽用于 SSD 缓存

- 性能较上一代产品提升 150%

- 凭借流畅的高负载性能，提升工作流程效率

### 高速连接能力

- 双 2.5 GbE 接口，线性数据传输速度可达 283 MB/s

- 适合多用户和高并发文件访问
- 双 USB 3.2 Gen2 10Gbps 接口
- 支持多种 RAID 类型：
  - RAID 0/1/5/6/10/JBOD/Single 和 TRAID
