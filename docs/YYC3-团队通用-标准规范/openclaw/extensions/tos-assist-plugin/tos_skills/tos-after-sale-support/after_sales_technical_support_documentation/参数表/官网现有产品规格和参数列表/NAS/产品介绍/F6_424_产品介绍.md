# 铁威马 F6-424 产品介绍

## 产品概述

F6-424 是一款6盘位高性能存储方案，专为SMB用户设计。多种企业级备份解决方案可确保用户数据安全并防范潜在的数据丢失风险，强大的计算能力让企业可从容应对高负载工作任务。采用Intel Celeron N95 4核4线程处理器，最大睿频至3.4GHz，集成Intel® UHD Graphics 显卡，最大动态主频 0.75Ghz，支持 AES NI 硬件加密，搭配 8 GB DDR5 4800Mhz 内存，两个2.5G网口，内置两个M.2 NVMe 插槽，实现SSD 缓存加速，成倍提升磁盘阵列的存储效率，是中小型商业用户虚拟化与数据库的高性能存储解决方案。

## 核心特性

### 最安静的6盘位混合型NAS

- 精心设计多种减震结构，并采取巧妙的消音措施
- 确保F6-424即使在满负荷运行时，也能保持低温和静音状态
- 新一代产品的噪声相比上一代降低了50%
- 在待机状态下，其噪声仅为22dB(A)！
- 凭借出色的静音特性，在为工作提供强大动力的同时，营造安静舒适的办公环境

*(测试条件：使用 2 个 SATA HDD/SSD 工作于处于待机状态；测试环境噪声：17.3dB(A) 测试距离：1米)*

### 更快的应用程序响应

- 采用更强大的CPU与DDR5内存
- 与T6-423相比，综合运算性能提升超过220%
- 应用程序的加载速度提升160%
- 文件与照片的检索速度提升90%
- 数据库响应速度提升100%
- 网页PHP响应提升110%
- 能轻松应对高负载工作流

### 5Gb高速吞吐性能

- 标配两个 2.5GbE 网口，提供2.5Gb网络带宽
- 线性数据传输速度可高达 283MB/秒 (Seagate IronWolf 18TB x 6, RAID0)
- 通过网络聚合Link Aggregation，可实现高达5Gb的网络带宽
- 为多用户高并发的文件访问提供经济实惠的解决方案

### 强大的多媒体服务

- 具备强大的4K视频解码能力
- 兼容 uPnP/DLNA协议
- 配合铁威马专用应用程序"多媒体服务器"或者 Plex, Emby, Jellyfin 等第三方多媒体服务器
- 将视频串流到各种多媒体设备：电脑、智能手机、媒体播放器和电视
- 提供不间断的、愉快的观看体验

### 灵活的存储配置

- 支持Single/RAID0/1/5/6/10，多种 RAID类型
- 提供铁威马特有弹性阵列TRAID/TRAID+
- 实现阵列在线容量扩充，在线迁移，并能为阵列配置冗余盘
- 支持创建多个存储空间，根据业务需求，可任意选择ext4或Btrfs文件系统
- 配合铁威马USB DAS磁盘阵列，能够弹性扩充存储空间容量

- 采用全新的用户交互方式，实现了由内而外的焕然一新

- 全面满足各种网络环境下的跨平台文件服务需求

铁威马视用户数据为最珍贵的资产，为此开发了全面强大的各类数据备份工具，为数字资产提供妥善保障：

- "文件系统快照（FSS）"与"快照"提供从卷级别到文件夹级别的快照服务
- 让您免于承担遭受勒索病毒攻击的风险

- Duple Backup为卷、文件夹、iSCSI LUN数据实现3-2-1的备份策略提供一站式解决方案
- Centralized Backup从商业用户的需求出发，提供主动式中央控管备份任务管理
- 全面满足商业用户对Windows工作站、文件服务器、虚拟机的备份需求

### 跨多设备的文件同步

- 使用铁威马TerraSync服务，将NAS架设为一台私有云服务器
- 打破文件存取限制，无论身在何处，都能跨平台、跨设备随时存取个人或他人共享的文件

- 通过铁威马CloudSync将云盘与NAS连接，实现云盘与NAS数据的同步共享

- 包括Google Drive，OneDrive, Amazon S3, Dropbox, Baidu, 阿里云等
- 只需要管理一个应用即可满足不同的云盘同步管理

面对日益猖獗的网络攻击，网络设备的系统安全正面临着前所未有的巨大挑战。TOS提供了多种系统性安全防护措施，旨在有效降低设备遭受恶意攻击的风险：

- OTP二次验证

- 防火墙

- 进一步提升系统安全性，降低用户数据遭受黑客或勒索病毒攻击的风险
