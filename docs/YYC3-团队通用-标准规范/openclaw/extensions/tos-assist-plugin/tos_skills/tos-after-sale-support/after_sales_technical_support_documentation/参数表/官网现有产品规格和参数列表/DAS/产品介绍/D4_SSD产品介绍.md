# D4 SSD 产品介绍

## 产品概述

D4 SSD 是一款4盘位全闪硬盘盒，专为媒体创作、影视制作等高性能应用场景设计，提供高达40Gbps的USB4传输带宽。

## 核心用途

- 专为媒体创作、影视制作应用场景设计
- 全面兼容USB 4传输协议，提供40Gbps高速带宽
- 可作为Mac mini外置存储扩展方案
- 可作为Mac OS系统启动盘
- 针对游戏玩家，可将电脑大型游戏程序安装至该设备，实现零延迟运行

## USB 4传输协议

- 采用 USB4 协议，实现高达 40Gbps 的数据传输带宽
- 4个M.2 SSD时，实际读/写速度可达 3257MB/s（Samsung 990PRO 4TB *4）
- 单硬盘时，读取速度可达 1608MB/s（Samsung 990PRO 4TB *1）
- 无论是多硬盘并行还是单硬盘运行，都能展现卓越性能，大大缩短后期制作工作流时间

**测试条件**：在D4 SSD设备中安装4块三星（Samsung）990 PRO 4TB M.2固态硬盘，与Mac mini（搭载Apple M4芯片，系统版本15.3.2）连接，并配置为RAID 0阵列。使用AJA系统测试软件进行性能评估，测得读取速度为3257MB/s，写入速度为3192MB/s。

## 全面兼容各种协议

- 全面兼容雷电3/4/5接口，带来疾速传输体验
- 支持USB4/3.2/3.1/3.0全协议，具有卓越的跨平台兼容性
- 能够无缝融入各类使用场景，满足不同用户的多样化需求

**备注**：部分Windows电脑的Thunderbolt 3接口存在对USB4协议支持不完整的情况，可能会引发D4 SSD连接至此类Thunderbolt 3接口时无法正常识别（不出盘）的问题。为解决此问题，建议您将D4 SSD转接至电脑上的其他USB接口进行连接使用。

## 32TB超大容量存储

- 支持安装多达 4 个M.2 SSD
- 单个硬盘最大容量可达 8TB（更大容量M.2 SSD待验证）
- 最高可提供 32TB 的海量存储空间，充分满足各种大规模的数据存储需求
- 备注：D4 SSD本身不提供阵列功能，而仅提供单盘工作模式。若用户需要组建阵列以提升数据存储的性能和安全性，可以借助第三方软阵列管理工具来实现

## 小巧便携，静音设计融入家居

- 采用M.2 NVMe SSD作为存储介质，体积小巧，重量轻，便于携带
- 创新的上下对流主动散热设计与静音风扇等多重高效散热设施
- 确保在满负荷运行时依然保持低温和静音状态
- 待机模式下噪音不超过19dB(A)，为您营造舒适的家居环境

## 支持宽电压输入12-20V

- 支持12V-20V宽电压输入，兼容市面上主流电子设备的标配电源规格
- 包括笔记本电脑、外接显示器、小型台式机/迷你电脑及影音设备等
- 其标配电源通常为19V（电流≥1.5A）即可适配
- 此特性让用户在差旅出行时，无需额外携带专用适配器，有效减轻行李负担

## 多重安全保障

### 供电保护

- 采用先进电源保护设计
- 若接入不匹配电源，内置保护机制会立即启动
- 防止电流过大或电压不稳对设备及硬盘造成损害

### 上电恢复功能

- 具备电源上电恢复记忆功能
- 正常关机在市电恢复时保持关机
- 异常断电后，市电恢复时自动启动
- 适合与服务器、NAS 等设备连接，实现无人值守自动化管理

## 智能温控，高效散热且静音

- 搭载第二代智能温控风扇系统，在高效散热的同时确保极致静音
- 有效延长设备及硬盘的使用寿命
- 内部配备4个精确的温度监测点，实现对温度的精准检测与控制
- 风扇转速随硬盘温度智能调节，确保硬盘工作在适宜温度范围
- 内部结构优化，提升风压，降低硬盘工作温度，减少部件与硬盘的共振
- 满负荷运行也能保持低噪音，营造宁静工作环境

## 自动数据备份

- 通过 TPC Backupper 这个友好的 Windows PC 备份工具，实现定时备份功能
- 将设备连接电脑，安装客户端并设置好任务，即可把 Windows PC 上的文件夹、磁盘分区备份到铁威马 USB 设备或 NAS 网络存储服务器上
- 支持增量与差异备份策略，适用于 Windows 8/8.1/10/11 系统，为重要数据提供可靠保护

## 手机数据自动备份

- 专为TDAS系列产品精心打造了TDAS mobile APP，实现与TDAS设备的无缝对接
- 只需简单连接手机，即可自动备份手机里的珍贵照片和视频
- 全面兼容iOS 15.6及以上、Android 11及以上系统
- 日常生活中无需打开PC，可以直接通过TDAS mobile轻松管理TDAS设备内的所有资料
- 支持文件的复制、删除、重命名及查看文件详情等操作，让生活更加便捷高效

## 应用场景

本产品具有广泛的适用性，可充分满足多样化的存储需求场景：

- 媒体创作
- 影视制作
- Mac mini的扩容需求
- Mac OS启动盘
- 日常的移动存储场景
