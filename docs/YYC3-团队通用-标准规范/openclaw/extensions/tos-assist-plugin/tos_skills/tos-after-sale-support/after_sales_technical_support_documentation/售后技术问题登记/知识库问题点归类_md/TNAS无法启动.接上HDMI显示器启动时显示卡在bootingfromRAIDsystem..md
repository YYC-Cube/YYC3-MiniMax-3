# TNAS 无法启动. 接上 HDMI 显示器启动时，显示卡在“booting from RAID system”.

通常是 TNAS 内的某个盘的头部启动分区异常。

如果您有多个盘，那么您每次启动应该有概率使用其它正常盘的启动分区。

您也可以考虑预约工程师远程帮您修复问题. 您可以考虑自行恢复出厂设置以修复问题:

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=423
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=241
