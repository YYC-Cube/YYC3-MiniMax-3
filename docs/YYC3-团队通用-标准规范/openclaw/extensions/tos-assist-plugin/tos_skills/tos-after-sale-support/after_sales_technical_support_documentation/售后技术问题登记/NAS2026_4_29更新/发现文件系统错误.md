# 发现文件系统错误.

**关键词：TOS、控制面板、HTTPS、文件系统错误.**

**解决方案：**

文件系统错误修复方法：

修复教程：
- 中文教程：https://forum.terra-master.com/cn/viewtopic.php?t=1691
- 英文教程：https://forum.terra-master.com/en/viewtopic.php?t=2575

简要步骤：
1. 备份重要数据（修复过程存在数据风险）
2. 前往 TOS Web > 控制面板 > 存储管理 > 卷
3. 选择问题卷，点击「检查文件系统」或「修复」
4. 等待修复完成（时间取决于卷大小和错误程度）
5. 若修复失败或问题反复出现：
   → 检查硬盘健康状态（SMART检测、坏块扫描）
   → 可能是硬盘物理损坏，建议更换硬盘
