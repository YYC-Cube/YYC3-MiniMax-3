# D5 300在Mac OS 系统中安装RAID Manager 后，RAID Manager 识别不到硬盘

适用型号
D5-300

故障现象
在Mac OS 系统中安装RAID Manager 后，RAID Manager 识别不到硬盘；但在磁盘工具里显示有识别到硬盘。

故障原因
安装RAID Manager 的过程中，可能被系统安全性与隐私阻止了RAID Manager 的安装。

解决对策
1.先卸载已安装的RAID Manager，前往>应用程序>选择>RAID Manager，将其移到废纸篓。

2.安装RAID Manager，点击运行RAID Manager，弹出一个安全性与隐私提示，请选择【好】。

选中电脑左上角的“苹果”标识，并前往 系统偏好设>安全性与隐私>将已阻止使用“RAID Manager’’,选择【仍要打开】

完成后会提示，请选择【打开】，按照提示步骤完成RAID Manager 安装。

3.若按以上两步操作后，RAID Manager 仍无法识别到硬盘，请选中电脑左上角的“苹果”标识，并前往 系统偏好设置>安全性与隐私>隐私>完全磁盘访问权限 >应用程序>选择RAID Manager【打开】。
