# 无法向RAID1添加盘.

**关键词：TOS、控制面板、存储池、RAID、插入更多硬盘**

**解决方案：**

原因：RAID1的成员数量在创建时即固定，TOS控制面板不支持在线修改。

说明：
- 若使用2块磁盘创建RAID1，成员数量始终为2块，无法添加更多盘
- RAID1设计为镜像冗余，磁盘数量固定

扩展存储方案：
方案一：备份数据后重建（数据会丢失，需先备份）
1. 备份所有数据
2. 删除当前RAID1存储池和卷
3. 插入更多硬盘，创建新的RAID类型：
   - RAID5（至少3块盘，1块冗余）
   - RAID6（至少4块盘，2块冗余）
   - TRAID（灵活扩展，推荐）
4. 恢复数据

方案二：保留RAID1，新增独立存储池
1. 插入新硬盘
2. 创建新的存储池（可选用不同RAID类型）
3. 新数据存到新存储池，旧数据保留在RAID1
