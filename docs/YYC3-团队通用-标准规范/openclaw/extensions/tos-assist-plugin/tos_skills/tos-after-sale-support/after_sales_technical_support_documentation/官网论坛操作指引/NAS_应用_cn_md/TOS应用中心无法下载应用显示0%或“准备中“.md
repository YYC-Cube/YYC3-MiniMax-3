# TOS应用中心无法下载应用，显示0%或“准备中“

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=1570&sid=2830252e3f49fda663c79a41b721ea52

---

故障排除

适用机型
所有 TNAS型号

原因分析
该现象通常是网络配置不正确或文件系统异常引起：
1.获取不到网关，状态栏甚至显示红色的“未连接”
2.路由器自动分配的DNS无法解析出下载服务器的域名
3.文件系统为只读文件系统

解决方法
1. 重新获取网关
登录ssh（如何登录），输入以下指令以手动添加一个默认网关(以192.168.1.1为例，具体请以路由器为准）:
代码： 全选route add default gw 192.168.1.1 eth0

再查看状态栏，若“未连接”变为“已连接”则代表TOS网络已经可用。

2. 更改 DNS 服务器，进入TOS的“控制面板-网络设置-网络接口”，选中正在使用的 LAN，点“编辑”，把 DNS服务器地址改为 8.8.8.8,然后重启设备。


3. 如发现无法安装任何应用的同时，还无法将任何数据传入 NAS ，无法新建、修改文件或目录，提示“只读”、“无法写入”、“无写入权限”等，可以判断该文件系统为只读文件系统。
请将 NAS中存储的数据导出，进入控制面板删除卷和存储池，重新创建新的存储池和卷。

4. 若存在其它未知原因，请联系铁威马技术支持获取离线应用安装包，使用本地安装方式。
