# 如何把小容量硬盘替换成大容量硬盘，并且实现数据迁移(保留数据)?

**关键词：TOS、控制面板、存储池、RAID、小硬盘换大硬盘、**

**解决方案：**

方案一：支持数据保留的替换（无需备份）

适用RAID类型：TRAID（2盘及以上）、TRAID+、RAID1、RAID5、RAID6、RAID10

操作步骤：
1. 逐一取出旧硬盘，插入新硬盘（每次只操作一块）
2. 前往 TOS Web > 控制面板 > 存储管理 > 存储池
3. 对每块新硬盘执行「修复」或「替换」操作，等待数据重建完成
4. 所有硬盘替换完成后，执行「扩容」操作，存储空间将自动增加
5. ⚠️ 全程保持至少1块含当前系统的盘在NAS内，以维持系统运行

方案二：不支持数据保留的替换（需备份）

适用RAID类型：RAID0、JBOD、Single等

操作步骤：
1. 备份所有数据到外部存储
2. 删除卷和存储池（数据将被清除）
3. 取下旧硬盘，换上新硬盘
4. 创建新存储池（选择所需RAID类型）
5. 创建卷，并将备份的数据恢复到新卷
