# D1 SSD 产品介绍

## 产品概述

D1 SSD 是一款三重防护 SSD 硬盘盒，专为需要在恶劣环境下安全存储和高速传输数据的用户设计。

## 核心特性

### 坚固装甲保护

- 一体成型航空级铝合金装甲
- 具备 IP67 防护等级
- 防水、防尘
- 能承受 1.2 吨压力
- 在恶劣条件下保护数据安全

### 协议级高速传输

- 采用 USB 3.2 Gen2 和 128b/132b 编码
- 速度高达 1020 MB/s
- 配备 UASP 协议提升效率
- 支持 TRIM 指令以维持长期性能

### 先进的被动散热

- 采用全金属散热片设计
- 散热面积提升 2.5 倍，实现高效散热
- 无风扇且静音运行
- 确保持续稳定性能，杜绝因过热导致降频

### 通用即插即用

- 广泛兼容最高 8TB 的 PCIe 3.0/4.0/5.0 M.2 NVMe SSD
- 在 Windows、macOS、Linux、Android 和 iOS 系统上均可免驱使用

### 专属移动备份

- 配合官方 TDAS App 使用
- 可轻松安全地将手机中的照片和视频备份至私有驱动器
- 释放云端空间

### 电路级保护

- 内置保护芯片
- 可防止短路、电压浪涌和静电干扰
- 确保数据传输稳定

### 紧凑多用

- 便携式设计，适合移动使用
- 可作为扩展、启动盘或在现场环境中进行数据传输的多功能工作站

### 专业级防护

- 随附高级便携包
- 抗震耐压
- 可在通勤和旅行途中保护您的数据安全

### 三重硬件保护

- 采用专用的三重屏蔽芯片
- 能在毫秒级时间内监控并应对电涌、短路和静电放电等威胁
- 确保数据的绝对完整性和传输稳定性
