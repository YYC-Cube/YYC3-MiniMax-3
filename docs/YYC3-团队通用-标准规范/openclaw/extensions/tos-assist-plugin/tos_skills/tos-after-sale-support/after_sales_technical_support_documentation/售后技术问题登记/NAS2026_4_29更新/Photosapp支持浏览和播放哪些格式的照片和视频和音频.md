# Photos app支持浏览和播放哪些格式的照片和视频和音频？

**关键词：TOS、TNAS、APP**

**解决方案：**

如果是TNAS mobile V3.5 ，
目前支持音频格式（10 种）：aac、flac、wav、ogg、m4a、mp3、amr、mid、ape、wma，与TNAS mobile V3.4 一致
目前支持视频格式（13种）：MP4、M4V、MKV、MOV、FLV、MPG、WEBM、TS、MPEG、VOB、3GP、3G2、QT
目前支持图片格式（11种）：JPG、JPEG、BMP、GIF、PNG、ICO、WEBP、TIFF、HEIC、HEIF、TIF(V3.5 支持的图片格式与 V3.4 一致)
如果是TNAS mobile V3.4 
支持视频格式（7种）：MP4、M4V、MKV、MOV、FLV、MPG、WEBM
支持音频格式与TNAS mobile V3.5 一致
支持图片格式与TNAS mobile V3.5 一致
TNAS mobile V3.5 比 V3.4 新增6种格式支持，对高帧率（120 FPS）和高分辨率（8K）视频的兼容性大幅提升，播放更稳定、流畅。
