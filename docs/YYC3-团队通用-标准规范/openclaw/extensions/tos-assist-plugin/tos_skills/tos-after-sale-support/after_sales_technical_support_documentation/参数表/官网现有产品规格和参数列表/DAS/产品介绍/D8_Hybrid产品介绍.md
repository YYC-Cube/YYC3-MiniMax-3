# D8 Hybrid 产品介绍

## 产品概述

D8 Hybrid 是一款创新的 8 盘位混合架构存储设备，结合了大容量与高性能的优势，为专业用户和企业用户提供理想的存储解决方案。

## 核心特性

### 混合架构，高达 152TB 海量容量

- 创新 8 盘位设计
- 搭载 4 块 3.5 英寸 SATA 硬盘 / 固态硬盘与 4 块 M.2 NVMe 固态硬盘
- 兼顾超大容量与极速性能
- 单盘支持最高 30TB 硬盘、8TB 固态硬盘
- 总容量可达 152TB（30TB×4 + 8TB×4）

### 手动冷热数据分层

- 完全自主掌控数据存储策略
- 将高频使用的 "热数据" 存于 NVMe 固态硬盘，享受极速响应
- 将低频使用的 "冷数据" 存于大容量硬盘，节省成本
- 实现性能与开销双重优化

### 10Gb/s 高速，真实场景性能

- 采用 USB 3.2 Gen2 接口，带宽 10Gb/s
- 实际读取速度最高可达 980MB/s（NVMe 固态硬盘）
- 实际读取速度最高可达 521MB/s（SATA 固态硬盘）
- 完美适配 4K 视频制作与大文件传输

### 免工具、安全智能设计

- 支持免工具硬盘托架，安装维护更便捷
- 配备独特按压式自动锁扣，确保硬盘稳固连接
- 智能风扇散热静音，提供良好的工作环境
- 断电恢复功能可配合 NAS 或服务器实现稳定无人值守运行

### 完整备份与跨平台方案

- 配备 Windows 版 TPC Backupper 备份软件
- Mac 用户可使用 Time Machine 进行备份
- USB-C 接口广泛兼容 PC、Mac 与 NAS 设备
- 轻松扩展存储空间，满足多样化需求
