# Surveillance Mangager有迁移录像功能吗?

**关键词：TOS、共享文件夹、摄像头录像移到外置硬盘**

**解决方案：**

不支持专用的录像迁移功能。

替代方案：手动迁移录像文件
1. 前往 TOS Web > 文件管理
2. 找到Surveillance Manager的录像存储目录（通常在共享文件夹内）
3. 手动将录像文件复制到目标位置（如外接硬盘、其他共享文件夹等）
4. 时间线功能会根据摄像头自动查找录像文件
5. 确保迁移后文件权限正确，即可在Surveillance Manager中正常访问移动后的录像

注意事项：
- 迁移前建议暂停录像，避免文件正在写入导致损坏
- 大量录像文件迁移可能耗时较长，请耐心等待
- 迁移后建议在Surveillance Manager中验证录像是否可正常播放
