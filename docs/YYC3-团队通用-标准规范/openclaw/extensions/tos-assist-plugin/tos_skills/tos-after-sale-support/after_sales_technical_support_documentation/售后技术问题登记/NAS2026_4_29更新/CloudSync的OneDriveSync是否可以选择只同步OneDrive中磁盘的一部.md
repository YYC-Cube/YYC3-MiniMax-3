# CloudSync 的 OneDrive Sync是否可以选择只同步 OneDrive 中磁盘的一部分?

**关键词：TOS、CloudSync只步几个文件夹怎么设置**

**解决方案：**

支持。

CloudSync的OneDrive同步可以灵活配置：
1. 在创建或编辑CloudSync任务时，可以选择同步整个OneDrive或指定文件夹
2. 支持选择OneDrive中的特定目录进行同步，不必同步全部内容
3. 支持双向同步或单向同步（上传/下载）模式选择

配置路径：TOS Web > 应用中心 > CloudSync > 创建任务 > OneDrive > 选择同步目录
