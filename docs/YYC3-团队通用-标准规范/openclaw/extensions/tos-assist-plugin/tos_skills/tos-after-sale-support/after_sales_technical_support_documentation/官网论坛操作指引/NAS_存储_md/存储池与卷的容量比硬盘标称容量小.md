# 存储池与卷的容量比硬盘标称容量小？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3430&sid=2853efb328304e05736fc85f61407238

硬盘厂家为了便于生产和计算，市面上的硬盘在标称容量的时候均是以 10进制计算的，如：1KB=1000B，1MB=1000KB，1GB=1000MB，1TB=1000GB 依次类推 。1TB 的硬盘其实是 1,000,000,000,000B。

而电脑系统中计算的存储容量是2进制的计算（2^10 = 1024），也就是说 1KB=1024B，1MB=1024KB，1GB=1024MB，1TB=1024GB 依次类推。

当硬盘被系统分区格式化后，系统将按照2进制来计算硬盘的可用容量，那么由10进制换算为2进制后，1TB(10进制）= (1000GB x1000 x1000 x1000)/(1024 x 1024 x1024) = 931GB（2进制）。

由此看出，10进制的硬盘容量换算为2进制后，显示的可用容量是明显要小的，这属于正常现象。
