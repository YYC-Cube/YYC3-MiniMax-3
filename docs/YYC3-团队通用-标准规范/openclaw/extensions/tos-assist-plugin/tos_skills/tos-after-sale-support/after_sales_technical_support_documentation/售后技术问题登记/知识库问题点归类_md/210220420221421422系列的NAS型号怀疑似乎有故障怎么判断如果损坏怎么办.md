# 210/220/420/221/421/422/系列的 NAS 型号怀疑似乎有故障。怎么判断？如果损坏怎么办？

判断硬件是否损坏：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=4837
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=3553
  

如果损坏：

1. 您可以通过 Linxu 电脑或 Linux 虚拟机的 mdadm&LVM 工具访问硬盘数据。
   
2. 您可以通过一些专业硬盘工具读取数据。
   
3. 您可以考虑购买新的 TNAS 继续使用，请注意：由于新型号使用的系统需要的存储格式不同于旧盘的格式，因此无法直接使用旧盘。您可以购买具有M.2 槽位的新型号或 SATA 槽位更多的新型号，同时多购置 1 个 HDD/SSD 用于安装 TOS6。安装 TOS6 时请仅在 NAS 上插入新的 HDD/SSD。安装 TOS6 成功后，请联系我们帮您调整系统以读取旧 HDD 上的数据。
