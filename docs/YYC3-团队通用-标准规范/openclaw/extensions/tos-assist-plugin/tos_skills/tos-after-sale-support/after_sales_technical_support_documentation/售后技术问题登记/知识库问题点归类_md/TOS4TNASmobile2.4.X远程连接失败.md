# TOS4, TNAS mobile 2.4. X 远程连接失败。

TOS 4 的 TNAS. Online 远程访问服务与 TNAS mobile 2.4. X 版本之间存在问题。由于版本太旧，我们目前无法排查出故障原因。

我们建议切换到更稳定的 DDNS 解决方案进行远程访问。您可以在 TNAS 设备上配置 DDNS，然后在移动应用程序中使用分配的 DDNS 域名建立连接.

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=433
