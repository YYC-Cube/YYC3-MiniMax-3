# TNAS使用出现了异常. 带着盘启动时, 无法启动系统. 不带着盘启动时, 显示"未找到硬盘".

**关键词：TOS、TNAS、初始化、格式化、硬盘又显示没找到硬盘、**

**解决方案：**

原因：硬盘上的TOS系统分区已损坏，导致系统无法从硬盘启动，自动进入初始化模式。

修复步骤：
1. 保持初始化页面运行，不要关闭
2. 将TNAS上使用的硬盘热插到设备中（设备运行时插入）
3. 初始化页面应检测到硬盘，按页面指引重新初始化系统
4. ⚠️ 重要：如果页面提示「删除/格式化」，请立即停止操作
5. 联系人工客服确认操作步骤，避免数据丢失

若重新初始化后问题仍存在：
- 硬盘可能存在物理损坏，建议检测SMART值和坏道
- 联系售后更换硬盘
