# 无法访问 Plex 服务 (Plex 服务不工作)

- 可能是旧版的缓存让更新失败，请清理浏览器缓存再尝试下载。（可能性最高）
- 可能是 TOS 版本低，应用中心无法检测到正确的应用。请更新 TOS，然后再下载安装 app。请尽可能使用 APP Center 提供的 Plex 版本。
- 可能是旧的版本与新的版本不兼容，请尝试删除 `/User/plex` 或 `/User/emby`，然后启动 app 来重新生成配置文件。
- 可能是卷容量不足了，您可以尝试适当移动或删除部分文件。
- 可能是文件系统错误，请尝试检查修复可能的错误：
  
    - **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=2575
      
    - **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=1691
