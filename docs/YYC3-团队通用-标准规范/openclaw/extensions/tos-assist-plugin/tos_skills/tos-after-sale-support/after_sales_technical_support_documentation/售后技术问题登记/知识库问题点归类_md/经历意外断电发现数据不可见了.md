# 经历意外断电，发现数据不可见了.

很可能是文件系统错误，参考这个尝试修复文件系统错误：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=2575
  
- **[CN]** https://forum.terra-master.com/en/viewtopic.php?t=2575
  

如果修复失败，或者修复后数据依然不可见，很可能是盘存在异常。建议您使用 Smart 工具和坏道扫描工具扫描并检查下盘。如果您曾尝试重装过 TOS 以试图解决问题，由于重装 TOS 会重置权限，请前往 TOS 网页－控制面板－共享文件夹检查权限设置。
