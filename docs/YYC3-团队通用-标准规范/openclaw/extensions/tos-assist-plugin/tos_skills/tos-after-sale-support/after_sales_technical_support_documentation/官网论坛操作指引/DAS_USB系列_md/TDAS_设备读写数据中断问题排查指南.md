# TDAS 设备读写数据中断问题排查指南

适用机型
D2 - 320、D4 - 320、D4-320U、D6 - 320、D5 Hybrid、D8 Hybrid、D9-320

故障现象
当 TerraMaster USB TDAS 存储设备已完成正确安装后，在执行文件读写操作时，频繁出现读写过程随机性中断的情况。

常见原因及对应解决方案
我们针对该故障，在不同品牌 Windows 电脑上完成了多轮验证与观察，梳理出以下两类高频诱因及具体排查方法，可按步骤逐步操作。

原因 1：电脑 USB 接口或连接配件相关问题
部分 Windows PC 及 Windows mini PC 存在 USB 接口信号弱、USB 驱动不兼容，或使用非原装连接配件等情况，均会导致设备读写数据时随机性中断。

1.调整 USB 接口：优先更换电脑后置 USB 接口使用（后置接口供电和信号稳定性通常优于前置）；若问题仍存在，可换用另一台正常电脑测试，排除原电脑硬件问题。
借助转接设备：可搭配一款 10Gbps 规格的 USB – A/USB – C 分线器，选择 0.3 米或 0.5 米的短线款转接使用，减少信号传输损耗。

2.更新适配驱动：若电脑安装的是公版 USB 驱动，易与主板不兼容，建议登录电脑品牌官方网站，下载并安装与电脑型号完全匹配的专用 USB 驱动。

3.更换原装 USB 线：非原装 USB 线可能存在线芯质量差、传输稳定性不足等问题，建议更换设备配套的原装 USB 线。

原因 2：旧硬盘与 RAID 功能不兼容
带有 RAID 功能的 TDAS 设备，若接入的是预先存储有数据的旧硬盘，可能因硬盘兼容性、遗留数据干扰等因素，引发读写中断。

1.尝试更换新硬盘：直接更换全新硬盘接入设备，测试读写操作是否恢复正常，初步判断是否为旧硬盘本身的问题。

2.重建 RAID 阵列并格式化（注意：此操作会清空硬盘所有数据，务必提前备份旧硬盘内的重要数据）：先将旧硬盘的数据完整备份，再将其重新安装到 TerraMaster TDAS 设备中；随后在设备中创建新的 RAID 阵列，并对硬盘执行格式化操作，消除旧数据和旧配置带来的兼容性影响。
