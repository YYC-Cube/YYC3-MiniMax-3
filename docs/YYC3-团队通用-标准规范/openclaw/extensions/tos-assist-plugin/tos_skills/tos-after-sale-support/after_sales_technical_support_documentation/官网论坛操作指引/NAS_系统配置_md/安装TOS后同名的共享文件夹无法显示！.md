# 安装TOS后，同名的共享文件夹无法显示！

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3393&sid=91960374e52a8fba318a0aab4711ff91

故障现象
使用多块安装过TOS的硬盘一起安装TOS，不同的卷中都有一个名称相同的文件夹，访问时只能看到其中一个。

适用机型
所有 TNAS 型号

TOS 5解决方法
假如卷1和卷2都有public共享文件夹，卷2中的public共享文件夹无法显示：
1.png
1.前往控制面板>任务计划>创建一个自定义计划，用户选择超级管理员用户，命令脚本填写以下内容：
代码： 全选mv /Volume2/public /Volume2/public1
代码： 全选/etc/tos/scripts/mntdata
2.png
3.png
2、启用任务后执行一次任务，执行完后刷新页面重新查看改名后的共享文件夹。
4.png
3、重新编辑改名后的共享文件夹权限。

TOS 4 解决方法
假如卷1和卷2都有public共享文件夹，无法查看卷2中的public共享文件夹的数据：
1、前往TOS控制面板>共享文件夹>高级>选择恢复到无法看到的共享文件夹所在的卷
5.png
2、选择恢复到卷2，然后将public共享文件夹中的数据复制或者剪切到其他共享文件夹。
3、重新恢复到卷1。
