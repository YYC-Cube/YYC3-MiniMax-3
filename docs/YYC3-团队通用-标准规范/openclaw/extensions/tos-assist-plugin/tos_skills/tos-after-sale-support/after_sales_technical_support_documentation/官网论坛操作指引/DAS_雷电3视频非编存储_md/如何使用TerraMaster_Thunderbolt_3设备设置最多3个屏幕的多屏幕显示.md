# 如何使用TerraMaster Thunderbolt 3设备设置最多3个屏幕的多屏幕显示？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=299

操作指引

适用机型：
TerraMaster TD2雷电3 / D2雷电3（D2-330）
TerraMaster D4雷电3（D4-330）
TerraMaster D5雷电3（D5-330）
TerraMaster D8雷电3（D8-330）

由于配备了DP接口和Thunderbolt 3接口，因此TerraMaster Thunderbolt存储设备最多支持3个屏幕的4K多屏幕显示。
displayconnection.png
设置多屏指南

1.将TerraMaster Thunderbolt设备上的Thunderbolt 3接口之一连接到计算机上的Thunderbolt 3接口；
2.将TerraMaster Thunderbolt设备上的另一个Thunderbolt 3接口连接到4K监视器。这要求您的minitor配备Thunderbolt 3接口，如果没有，您可以购买一个额外的USB Type-C转HDMI适配器；
3.将TerraMaster Thunderbolt设备上的Displayport接口连接到4K监视器。这需要您的Minitor配备Displayport接口，或者您可以购买一个额外的Displayport转HDMI适配器；

现在，你就拥有3个屏幕显示了。
