# TRAID 迁移到 TRAID+ 操作指南

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4397&sid=2853efb328304e05736fc85f61407238

适用机型：4盘位及以上的TNAS机型

适用版本：TOS 6.x

TRAID+介绍:
TRAID+不仅继承了TRAID的所有优秀特性，更在冗余保护上实现了突破。传统的 TRAID 提供1块硬盘的故障冗余，而 TRAID+ 则将此提升至2块，为用户数据提供更坚实的保护。这一改进使得 TRAID+ 成为寻求更高级别数据安全的用户的理想选择。

前置条件：
若想要从 TRAID 迁移至 TRAID+，您的阵列需符合以下必要条件：必须至少拥有三块最大容量的磁盘。举例来说，如果您的当前 TRAID 阵列中混合配置了 1TB 和 2TB 的磁盘，那么要实现向 TRAID+ 的升级，就需要确保至少有3块 2TB 的磁盘存在。

一、TRAID阵列中最大容量的磁盘数量已达到3块或超过3块

操作步骤：
1、向设备中插入一块新磁盘，其容量需大于或等于当前阵列中最大容量磁盘的容量。
2、编辑存储池，选择“阵列在线迁移”功能以启动迁移过程。

案例分析：
用户A场景：若TRAID阵列由3块1TB磁盘组成，此时需额外插入一块容量大于或等于1TB的磁盘，以满足迁移条件。
用户B场景：若TRAID阵列包含1块1TB磁盘和3块2TB磁盘，由于2TB磁盘是阵列中的最大容量磁盘且数量已达3块，因此需插入一块容量大于或等于2TB的新磁盘，即可进行TRAID+迁移。

二、TRAID阵列中最大容量的磁盘数量已有2块

操作步骤：
1、向设备中插入一块新磁盘，其容量需等于当前阵列中最大容量磁盘的容量。
2、编辑存储池，选择“为阵列添加磁盘”功能将磁盘添加至阵列中。
3、再次向设备中插入一块新磁盘，其容量需大于或等于当前阵列中最大容量磁盘的容量。
4、此时，TRAID阵列中最大容量的磁盘数量已达到3块。再次编辑存储池，选择另1块磁盘，选择“阵列在线迁移”功能以启动迁移过程。

案例分析：
用户C场景：若TRAID阵列由2块1TB磁盘组成，此时要向阵列中添加1块1TB磁盘，使阵列中最大容量磁盘达到3块。添加完毕后，需额外插入一块容量大于或等于1TB的磁盘，以满足迁移条件。
用户D场景：若TRAID阵列包含2块1TB、2块 2TB 磁盘，此时要向阵列中添加1块2TB磁盘，使阵列中最大容量磁盘达到3块。添加完毕后，需额外插入一块容量大于或等于2TB的磁盘，以满足迁移条件。

三、TRAID阵列中最大容量的磁盘数量已有1块

操作步骤：
1、向设备中插入一块新磁盘，其容量需等于当前阵列中最大容量磁盘的容量。
2、编辑存储池，选择“为阵列添加磁盘”功能将磁盘添加至阵列中。
3、再次为阵列添加磁盘：待同步完成后，重复一次第2步操作。
4、再次向设备中插入一块新磁盘，其容量需大于或等于当前阵列中最大容量磁盘的容量。
5、此时，TRAID阵列中最大容量的磁盘数量已达到3块。再次编辑存储池，选择另1块磁盘，选择“阵列在线迁移”功能以启动迁移过程。

案例分析：
用户E场景：若TRAID阵列由1块1TB磁盘组成，此时要向阵列中依次添加2块1TB磁盘，使阵列中最大容量磁盘达到3块。添加完毕后，需额外插入一块容量大于或等于1TB的磁盘，以满足迁移条件。
用户F场景：若TRAID阵列包含1块1TB、1块 2TB、1块 4TB 磁盘，此时要向阵列中依次添加2块4TB磁盘，使阵列中最大容量磁盘达到3块。添加完毕后，需额外插入一块容量大于或等于4TB的磁盘，以满足迁移条件。
