# TDAS 型号产品，按下电源按钮后风扇转动旋即停止的原因及解决办法

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4767

对于 D2-320、D4-320、D5 Hvbrid、D8 Hvbrid 以及 D6-320 TDAS 型号的产品，当您按下电源按钮时，风
扇转动但随即停止，可能的原因及解决办法如下:

正常情况
未连接 USB 或无硬盘:启动时，若 TDAS 设备未连接到计算机的 USB 接口，或者尚未安装硬盘，出于降低功耗和延长使用寿命的考虑，设备会进入待机模式，从而出现风扇转动一下就停止的情况。
工作逻辑:TDAS 设备的风扇和硬盘指示灯(HDD_LED)的工作逻辑是，只有在硬盘(HDD)被计算机识别时才会启动运行。当 TDAS 设备处于待机状态或硬盘进入睡眠模式，风扇和指示灯便会停止工作。

故障情况
硬盘抽屉安装问题:硬盘抽屉可能没有安装到位，这可能会影响设备的正常启动和运行，导致风扇异常转动。
USB 接口兼容性问题:US8 线缆与计算机的 USB-C接口之间可能存在阻抗兼容性问题，这可能会导致
设备无法正常通信和工作，进而使风扇出现转动旋即停止的现象。

解决办法
检查硬盘安装:手动向内按压硬盘抽屉，确保其安装牢固，若不确定安装是否正确，可访问官方网站
