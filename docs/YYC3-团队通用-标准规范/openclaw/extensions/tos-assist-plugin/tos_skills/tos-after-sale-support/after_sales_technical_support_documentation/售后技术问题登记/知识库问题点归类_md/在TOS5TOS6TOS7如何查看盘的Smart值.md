# 在 TOS5/TOS6/TOS7, 如何查看盘的 Smart 值？

请您前往 TOS 网页-控制面板-盘-S.M.A.R.T，对盘执行一次 Quick test。完成测试后，请展开查看S.m.a.r.t info。同时，您可以导出S.m.a.r.t info csv 文件，将它喂给通用 AI 大模型，详细了解各项属性数值所代表的含义及整体情况。

Please go to the TOS website > Control Panel > Disks > S.M.A.R.T. and run a Quick Test on the disk. Once the test is complete, expand the view to see the S.M.A.R.T. information. You can also export the S.M.A.R.T. information as a CSV file and feed it into a general-purpose AI model to gain a detailed understanding of what each attribute value represents and the overall status of the disk.
