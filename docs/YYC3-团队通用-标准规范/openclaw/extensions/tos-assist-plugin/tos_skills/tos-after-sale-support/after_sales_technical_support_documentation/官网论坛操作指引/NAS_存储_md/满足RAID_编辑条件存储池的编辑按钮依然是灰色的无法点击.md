# 满足RAID 编辑条件，存储池的编辑按钮依然是灰色的，无法点击？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1583&sid=2853efb328304e05736fc85f61407238

故障排除

适用机型
所有TNAS型号

适用版本
TOS 4.1.x ~ TOS 4.2.x

原因分析
更换故障硬盘或增加新的硬盘，且满足容量条件后，存储池中的编辑按钮是灰色，新的硬盘不能恢复或加入到 RAID中。可能是您硬盘容量与其他硬盘有细微差异，系统判断该硬盘与 RAID的其他硬盘不匹配，导致无法加入。

解决办法
1.进入控制面板>存储池中,然后用您的新硬盘单独创建一个新的 Single类型存储池
2.删除刚刚新创建的存储池
3.登录 SSH终端，并且切换到 root用户 如何登录 SSH终端？
4.输入以下指令以观察 RAID和各硬盘的关系：
代码： 全选lsblk
5.最后，执行以下命令以将新硬盘添加到 RAID中：
“sd[a-z]4”代表硬盘分区；“a-z”代表硬盘的序号，你需要确定新加入的硬盘的序号；“4”代表第四个分区，是关键的数据分区；“md0”代表存储池1，如果您要编辑的是存储池2，请改为输入“md1”。
代码： 全选mdadm -a /dev/md0 /dev/sd[a-z]4
