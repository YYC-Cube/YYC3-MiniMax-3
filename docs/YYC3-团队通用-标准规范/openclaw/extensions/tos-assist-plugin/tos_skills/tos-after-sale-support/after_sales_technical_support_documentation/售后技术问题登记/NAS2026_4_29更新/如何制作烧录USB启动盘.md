# 如何制作/烧录USB启动盘.

**关键词：USB启动**

**解决方案：**

适用场景：
- 启动加载程序损坏，需要重制USB镜像
- 卡在UEFI Shell界面无法启动
- 内置USB的EFI文件夹丢失
- 需要USB恢复镜像

操作指南：
- 中文教程：https://forum.terra-master.com/cn/viewtopic.php?t=4399
- 英文教程：https://forum.terra-master.com/en/viewtopic.php?t=6433

简要步骤：
1. 准备一个空USB盘（建议8GB以上）
2. 下载对应机型的USB镜像文件
3. 使用镜像烧录工具（如Rufus、Etcher）烧录到USB盘
4. 将USB插入TNAS，开机并按提示操作
