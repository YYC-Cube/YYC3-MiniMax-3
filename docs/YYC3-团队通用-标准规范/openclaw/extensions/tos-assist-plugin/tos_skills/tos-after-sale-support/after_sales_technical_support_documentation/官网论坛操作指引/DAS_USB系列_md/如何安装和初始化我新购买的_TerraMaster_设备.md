如何安装和初始化我新购买的 TerraMaster 设备？我怎么开始？

适用机型:
TerraMaster 设备的用户手册并不会打印出来随新购买的设备一起提供。相反，快速安装指南、用户手册和常见问题解答等文档都放在网上，您需要访问特定的网站以便获得操作说明。我们提供了快速指南传单在设备包装内，您可以在该传单上找到网站地址，请在您的 web 浏览器中输入，然后按照网页上的指南开始使用您的设备。

如果你没有在你的包装上找到这样的传单，或者你只是错过了它。请访问以下链接开始。
