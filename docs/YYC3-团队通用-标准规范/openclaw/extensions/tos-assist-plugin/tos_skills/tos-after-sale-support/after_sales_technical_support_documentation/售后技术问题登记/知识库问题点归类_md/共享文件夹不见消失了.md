# 共享文件夹不见/消失了。

可能您同时有多个卷，多个卷上可能有同名的文件夹（特别是 public 文件夹）。而系统只会显示其中 1 个卷的共享文件夹。

请前往控制面板-共享文件夹-高级设置，尝试恢复到之前的卷。这个操作会影响 public/appdata 的位置，共享文件夹显示出来后，请再恢复原来的卷。

如果未起作用，请尝试尽可能禁用正在运行的服务和应用，并尝试重启以应用修改。

如果依然存在问题，可能是数据库错乱或其它问题，您可以尝试重置系统来修复它：

- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=241
