# TDAS 设备获取硬盘 S.M.A.R.T 信息的方法

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4855

S.M.A.R.T.（Self-Monitoring, Analysis and Reporting Technology）即自我监测、分析及报告技术，通过它可以了解硬盘的健康状况等重要信息。以下为您介绍在不同系统下，如何借助第三方软件让 TDAS 设备获取硬盘的 S.M.A.R.T 信息。

Windows 系统

1.	软件下载
您可使用 CrystalDiskInfo 7.0.0 x64 这款软件。您可以通过以下链接进行下载：https://crystaldiskinfo.en.softonic.com/ 。点击链接后，进入软件下载页面，根据页面提示，选择适合您系统的下载选项（如普通下载或高速下载），将软件安装包下载至您的电脑。

2.	安装软件
找到下载完成的安装包，通常在浏览器的下载文件夹中，双击安装包开始安装。安装过程中，按照安装向导的提示，点击 “下一步”，接受许可协议等，直至完成软件安装。

3.	获取 S.M.A.R.T 信息
打开安装好的 CrystalDiskInfo 软件，软件会自动识别连接到 TDAS 设备上的硬盘，并在主界面中直观地展示硬盘的各项 S.M.A.R.T 信息，包括硬盘温度、健康状态、各项指标的具体数值等。您可以根据这些信息判断硬盘的运行状况。

MacOS 系统

1.	SMARTReporter 软件使用

o	下载：访问下载链接https://www.corecode.io/smartreporter/ ，在页面中找到下载按钮，点击下载 SMARTReporter 软件安装文件。

o	安装：下载完成后，双击安装文件，按照系统提示完成软件安装。一般是将软件图标拖移到 “应用程序” 文件夹中。

o	获取信息：打开 SMARTReporter 软件，它会自动扫描连接到 TDAS 设备的硬盘，并显示硬盘的 S.M.A.R.T 数据。软件界面会以简洁明了的方式呈现硬盘的健康状态，以及各项 S.M.A.R.T 参数的详细情况。

2.	DriveDx 软件使用

o	下载：前往下载链接https://binaryfruit.com/ ，在该网站找到 DriveDx 软件的下载入口，点击下载软件安装包。

o	安装：找到下载好的安装包并打开，依照安装引导步骤完成软件安装。

o	获取信息：启动 DriveDx 软件，软件会识别 TDAS 设备连接的硬盘，展示全面的 S.M.A.R.T 信息。它不仅能呈现基本的健康状态，还能提供详细的数据分析和潜在问题预警，方便您全面了解硬盘状况。
