# FTP如何进行外网访问？（设置路由器端口转发方法）

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=749&sid=048e1debfe835733a17dfc037a28fa77

操作指引

在使用远程FTP访问功能前，需要在路由器设置端口转发，以下是在部分路由器上进行端口转发的方法（具体方法可以参考您的路由器厂商的使用教程），供您参考：
1.通过输入管理员的账号密码登录到路由器的控制页面；
2.找到端口转发模块，例如NAT。

3.单击“ NAT”以编辑TCP协议，NAS IP地址，FTP端口和被动端口并保存设置。
例如：192.168.1.2是您的TNAS的IP地址，21是FTP端口，55536-56559是被动端口。

4.您可以在登录页面上找到路由器的广域网IP地址（又名公网ip、WAN IP），然后可以通过在Windows File Explorer中输入：ftp://171.250.52.150来通过FTP服务远程访问TNAS。
   建议您在PC上下载并安装FTP客户端（如FileZilla、WinSCP等）以访问TNAS。

~

5.一般家庭用户的公网 IP常为运营商动态分配的，会不定期变更，导致无法持续连接。为了避免这样的麻烦，您可以将公网IP映射到一个DDNS域名，使用DDNS域名来代替IP地址进行访问。
