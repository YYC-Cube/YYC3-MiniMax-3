# TNAS 没有检测到我的硬盘？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=789&sid=ff7bc9dc8c8215f8ab568c189aad116e

故障排除

适用机型: 所有型号

如果您的 TNAS 无法检测到您的硬盘，或者在安装过程中 RAID 格式化失败（RAID格式化卡在10％到80％之间），请尝试以下操作：

1.  确保硬盘已固定在托盘正确的位置上； 从托盘上拆下硬盘，再次固定后将其插回 TNAS 。
2.  确保你的硬盘是健康的且在 兼容性列表中;
3.  从 TNAS 上卸下硬盘，使用 SATA 线连接电脑并使用第三方专业磁盘工具对其进行测试和修复；https://forum.terra-master.com/cn/viewt ... f=79&t=773，然后重试
4.  将硬盘连接电脑，进行低级格式化，然后重试；
5.  如果仍然失败，请更换新硬盘，然后重试。
注意:硬盘低级格式化会清除硬盘中的数据，请提前备份好数据。
