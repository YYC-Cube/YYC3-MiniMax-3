# TNAS 每隔一段时间断开连接或无法访问, 直到我重启它.

可能与您的一些定时执行的任务有关.

也可能是您正在使用存在 RAM 不断占用或泄漏的程序.

其中, 关于 TOS4, 210 机型., 请参考这个修复问题:

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=5124
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=3700
  

关于其它 TOS 版本和机型, 建议偶尔检查下 RAM 占用情况, 看看是否能找到引起 RAM 不断增加的应用. 如果您有使用虚拟机和 Docker 容器, 建议您限制每个虚拟机和容器的 RAM 上限.

Btrfs 配额功能的启用可能会让元数据维护的性能开销剧增, 当您在短时间内备份或上传大量输入进入 TNAS, 则会自动进行元数据维护. 期间可能会造成系统堵塞, 无法访问. 建议关闭该功能.

您可以提前启用 SSH/Telnet, 当问题再次出现时, 您可以自己或者在我们的支持下登录终端排查问题.
