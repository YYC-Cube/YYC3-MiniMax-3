# 铁威马 F2-424 产品介绍

## 产品概述

F2-424 适用于需要高性能存储方案的极客/SOHO 用户，多种企业级备份解决方案可确保用户数据安全并防范潜在的数据丢失风险，强大的计算能力让企业可从容应对高负载工作任务。采用Intel Celeron N95 4核4线程处理器，最大睿频至3.4GHz，集成Intel® UHD Graphics 显卡，最大动态主频 0.75Ghz，支持AES NI 硬件加密，搭配8 GB DDR5 4800Mhz 内存，两个2.5G网口，内置两个M.2 NVMe 插槽，实现SSD 缓存加速，成倍提升磁盘阵列的存储效率，是中小型商业用户虚拟化与数据库的高性能存储解决方案。

## 核心特性

### 更快的应用程序响应

- 采用更强大的CPU与DDR5内存
- 与上一代相比，综合运算性能提升超过140%
- 应用程序的加载速度提升90%
- 文件与照片的检索速度提升40%
- 数据库响应速度提升50%
- 网页PHP响应提升60%
- 能轻松应对高负载工作流

### 更快的传输速度

- 标配两个 2.5GbE 网口，提供 2.5Gb 网络带宽
- 线性数据传输速度可高达 283 MB/秒 (Seagate IronWolf 18TB x 2, RAID 0)
- 通过网络聚合Link Aggregation，可实现高达5Gb的网络带宽
- 为多用户高并发的文件访问提供经济实惠的解决方案

### 强大的多媒体服务

- 具备强大的4K视频解码能力
- 兼容 uPnP/DLNA协议
- 配合铁威马专用应用程序"多媒体服务器"或者第三方多媒体服务器
- 将视频串流到各种多媒体设备：电脑、智能手机、媒体播放器和电视
- 提供不间断的、愉快的观看体验

### 灵活的存储配置

- 支持TRAID/Single/RAID 0/1，多种 RAID 类型
- 支持RAID阵列在线容量扩充，在线迁移
- 能为阵列配置热备盘 (Hot Spare)
- 支持创建多个存储空间，根据业务需求，可任意选择ext4 或 Btrfs 文件系统
- 配合铁威马USB DAS 磁盘阵列，能够弹性扩充存储空间容量

### 专业的操作系统

- TNAS 运行基于Linux 开发的铁威马操作系统----TOS
- 通过对各类商业用户需求的多年研究，并经过几代持续进化
- 以友好、直观、扁平化的web操作界面实现网络管理、权限管理、存储管理、资源监控等全方位的专业存储管理功能
- 在应用市场中提供了上百个免费的各种应用程序

### 跨平台的文件服务

- 支持主流文件服务：SMB、AFP、SFTP/FTP、iSCSI、NFS、WebDAV
- 全面满足各种网络环境下的，跨平台的文件服务需求
- 支持window AD域及LDAP，方便加入企业现有IT环境，提高管理效率
- 具备用户、用户组及文件目录的多种权限管理
- 满足企业对跨部门协作及数据安全的综合需求

### 丰富的备份方案

TOS 提供了多种备份应用程序以适应在不同场景下的备份需求，以直观的操作界面和可靠的存储技术来保护您的宝贵数据。

#### 中央备份

- 能够从TNAS 端主动发起针对企业的服务器、虚拟机、职员PC 和文件服务器的备份任务
- 在事故发生后快速地还原数据

#### 双重备份

- 可将TNAS中的文件备份至远程TNAS、文件服务器或云盘上以提供多版本的异地备份
- 为TNAS设备上的数据提供进阶数据保护

#### 快照

- 利用Btrfs 文件系统先进的存储技术和经过优化的快照技术
- 启用快照计划对文件夹或 iSCSI LUN 进行连续性快照
- 在灾难发生时，按时间点回滚并还原至上一次备份以保护数据安全

#### 云同步

- 将 TNAS 的数据与云盘进行备份或者同步
- 既能云端数据的使用效率，又能提供多版本的远程备份
- 让您的数据万无一失

### 虚拟化应用

- 通过专业的虚拟化应用VirtualBox 与 Docker，配合 Docker-compose 与 Portainer
- 满足您虚拟化应用的需求
- 以一台设备实现更多功能，降低企业IT 投资成本

### 更换硬盘更方便

- 采用免工具的硬盘支架设计，无需任何工具可装卸硬盘
- 采用铁威马全新的 Push-lock 独特设计，在插入硬盘时，硬盘支架自动上锁避免硬盘脱落或掉线
- 安装一块硬盘仅需不到10秒钟
- 为需要频繁更换硬盘交换数据的用户提供了极大的便利

### 轻松安装M.2 SSD

- 为便于用户更换内存与拆装M.2 SSD，机身专门设计了侧面滑盖
- 只需将滑盖推开，便可以安装内测与M.2 SSD
- 专门提供了可手拧的螺丝，5秒钟内便可安装一条SSD

### 更好的散热

- 采用智能温控风扇，风扇转速随硬盘温度自动调节
- 确保硬盘处于最佳工作温度
- 为M.2 SDD设计了专门的通风通道
- 即便在满负荷的工作状态，M.2 SSD的温度依然能控制在合理的区间

### 加倍静音

- 由于放置的位置会与用户的距离较近，大多数用户对桌面式的产品的噪声有较严格的要求
- 机械硬盘在读写时碟片与磁头高速运转会产生震动，产生明显的噪声
- 这些噪声有可能与产品的腔体发生共鸣而进一步将噪音放大
- 为了降低噪音，除了增加减震措施外，工程师在新的结构中专门设计了大量的特殊的消音比壁以减少噪声
- 经过测试验证，新一代的产品达到了一个非常安静的水平，较上一代的噪声减少了 50%
- 在待机状态下，噪声仅 19dB(A)！

*(测试条件：使用 2 个 SATA HDD/SSD 工作于处于待机状态；测试环境噪声：17.3dB(A)测试距离：1 米)*
