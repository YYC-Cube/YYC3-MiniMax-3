# 为什么我的花生壳域名提示域名不存在或身份信息不对呢

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=1990&sid=2830252e3f49fda663c79a41b721ea52

**关键词**：DDNS、内网穿透、动态域名、域名解析、花生壳、远程访问

---

适用机型
所有 TNAS型号

原因分析
该现象是花生壳域名未做实名认证的原因，花生壳的规定：https://www.oray.com/announcements/affiche/?aid=655

解决方法
1.实认认证，登录花生壳的管理平台：https://console.hsk.oray.com/passport/login，填写SN与初始密码，然后选择SN登录即可。
1111.jpg
2.登录管理平后，将鼠标移到右上角帐户的位置，会出现一个弹窗，选择实名认证即可。
