# 如何将一台TNAS挂载到另一台TNAS？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4614&sid=048e1debfe835733a17dfc037a28fa77

适用版本:
所有版本

适用机型：
所有 TNAS 型号

场景1：在TNAS本地挂载另外一台TNAS设备上的共享文件夹

操作指引：
为增强数据访问的便捷性，实现两台TNAS设备间的文件同步与迁移，您可将位于另外一台TNAS的共享文件夹挂载至TNAS本地，具体操作请参照以下指引。

操作步骤：
方法1：使用SMB协议挂载

1、在源TNAS_A上启用SMB协议：
· 进入源TNAS_A的“控制面板”>“文件服务”，找到并启用SMB文件协议。

2、在目标TNAS_B上挂载远程文件夹：
· 进入目标TNAS_B的“控制面板”>“远程文件夹”>“SMB文件夹”。
· 点击“挂载”，在弹出的窗口中，填写源TNAS_A的挂载路径、用户名和密码，选择一个挂载目的地，即目标TNAS_B上的一个空文件夹，用于挂载源TNAS_A的共享文件夹。
· 最后，点击“应用”>“启用”后完成挂载。

3、访问挂载的文件夹：
· 挂载成功后，您可以在目标TNAS_B上的“文件管理”中看到挂载目录。
· 将需要迁移的文件或文件夹从挂载目录复制到目标位置即可。

方法2：使用NFS协议挂载

1、在源TNAS_A上启用NFS协议：
· 进入源TNAS_A的“控制面板”>“文件服务”，找到并启用NFS文件协议。

2、在源TNAS_A设置允许访问的IP地址（即目标TNAS_B的IP地址）：
· 进入源TNAS_A的“控制面板”>“共享文件夹”，点击“编辑”共享文件夹，创建NFS规则，即允许目标TNAS_B访问共享文件夹。

3、在目标TNAS_B上挂载远程文件夹：
· 进入目标TNAS_B的“控制面板”>“远程文件夹”>“NFS文件夹”。
· 点击“挂载”，在弹出的窗口中，填写源TNAS_A的挂载路径，选择NFS版本和协议，再选择一个挂载目的地，即目标TNAS_B上的一个空文件夹，用于挂载源TNAS_A的共享文件夹。
· 最后，点击“应用”>“启用”后完成挂载。

4、访问挂载的文件夹：
· 挂载成功后，您可以在目标TNAS_B上的“文件管理”中看到挂载目录。
· 将需要迁移的文件或文件夹从挂载目录复制到目标位置即可。

方法3：使用WebDAV协议挂载

1、在源TNAS_A上启用WebDAV协议：
· 进入源TNAS_A的“控制面板”>“文件服务”，找到并启用WebDAV文件协议。

2、在目标TNAS_B上挂载远程文件夹：
· 进入目标TNAS_B的“控制面板”>“远程文件夹”>“云盘”。
· 点击“挂载”，在弹出的窗口中，选择WebDAV云服务商，自定义名称，填写源TNAS_A的挂载路径、用户名和密码，点击下一步后，选择要挂载的云盘目录，并指定挂载目的地，即目标TNAS_B上的一个空文件夹。
· 最后，点击“应用”>“启用”后完成挂载。

3、访问挂载的文件夹：
· 挂载成功后，您可以在目标TNAS_B上的“文件管理”中看到挂载目录。
· 将需要迁移的文件或文件夹从挂载目录复制到目标位置即可。

场景2：通过iSCSI协议在TNAS本地挂载另外一台TNAS设备的存储空间

操作指引：
通过iSCSI协议，用户能够将另一台TNAS设备的存储空间挂载到本地TNAS上，实现存储资源的灵活扩展和高效利用。

操作步骤：
1、在源TNAS_A上配置iSCSI：
· 在TOS系统的应用中心安装iSCSI Manager应用，以及创建好 iSCSI Target 和 iSCSI LUN。

2、在目标TNAS_B上挂载iSCSI：
· 进入目标TNAS_B的“控制面板”>“存储管理”>“虚拟磁盘”。
· 击点“挂载”，输入 iSCSI Target 所在的服务器 IP 地址及其通讯端口(预设端口为：3260)，然后点击“获取 iSCSI LUN”。如需密码认证，请输入使用者名称及密码。你可以选择启用“数据摘要”或“标头摘要”，这些选项将被设定为 iSCSI initiator 联机 iSCSI Target 时需要验证的项目。然后点击“下一步”。

· 选择 iSCSI LUN， 点击“完成”。请注意，iSCSI LUN 磁盘同时只能连接不超过一台主机或服务器。TNAS可挂载 EXT4,NTFS 硬盘格式。

3、访问挂载的存储空间：
· 挂载成功后，您可以在目标TNAS_B上的“文件管理”中看到挂载的磁盘目录。
· 将需要存储的文件或者文件上传至磁盘目录即可。
