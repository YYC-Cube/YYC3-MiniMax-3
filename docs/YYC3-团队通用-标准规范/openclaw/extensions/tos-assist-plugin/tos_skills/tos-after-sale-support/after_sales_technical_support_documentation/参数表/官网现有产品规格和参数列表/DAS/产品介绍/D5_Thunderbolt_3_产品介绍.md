# 铁威马 D5 Thunderbolt 3 产品介绍

## 产品概述

D5 Thunderbolt 3 是一款雷电3专业级磁盘阵列，专为需要高性能存储和专业视频编辑的用户设计。

## 核心特性

### 超大存储容量

- 五个盘位，支持3.5寸SATA硬盘及2.5寸SSD
- 总存储容量可高达80TB

### 闪电般的速度！

- Thunderbolt™ 3 40Gbps接口
- 读写速度高达1035 MB/s（测试条件：5块SSD RAID 0模式）
- 双Thunderbolt™ 3接口，支持多台Thunderbolt™ 3设备菊花链串接

### 专用DP接口

- 配备高清DP数字接口
- 可直接与显示器连接
- 更好满足视频编辑用户需求

### 多屏显示

- 通过Thunderbolt™ 3接口和DP接口
- D5 Thunderbolt™ 3可以实现最多3个屏幕同时显示
- 用户可以更灵活地进行多任务操作

### 多种阵列模式

- 支持RAID 0、1、5、10和JBOD阵列模式
- 适应多种应用需求

### 不仅专业而且安全！

- 采用多种专业存储技术
- 让您的数据更安全

### 服务专业领域

- 体积小、容量大、速度快
- 更适用于4K视频编辑与存储专业领域的专业用户
- 适用于拥有大容量数据并对速度要求严格的用户

### 权威质量认证

- 设计与性能通过了Apple公司与Intel公司的双重认证
- 性能更稳定，质量更可靠
