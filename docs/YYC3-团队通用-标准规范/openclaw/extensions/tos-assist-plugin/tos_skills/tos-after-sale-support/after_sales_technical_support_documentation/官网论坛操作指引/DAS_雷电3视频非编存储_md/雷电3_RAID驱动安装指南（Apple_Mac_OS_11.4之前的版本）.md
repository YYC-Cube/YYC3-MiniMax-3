# 雷电3 RAID驱动安装指南（Apple Mac OS 11.4之前的版本）

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1605

您需要在电脑上安装RAID控制器驱动程序,否则电脑无法识别到设备

适用型号
D4 Thunderbolt3、D5 Thunderbolt3、D8 Thunderbolt3、D16 Thunderbolt3

第一步：安装驱动程序
1.1. 下载驱动程序 https://download2.terra-master.com/T3_R ... 211116.zip 。
1.2. 找到下载驱动文件，然后双击该软件包以启动安装程序，单击【继续】按钮。
1.3. Mac OS 将提示您安装驱动程序，单击【安装】按钮。
1.4. 系统将提示输入管理员用户名和密码，然后单击 【软件安装】
1.5. 注意【安全性与隐私】弹出窗口提示，点击【打开安全性偏好设置】点击允许运行【启用系统扩展】，请不要忽略！
特别提醒：点击【打开安全性偏好设置】才会弹出【安全性与隐私窗口】

1.6. 确保已选中【App Store和被认可的开发者】，然后单击【Allow】：

17. 您将收到一个弹出窗口，单击【重新启动】按钮，会执行重建系统扩展缓存，执行完成后再点击【重新启动】铵钮。

第二步：查看驱动是否安装成功
2.1. 请保持雷电3设备开机并与电脑连接状态，以系统管理员身份登录 Mac OS【前往→实用工具】打开【终端】窗口。
2.2. 输入以下命令后按回车：sudo su
2.3. 完成后在 Password 位置输入 Mac OS 密码，然后回车（注意输入密码不会显示）。
2.4. 输入以下命令后按回车：kextstat | grep high*
2.5. 请确认版本为4.23.6。
2.6. 恭喜您驱动安装成功，Thunderbolt3设备正常使用。
