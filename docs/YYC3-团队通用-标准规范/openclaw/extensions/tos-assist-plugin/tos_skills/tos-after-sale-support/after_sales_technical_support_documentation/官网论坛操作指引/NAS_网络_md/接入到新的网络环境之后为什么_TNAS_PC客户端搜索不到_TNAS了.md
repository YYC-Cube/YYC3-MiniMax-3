# 接入到新的网络环境之后，为什么 TNAS PC客户端搜索不到 TNAS了？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1991&sid=51493c53a160f99b97633ae2f702b6b5

适用机型
F2-220、F2-221、F2-420、F2-421、
F4-220、F4-221、F4-420、F4-421、
F5-220、F5-221、F5-225、F5-420、F5-421、F5-422、
F8-421、F8-422

适用 TOS版本
不限

造成该现象的原因可能有好几种，请按照以下对策排查问题：

1.检查 TNAS设备与电脑是否在同一局域网且在同一网段。
2.按原来的顺序将硬盘重新安装进 TNAS再开机，再尝试搜索。
3.取出硬盘，空机开机并等待1分钟左右，再尝试搜索。
4.尝试将 TNAS与电脑直接连接试试，再尝试搜索。
5.检查电脑是否开启防火墙，请关闭防火墙，再尝试搜索。
6.在搬家之前，您可能曾经在 TNAS上将防火墙设置为仅允许某一网段访问，导致无法访问。请将 TNAS与电脑直连，然后将电脑的 IP修改为允许访问的网段的 IP，再尝试搜索。
