# 在 Windows 11 上使用 D16 Thunderbolt 3 设备时，可能会出现蓝屏问题。

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4850

适用机型
D16 Thunderbolt 3

现象及对策
如果在 Windows 11 上使用 D16 Thunderbolt 3 设备时遇到蓝屏问题，建议排除以下原因：
D16 Thunderbolt 3 设备不支持 Windows Thunderbolt 4。
建议在 Windows Thunderbolt 3、MacOS Thunderbolt 4 或 MacOS Thunderbolt 3 接口上使用该设备。
