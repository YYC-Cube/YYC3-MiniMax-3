# 如何注册登记？

请先注册并登录 TerraMaster 账号：account. Terra-master. Com

完成注册并登录后，请前往”Warranty Registration（保修登记）“登记您的设备。

请注意，关于”My Device（我的设备）“，它是与 TNAS 设备有关的功能。

- 如果您购买的设备是 DAS 产品，请忽略。
  
- 如果您购买的是 NAS 产品，您可以在完成 NAS 系统（TOS）安装后，前往 TOS 网页-控制面板-系统，获取 Device ID 将 NAS 登记到 TerraMaster 账号。
  
    产品保修注册完成。随后会收到产品注册成功的邮件，赠送的 6 个月保修时长。
