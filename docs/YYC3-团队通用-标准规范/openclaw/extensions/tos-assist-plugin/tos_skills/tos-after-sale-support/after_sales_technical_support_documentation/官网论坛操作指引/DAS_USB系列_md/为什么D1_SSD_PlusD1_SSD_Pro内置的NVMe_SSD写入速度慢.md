# 为什么D1 SSD PlusD1 SSD Pro内置的NVMe SSD写入速度慢？

适用机型：D1 SSD Plus/D1 SSD Pro
适用系统：Windows 10/11

如果您在使用D1 SSD Plus/D1 SSD Pro时，发现写入速度明显偏低，可能是部分NVMe SSD因未开启写入缓存。
请参考以下步骤进行排查与处理，以确保NVMe SSD 获得最佳性能。

请按照以下步骤在 Windows 系统中开启NVMe SSD写入缓存：

1、打开控制面板→设备管理器→找到并展开磁盘驱动器
2、双击您的NVMe SSD（名称依据品牌与容量显示）→在弹出的设置窗口中切换到“策略”
3、在策略页面勾选【更好的性能】和【启动设备上的写入缓存】，最后点击【确定】完成设置

写入缓存开启与未开启的速度对比
测试环境： Windows 11、USB4 接口、D1 SSD Plus 搭配 Samsung 990 PRO 4TB

从测试结果可见，开启写入缓存后写入速度可提升数倍，有助于充分发挥NVMe SSD 的速度性能。

如已按照上述方法进行设置，仍存在速度异常，可进一步检查 USB 接口版本、线材质量、主机配置，或联系技术支持以获取更多帮助。
