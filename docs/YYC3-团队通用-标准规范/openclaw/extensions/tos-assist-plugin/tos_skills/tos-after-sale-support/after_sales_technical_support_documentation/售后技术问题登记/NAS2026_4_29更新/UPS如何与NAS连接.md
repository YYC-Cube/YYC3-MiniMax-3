# UPS如何与NAS连接?

**关键词：TOS、TNAS、控制面板、UPS**

**解决方案：**

UPS连接与设置方法：

硬件连接：
1. 将UPS的USB通信线（或网线，视UPS型号而定）连接到TNAS的USB口
2. 确保UPS已正常供电并运行

软件设置：
- 详细教程：https://toshelp.terra-master.com/cn/docs/TOS7/controlpanel/general-settings/hardware-power/

简要步骤：
1. 前往 TOS Web > 控制面板 > 通用设置 > 硬件与电源
2. 找到UPS设置部分
3. 系统应自动检测到已连接的UPS
4. 配置断电后的操作（如断电X分钟后自动关机以保护数据）
5. 保存设置

注意：不同UPS型号支持的功能可能不同，请参考UPS说明书确认兼容性
