# 我的计算机无法识别硬盘，并且没有出现硬盘盘符？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=293

故障排除

适用机型：
TerraMaster D2 Thunderbolt 3 / TD2 Thunderbolt 3（D2-330）
TerraMaster D4 Thunderbolt 3（D4-330）
TerraMaster D5 Thunderbolt 3（D5-330）
TerraMaster D8 Thunderbolt 3（D8-330）

如果您在TerraMaster Thunderbolt 3设备中安装了推荐的硬盘， 但是您的计算机无法识别该硬盘，请尝试以下解决方案：

1.如果硬盘指示灯不亮，请确认硬盘是否已正确安装。取下硬盘并插入硬盘，然后重试；
2.如果硬盘指示灯为绿色，请转至Windows磁盘管理初始化硬盘，或使用MAC disk utility清除外部设备。

注意：
设备的默认出厂模式为Single(单盘)模式。在Single模式下，每个硬盘均显示不同的盘位并独立工作。如果您安装有数据的硬盘并希望使用Single模式，则可以直接使用而无需更改任何设置。
