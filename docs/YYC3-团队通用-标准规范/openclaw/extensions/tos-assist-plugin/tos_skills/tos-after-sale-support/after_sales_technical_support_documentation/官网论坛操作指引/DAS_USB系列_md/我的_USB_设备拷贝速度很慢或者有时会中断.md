# 我的 USB 设备拷贝速度很慢，或者有时会中断？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=502

我的 USB 设备拷贝速度很慢，或者有时会中断？

适用机型：
D2-300
D2-310
D4-300
D5-300C
D5-300

如果您的 TerraMaster USB DAS 存储设备已经正确安装，但是拷贝文件的速度非常慢（例如只有5〜20MB/s，或甚至更慢），或者有时甚至会随机性中断。
根据我们近10 年来服务和观察过的案例，总结出以下几种最常见的原因与解决方案：

数据传输过程中随机性中断问题的排除方法:

1.具有 RAID 功能的 TDAS 对在开始使用前就有数据的旧硬盘可能存在不兼容或其他因素导致随机性中断现象。
①建议您更换新硬盘尝试。
②备份旧硬盘的数据，然后将旧硬盘安装至 TerraMaster TDAS 产品上。并创建新的 RAID 阵列并格式化硬盘试试。
注意！此操作会清空硬盘数据，请先备份数据再执行操作。

2.Windows PC 电脑品牌很多，不同品牌电脑的 USB 接口或线路的速率及质量可能不一致，当电脑的 USB 接口连接外置硬盘盒，拷贝时可能存在随机性中断问题，建议根据以下步骤排除：
①个别Windows 电脑 USB 接口信号弱，建议更换其他的 USB 接口尝试；或者更换其它的电脑试试。
②电脑预装的是公版 USB 驱动，与电脑主板不兼容或不匹配，建议你前往电脑官方下载并安装正确的 USB 驱动。

3.可能是使用了不兼容的 USB 分线器或 USB HUB 扩展坞导致掉线，建议您使用原装线单独连接至电脑的 USB 接口使用。

数据传输过程中速度慢问题的排除方法:

1.可能是拷贝的文件都是一些小文件导致的！若文件都为单一的小文件（如几 KB 或者几十 KB 的文件），拷贝速度会极大衰减，这属于正常的现象。请更换单一文件大于10 GB 的文件再测试一下速度。

2.可能是安装至 DAS 产品里的硬盘故障或者电脑本身的硬盘故障，请使用硬盘健康检测工具测试排除，例如：HD Tune。
3.使用的 USB 线不是原装线材，请确保使用原装 USB 线。

4.电脑的 USB 接口故障，请确认您正在使用的是 USB 3.0 / USB 3.1高速接口而不是 USB 2.0 接口，并更换电脑的其它 USB 接口试试。
5.其他转接设备干扰，通过 USB HUB 分线器或扩展坞再连接TDAS，可能会导致速度慢。请直接连接至电脑的 USB 接口试试。
