# 拔掉初始化安装TOS系统的硬盘后，TOS系统不能启动？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3591&sid=91960374e52a8fba318a0aab4711ff91

适用型号：
F2-220、F2-420、F4-220、F4-420、F5-420、F2-221、F2-421、F2-422、F4-221、F4-421、F4-422、F5-221 、F5-421、F5-422、F8-421、F8-422、F2-423、F4-423、T6-423、T9-423、T12-423，T9-450、U4-423、U8-423、U8-450、U12-423

适用版本：
TOS 5.1.40

故障现象：
将TNAS设备内初始化安装TOS系统的硬盘拔掉，设备内仅保留后面添加的硬盘。然后开机，TNAS设备的网络指示灯不亮，仅电源指示灯亮起，同时通过TNAS PC客户端搜索不到。
例如，用一块SATA硬盘或M.2 SSD安装TOS系统，然后再插入其他硬盘，在TOS控制面板中创建存储池与卷，再关机拔掉安装系统时插的硬盘。

原因分析：
TOS 5.1.40版本有对TOS系统盘有做调整，对于未参与初始化安装系统的硬盘是不具有TOS系统。而TOS5.1.40版本之前的系统，安装TOS系统之后再添加的硬盘是具有系统信息的。

解决方法：
请勿拔掉TOS的系统盘使用。
