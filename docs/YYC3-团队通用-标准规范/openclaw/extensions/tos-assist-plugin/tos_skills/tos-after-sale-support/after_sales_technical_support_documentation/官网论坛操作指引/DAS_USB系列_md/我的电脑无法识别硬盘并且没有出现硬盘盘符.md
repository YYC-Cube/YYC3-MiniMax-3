# 我的电脑无法识别硬盘，并且没有出现硬盘盘符？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=497

故障排除

适用机型：
D2-310

如果您在 TerraMaster USB 存储设备中安装了推荐的硬盘，但是您的电脑无法识别该硬盘，请尝试以下解决方案：

1.如果硬盘指示灯不亮，请确认硬盘是否正确安装。尝试卸下硬盘，再插回；
2.如果硬盘指示灯为绿色，请转到 Windows 磁盘管理初始化硬盘，或使用 MAC 的 DISK Utility 擦除外部设备；
3.如果硬盘指示灯为橙色，则表明硬盘可能有故障。需要更换硬盘。

注意：
设备的默认出厂模式为“Single(单盘)“模式。在 Single 模式下，每个硬盘均显示不同的盘位并独立工作。如果您安装有数据的硬盘并希望使用 Single 模式，则可以直接使用而无需更改任何设置。
