# 如何为阵列添加硬盘

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4562&sid=2853efb328304e05736fc85f61407238

适用版本: 所有版本

适用机型：所有 TNAS 型号

故障现象：

存储池和卷没有足够的可用容量，需要为阵列添加硬盘。在不改变阵列模式的前提下，替换更大容量的硬盘，让存储池增加更多的可用容量。

一、解决办法：

1、登录 TOS 系统页面 ，在 TNAS 中插入一块新的硬盘并确保插入的新硬盘容量大于或等于阵列中容量最小的硬盘的容量，

2、前往 至 控制面板>存储管理>存储池 点击 “编辑”按钮，在弹出的菜单中，选择“为阵列添加硬盘”，此时阵列开始同步，过程需要一些时间，请耐心等待直至其同步完成。如下图：

3、前往 至 控制面板>存储管理>卷 点击 “编辑”按钮 根据需求编辑卷容量。

注意：
1、本解决办法仅适用于TRAID、TRAID+、JBOD、RAID5、RAID6阵列类型，

2.、阵列编辑只能一次添加一块新硬盘,不可同时添加两块或更多硬盘。

3、同步完成后如果发现依然无法扩容存储池或卷,请参考这个指引,手动扩容:
