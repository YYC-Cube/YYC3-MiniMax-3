# 初次安装 TOS 安装进度卡在0%了？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3121&sid=df318c2657b676e1a07d8bad1baa14ba

适用机型
F2-220、F2-221、F2-420、F2-421、F2-422、F4-220、F4-221、F4-420、F4-421、F5-220、F5-221、F5-225、F5-420、F5-421、F5-422、F8-421、F8-422、F2-223、F2-423、F4-223、F4-423等所有TNAS型号

故障现象
少数用户在使用新入手的 TNAS 设备按照指引，使用自动模式安装 TOS，却卡在0%一直不动。

故障原因
由于网络原因，TNAS未请求到下载服务器。

对策
遇到该问题请刷新TOS初始化网页，按照指引从铁威马官网下载对应型号的.ins安装包，选择手动模式，通过上传安装包来完成 TOS 的安装。
https://support.terra-master.com/download
