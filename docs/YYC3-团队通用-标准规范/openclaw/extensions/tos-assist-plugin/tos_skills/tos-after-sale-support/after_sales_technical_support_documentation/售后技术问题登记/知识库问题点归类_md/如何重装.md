# 如何重装?



关于重新安装TOS的方法，请参考：

* **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=423
* **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=241

如果您使用的是TOS 4，只要您的盘此前一直使用于TNAS内，您可以忽视安装系统时的”删除/格式化“提示，它是针对系统分区的。但在完成TOS安装后的管理员初始化阶段，如果出现RAID初始化提示”/创建/删除/格式化“，请不要继续防止丢失数据。此时您的盘或RAID很可能存在异常。

如果您使用的是TOS 5及以后的TOS版本，无论哪个阶段，只要有任何提示”删除/格式化“，请立即停止操作防止丢失数据。我们可以帮您安排工程师远程排查问题。
