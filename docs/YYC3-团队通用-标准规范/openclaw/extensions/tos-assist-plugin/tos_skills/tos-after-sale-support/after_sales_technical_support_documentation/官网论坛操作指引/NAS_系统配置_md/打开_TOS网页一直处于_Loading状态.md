# 打开 TOS网页一直处于 Loading状态？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1567&sid=91960374e52a8fba318a0aab4711ff91

故障排除

适用机型：所有 TNAS型号

原因分析：
升级到 TOS 4.2.12及以上的版本后，在进入TOS网页前，系统会自动检测文件系统。以下是几种会引起TOS网页一直处于 Loading状态的情况:
1.升级系统后，如果 RAID容量过大，第一次检测的时间会相对漫长，需要耐心等待。
2.当 Btrfs文件系统异常时，检测时间会很漫长，可能花费几小时甚至几天。

解决办法：
如果您遇到该情况，请不要关闭 TNAS，耐心等地等待一段时间直到成功进入TOS登录页面。若等待时间超过2天，基本上判断为Btrfs文件系统故障，请尝试联系铁威马技术支持远程协助排查故障。如何联系铁威马技术团队为您提供技术支持服务？
