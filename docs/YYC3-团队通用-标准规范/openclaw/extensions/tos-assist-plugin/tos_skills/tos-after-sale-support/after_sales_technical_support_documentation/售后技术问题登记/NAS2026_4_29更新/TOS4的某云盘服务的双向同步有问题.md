# TOS4的某云盘服务的双向同步有问题.

**关键词：TOS、TNAS、CloudSync、避免双向同步的冲突问**

**解决方案：**

原因：TOS4已是很旧的系统的版本，云服务接口可能已变更。

建议：
1. 仅使用单向同步：在CloudSync设置中，选择「仅下载」或「仅上传」模式，避免双向同步的冲突问题
2. 升级TOS版本：考虑升级到TOS5或更高版本，获得更好的云服务兼容性和功能支持
3. 替代方案：使用PC客户端同步，在电脑上安装云盘客户端和TNAS PC，通过电脑中转同步

注意事项：
- 旧版TOS4的CloudSync可能不再获得更新支持
- 重要数据建议定期手动备份，避免同步异常导致数据丢失
