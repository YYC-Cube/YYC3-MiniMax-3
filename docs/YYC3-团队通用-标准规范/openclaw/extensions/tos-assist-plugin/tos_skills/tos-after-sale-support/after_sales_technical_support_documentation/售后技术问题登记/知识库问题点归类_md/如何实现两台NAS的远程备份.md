# 如何实现两台 NAS 的远程备份？

有多种工具可用于远程备份。但您都需要设置端口映射才能实现。

此外，您也可以使用 SMB／NFS 远程挂载，这样 NAS 本地的备份软件 TFM 也能被用于备份。

通过 VPN 连接后，两个 NAS 可以直接用虚拟 IP 或 LAN IP 连接。这种情况下也可以使用多种备份工具。请参考这个挑选适合使用场景的备份工具
