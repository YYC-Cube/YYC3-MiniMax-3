# 无法在电脑上使用 A USBLAN 2.5G USB3.0转2.5G网卡

操作指引

A-USBLAN-2.5G 是专门为适配铁威马TNAS设备使用的 2.5Gb USB 网卡, 即插即用，无需安装驱动。TNAS设备的系统版本需TOS4.2.39及以上版本。
A-USBLAN-2.5G 同样也可以被用于电脑上。

适用型号或系统
Win8/Win10/Win11/macOS 等主流操作系统
备注：不兼容Windows XP、Windows 7系统、TerraMaster F2-210、TerraMaster F4-210。

故障现象
个别用户反馈将A-USBLAN-2.5G网卡安装至电脑上，无能被识别。

故障原因及对策
由于 A-USBLAN-2.5G 网卡是免驱动的, 正常情况下是可以即插即用。但不排除个别的电脑会出现不能被识别的现象，需要安装驱动才能使用。
