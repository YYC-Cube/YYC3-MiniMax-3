# 是否支持VPN用户端?

**关键词：TOS、TNAS、控制面板、HTTPS、VPN**

**解决方案：**

支持。

版本要求：TOS6最新版本及此后版本支持VPN客户端功能。

配置方法：
- 详细教程：https://toshelp.terra-master.com/docs/TOS6/controlpanel/network-services/network/vpn-connection

简要步骤：
1. 前往 TOS Web > 控制面板 > 网络服务 > 网络 > VPN连接
2. 添加VPN配置（支持PPTP、L2TP、OpenVPN等协议）
3. 填入VPN服务器信息并连接
4. 连接成功后，TNAS即可通过VPN访问远程网络资源
