# 能否调整CPU功耗PL1, PL2?

**关键词：TOS**

**解决方案：**

说明：
- 设备出厂前，已根据散热能力调整好合适的PL1/PL2功耗值
- 继续增加功耗：性能提升有限，但可能触发过热降频，反而降低性能
- 降低功耗：可适当调低1-2W，降低温度和能耗

调整方法：
1. 前往 TOS Web > 控制面板 > 通用设置 > 硬件与电源 > CPU功耗管理
2. 根据需求调整PL1（长时功耗）和PL2（短时功耗）
3. 观察温度和性能变化，找到平衡点

建议：
- 若无特殊需求，建议使用出厂默认值
- 若温度过高，优先考虑改善散热（清理灰尘、增加风扇等），而非单纯降低功耗
