# TNAS内存RAM可以升级吗？

**关键词：TNAS、HTTPS**

**解决方案：**

支持升级内存（RAM）。

关键信息：
1. 最大支持内存、内存类型、是否有预留内存槽：
   → 请查看对应TNAS产品的规格参数页面
   → 官网：www.terra-master.com，找到对应机型，规格参数通常在产品详情页最底部

2. 内存条选择：
   → 官方特供RAM条：https://www.terra-master.com/collections/accessories
   → 第三方RAM条：可选择规格参数相符的第三方内存条
   → 注意：第三方内存条存在较小兼容性风险（测试数据有限，无具体兼容清单）

3. 已知不兼容：Crucial T500（不建议使用）

4. 安装建议：
   → 购买前确认机型支持的最大内存和内存规格（DDR3/DDR4/DDR5，频率等）
   → 建议优先选择官方特供内存条，兼容性有保障
