# TNAS mobile iOS 端 3.x.x 访问 210/220/420/221/421/422 机型 (TOS4) 失败。能发现设备但无法连接。

抱歉，适配 TOS4 的 iOS 旧版 2.x.x TNAS mobile app 已停止服务。与此同时，Android 端 TNAS mobile app 还可以通过 LAN 和 WAN+映射端口进行访问。而您正在使用的新版 3.x.xTNAS mobile app 并不适配 TOS4。

如果您的 TNAS 机型支持升级 TOS5/6，您可以考虑升级，然后就可以使用新版 TNAS mobile app 访问 TNAS。

或者您可以考虑升级/更换/替换到可搭载新 TOS 版本的机型，例如 424,425, 425 Plus 等.
