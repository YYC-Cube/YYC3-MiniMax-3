# 不想使某种RAID, 想要改成另一种RAID.

**关键词：存储池、RAID**

**解决方案：**

操作前重要提示：修改RAID类型会删除存储池和卷，请务必先备份所有数据！

操作步骤：
1. 备份所有重要数据到外部存储
2. 前往 TOS Web > 控制面板 > 存储管理
3. 删除卷（数据将丢失，确认已备份）
4. 删除存储池（旧RAID）
5. 点击「创建存储池」，勾选需要的硬盘
6. 选择您需要的RAID类型（如RAID1、RAID5、TRAID等）
7. 完成创建后，再创建卷
8. 恢复备份的数据到新卷

说明：
- 不同RAID类型有不同的冗余和性能特性，请根据需求选择
- 建议了解各种RAID类型的优缺点后再做决定
