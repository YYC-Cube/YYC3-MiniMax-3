# 只有使用超级管理员时,才能在Rsync使用SSH通过连接测试, 使用其它用户时提示"无法建立通信".

**关键词：TOS、TNAS、SSH、Rsync、**

**解决方案：**

原因：TOS5及以上版本中，Rsync使用SSH加密时，仅超级管理员（主管理员）账户支持SSH访问。

说明：
- 当Rsync选择SSH加密方式时，连接使用系统的SSH服务
- TOS5+版本基于安全考虑，限制普通用户通过SSH访问
- 因此只有超级管理员账户能成功通过SSH连接Rsync服务

解决方案：
1. 使用超级管理员账户进行Rsync SSH连接测试
2. 若需使用普通用户：考虑不使用SSH加密方式，改用普通Rsync连接方式（需在TNAS上配置Rsync Server并创建相应用户）
3. 或考虑升级到最新TOS版本，查看是否有更灵活的用户权限配置
