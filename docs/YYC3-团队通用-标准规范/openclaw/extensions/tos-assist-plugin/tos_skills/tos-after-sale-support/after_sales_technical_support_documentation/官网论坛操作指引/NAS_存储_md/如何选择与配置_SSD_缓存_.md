# 如何选择与配置 SSD 缓存 ？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=2280&sid=2853efb328304e05736fc85f61407238

由于启用 SSD 缓存消耗一定数量的TNAS 的内存。SSD 缓存的内存占用率建议不得超过TNAS 总内存容量的 50~70%，否则可能影响TNAS 的设备性能。

以下是 SSD 缓存的配置建议：

内存大小       ：建议配置的 SSD 缓存容量(最大)
2GB：	    160GB
4GB：	    320GB
6GB：	    500GB
8GB：	    800GB
10GB：	    1000GB
12GB：	    1280GB
16GB：	    1600GB
32GB：	    3200GB
