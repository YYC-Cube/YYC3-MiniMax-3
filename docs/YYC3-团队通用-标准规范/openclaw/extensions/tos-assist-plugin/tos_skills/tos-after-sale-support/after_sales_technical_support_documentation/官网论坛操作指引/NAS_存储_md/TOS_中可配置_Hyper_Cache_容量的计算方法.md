# TOS 中可配置 Hyper Cache 容量的计算方法

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4852&sid=2853efb328304e05736fc85f61407238

适用版本: TOS 5,TOS 6.0.xxx~6.0.673

适用机型：所有x86机型

计算最大缓存容量公式及详解：

一、计算公式：

允许创建的最大缓存容量 =（总运行内存 {GB} x0.6 - 已使用的运行内存 {GB}）*1024/5.5

二、公式详解：

1、“总运行内存 {GB}” 指的是您设备所配备的运行内存总量，单位为 GB。例如，您的设备运行内存为 8GB、16GB 或 32GB 等。​

2、“已使用的运行内存 {GB}” 是当前系统及正在运行的应用程序已经占用的运行内存大小，同样以 GB 为单位。可以通过 ”控制面板>通用设置>系统信息


3、“x0.6” 表示系统建议的用于缓存创建的运行内存占比。系统会根据这个比例来分配运行内存用于缓存，以平衡系统运行与缓存

创建的需求。​

4、“x1024” 是将以 GB 为单位的数值转换为 MB，因为在计算机存储容量的换算中，1GB = 1024MB。这样可以保证最终计算结果的单位一致性。​

5、“/5.5” 是一个调整系数，该系数是根据系统对缓存性能和资源利用的综合优化得出的，用于进一步准确计算运行内存允许创建的最大缓存容量。

注意：如果计算结果为0或负数，表示剩余的可用内存不足以支持创建缓存，无法进行缓存创建操作。

三、示例计算：​

假设您的设备总运行内存为 16GB，通过系统监控工具查看到已使用的运行内存为 6GB。首先计算括号内的值：(16GBx0.6 - 6GB)=9.6GB - 6GB = 3.6G​B

然后进行单位转换和除法运算：3.6GBx1024/5.5≈665.45GB​

四、确定 Hyper Cache 容量

在得到运行内存允许创建的最大缓存容量后，需结合卷容量、SSD 缓存盘容量，从这三个数值中选取最小值，该最小值就是最终创建 Hyper Cache 的容量。
