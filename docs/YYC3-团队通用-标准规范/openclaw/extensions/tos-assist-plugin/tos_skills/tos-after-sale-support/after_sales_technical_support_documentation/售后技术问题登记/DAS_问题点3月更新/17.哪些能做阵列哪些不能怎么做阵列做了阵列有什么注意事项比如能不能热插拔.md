# 哪些能做阵列，哪些不能?怎么做阵列，做了阵列有什么注意事项，比如能不能热插拔

答：身自带USB系列支持RAID型号：D2-320/D5Hybrid（HDD1/2槽位）/ D8Hybrid（HDD1/2槽位）/D5-300/D5-310

本身自带雷电系列支持RAID型号：TD2 THUNDERBOLT 3/ TD5 THUNDERBOLT 3/ TD16 THUNDERBOLT 3/D8-332

无自带RAID软件型号：D4-320/D6-320/D9-320/D4-320U，这些型号本身不支持RAID功能，但是能支持第三方RAID软件，例如Windows存储空间、MacOS RAID助理、TrueNAS、Proxmox Virtual Environment 8.3 系统中使用外置的USB设备创建ZFS存储池、飞牛系统、麒麟系统_版本2303、统信专业版2500

17.在MacOS使用平台无法安装Thunderbolt 3设备的RAID驱动，或者更新MacOS之后无法识别。
适用机型：D5 Thunderbolt 3/D16 Thunderbolt 3 /D8-332(Thunderbolt 3)

1.首先需要核实你需要使用原装的雷电线，线材有带闪电标识。
2.D5 Thunderbolt 3正常连接到在Mac的雷电接口，并且处于开机状态。
3.前往MacOS关于本机，系统报告，雷电选择项，查看，是否有D5设备的连接（确认后下一步）
注意：如果，系统报告，雷电选择项，没有显示D5设备，请排除与电脑连接是否有问题，例如使用线材错误、电源使用错误、或者D5设备本身故障。
4.前往MacOS关于本机，系统报告，PCIE选择项，查看，2720驱动器是否加载成功（否/是）
注意：显示否，是未加载RAID驱动，说明驱动安装问题，安装驱动时注意两项（1.修改MacOS安全策略。2.安装RAID驱动时如果没有提示扩展驱动，需要手动进入开通，系统隐私项手动点击加载驱动）
