# 如何在Windows10系统上安装Thunderbolt 3驱动程序？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=298

操作指引

适用机型：
TerraMaster TD2雷电3 / D2雷电3（D2-330）
TerraMaster D4雷电3（D4-330）
TerraMaster D5雷电3（D5-330）
TerraMaster D8雷电3（D8-330）

如果您是Windows系统用户，则需要先安装Thunderbolt 3驱动程序，然后才能在计算机上使用Thunderbolt 3设备。

安装Thunderbolt 3驱动程序的指南:

1.从您的计算机制造商的官方网站下载
从您的计算机制造商的官方网站上找到“支持和服务”；
输入您的计算机型号；
找到驱动程序下载部分，然后选择“ Thunderbolt驱动程序”，单击下载；
如果找不到Thunderbolt驱动程序，请下载最新的主板驱动程序并进行更新。
2.从英特尔官方网站下载
确保您的计算机装有Intel的Thunderbolt 3控制器；
转到https://downloadcenter.intel.com/zh-cn/ ... -Intel-NUC
请按照页面上提供的说明完成下载和安装；
安装Thunderbolt 3驱动程序后，计算机上还将安装Thunderbolt控制软件。查找并打开Thunderbolt控制软件，允许所连接的Thunderbolt设备。
