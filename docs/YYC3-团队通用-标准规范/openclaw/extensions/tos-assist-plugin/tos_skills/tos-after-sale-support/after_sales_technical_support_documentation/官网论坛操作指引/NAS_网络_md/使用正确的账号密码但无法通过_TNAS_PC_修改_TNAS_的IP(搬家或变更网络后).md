# 使用正确的账号密码，但无法通过 TNAS PC 修改 TNAS 的IP？(搬家或变更网络后)

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3439&sid=51493c53a160f99b97633ae2f702b6b5

故障现象
这种现象一般出现在搬家、换路由器、换工作场所、换服务商后。

适用机型
所有 TNAS 型号

适用 TOS 版本
所有 TOS 版本

故障原因分析
你的新路由器或新的路由器配置的IP网段可能和之前的 IP 网段不一样，而你之前已经把 TNAS 的 IP 设置为之前 IP 网段格式下的静态 IP，这导致你不能修改 TNAS 的 IP。

解决方法
1. 将您的 TNAS 直接连接到您的电脑。
2. 电脑上与TNAS连接的网卡的 IP 地址改成上一个 IP 网段的格式。（表示网段的数字是IP中的倒数第二个数字xxx.xxx.xxx.xxx）
3. 然后您应该就可以登录 TNAS了，请在 TOS 控制面板中将静态 IP 改为自动 DHCP。
4. 将 TNAS 放回路由器下，将电脑的 IP 地址改回原来的设置或选择“自动获取”。
5. 然后您应该就可以修改 TNAS IP并通过 TNAS PC 访问 TNAS了。
6. 进入 TOS 控制面板将 TNAS IP 设置为新的静态 IP。（这意味着如果你再次改变路由器或网络环境，你需要重新执行这些步骤。所以更理想的方式是将 TNAS 设置为 DHCP，而由路由器根据 TNAS 的 Mac 地址为 TNAS 分配静态 IP，这需要你进入你的路由器控制面板。有关详细操作您可以咨询路由器厂商） .
