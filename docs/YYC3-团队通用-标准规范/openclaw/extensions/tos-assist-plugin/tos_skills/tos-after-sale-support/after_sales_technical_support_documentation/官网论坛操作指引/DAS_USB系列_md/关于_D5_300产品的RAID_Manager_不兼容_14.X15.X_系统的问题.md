# 关于 D5 300产品的RAID Manager 不兼容 14.X15.X 系统的问题

故障排除

适用机型
D5-300

问题分析
由于MacOS的更新，导致 D5-300 设备的 专用软件 RAID Mnanger 无法在MacOS 14.X/15.X运行。

解决方法
您可以采用以下方法解决问题：
1.将 D5-300连接到 Windows OS运行RAID Manager或连接到MacOS 14.X之前的 版本运行。
2.如果您的MacOS 14.X以上的版本建议在Windows OS上使用 RAID Manager 创建RAID模式后在返回MacOS 14.X以上格式化分区在使用。

注意: D5-300产品是通过 RAID Manager 管理软件创建及修改阵列模式，若您不需创建或修改阵列，则 D5-300产品依然可以在 Mac 电脑上使用。
