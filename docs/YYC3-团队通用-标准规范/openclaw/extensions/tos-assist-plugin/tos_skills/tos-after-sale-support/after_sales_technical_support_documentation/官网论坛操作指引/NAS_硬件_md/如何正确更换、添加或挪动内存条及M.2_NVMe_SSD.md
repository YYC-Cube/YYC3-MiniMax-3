# 如何正确更换、添加或挪动内存条及M.2 NVMe SSD？

适用版本: 所有版本

适用机型：所有x86机型

操作步骤：

一、 关闭TNAS设备，并拔掉连接TNAs设备的电源线，确保设备完全断电，再等待1-3分钟。

二(a)、更换或添加内存条

1、使用螺丝刀打开TNAS外壳后，找到内存条插槽的位置。

2、轻轻按下内存条两侧的卡扣，取出内存条。

3、将新内存条对准插槽，确保缺口位置正确，然后均匀用力按下，直到两侧卡扣自动扣紧。确保内存条完全插入且牢固固定，避免松动导致接触不良。

二(b)、更换或添加M.2 NVMe SSD

1、使用螺丝刀打开TNAS外壳后，找到M.2 NVMe SSD插槽的位置。

2、拧下M.2固定螺丝，将M.2 NVMe SSD对准插槽，插入并按压到位，然后拧紧固定螺丝。

三、重启TNAS设备

将设备外壳重新安装好，确保所有螺丝拧紧，外壳无松动。插上电源线，重启TNAS设备即可。

注意事项：在购买新内存或M.2 NVMe SSD前，请确认其与NAS设备的兼容性。建议选择官方推荐的型号。参考官网兼容性列表：
https://www.terra-master.com/global/compatibility/
