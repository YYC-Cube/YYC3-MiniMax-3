# 如何向TNAS内增加盘?

**关键词：TOS、TNAS、控制面板、存储池、RAID、在运行时直接添加硬盘**

**解决方案：**

TNAS的SATA插槽支持热插拔，可在运行时直接添加硬盘。

操作步骤：
1. 将新硬盘直接插入TNAS的空闲SATA插槽（设备运行时可操作）
2. 等待系统检测到硬盘（约10-30秒）
3. 前往 TOS Web > 控制面板 > 存储管理
4. 选择新硬盘，决定用途：
   - 创建新存储池/卷：将硬盘作为独立存储使用
   - 添加到现有存储池：扩展现有存储池容量（需RAID类型支持）
   - 用作Hyper Cache：作为缓存加速盘
   - 用作热备盘：作为备用盘自动替换故障盘
