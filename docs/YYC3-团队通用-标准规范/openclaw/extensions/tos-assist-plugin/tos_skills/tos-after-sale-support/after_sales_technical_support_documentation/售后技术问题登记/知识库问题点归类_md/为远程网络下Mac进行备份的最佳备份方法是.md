# 为远程网络下 Mac 进行备份的最佳备份方法是？

可用的方法有很多，您可以考虑 VPN+SMB 网络磁盘+TimeMachine 的方法。

您也可以考虑 TNAS PC 内置的 TerraSync 备份工具。您可以通过 TNAS. Online 网络进行远程访问，也可以自己映射 8023 端口进行远程访问。
