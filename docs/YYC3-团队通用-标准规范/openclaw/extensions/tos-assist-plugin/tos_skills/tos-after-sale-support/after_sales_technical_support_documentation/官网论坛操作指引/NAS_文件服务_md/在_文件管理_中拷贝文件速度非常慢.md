# 在 文件管理 中拷贝文件速度非常慢？

操作指引

适用机型：所有TNAS 型号

当您在使用TOS 桌面上的 “文件管理” 来拷贝文件时，速度非常慢？ 只有5~10MB？

TOS 桌面上的 “文件管理” 是一款基于浏览器的网页版文件管理工具，该工具的目的是为了方便用户在使用电脑远程访问TNAS 时对文件进行管理，但是该工具并不适合用来做大数据的传输或批量的文件管理。众所周知，在网页上传输大文件常常会遇到速度慢，中断，甚至是崩溃等问题。

当您需要传输10GB 以上的文件时，或需要批量上传上百个文件时，不建议您使用TOS 桌面上的 “文件管理”。此时，建议您改用SMB，APF, 或者NFS 文件服务。

如您是Windows 用户，如需使用smb文件服务，在文件浏览器中输入 //TNAS IP 地址，如：//192.168.0.10

win_fileexplorer.png

如您是Mac 用户，如需使用SMB文件服务或AFP 文件服务，在 Finder 中输入 smb://TNAS IP 地址, 或者 afp://TNAS IP 地址， 如：smb://192.168.0.10, 或者 afp://192.168.0.10

不论您是Windows 用户或者是Mac 用户, 都可以在您的电脑上安装TNAS PC 应用，点击 TNAS PC 页面上 “文件” 选项就可以使用smb文件服务。

您可以将您常用的文件夹映射成一个网络驱动器，这样使用起来更方便快捷。
如您需映射网络驱动器，您可以在Windows 文件浏览器中点击 “映射网络驱动器”，或者在TNAS PC 页面中点击 “映射网络磁盘”。
