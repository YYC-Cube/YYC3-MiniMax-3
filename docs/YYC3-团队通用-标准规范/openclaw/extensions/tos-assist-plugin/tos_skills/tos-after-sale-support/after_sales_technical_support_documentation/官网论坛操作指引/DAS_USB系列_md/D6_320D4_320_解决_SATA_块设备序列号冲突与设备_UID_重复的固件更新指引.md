# D6 320D4 320 解决 SATA 块设备序列号冲突与设备 UID 重复的固件更新指引

目的：
解决 SATA 块设备序列号冲突与设备 UID 重复的问题，确保主机能够正确识别USB 设备并通过 USB 接口向SATA 块设备发送指令。

适用机型：
D6-320/D4-320

升级固件前的注意事项：
1. 升级固件不会影响或改变你的 TDAS 设备的数据，但为了安全起见，依然建议备份你的数据。
2. 请在升级前从你的 Windows PC 的 USB 端口移除其他设备，以避免在升级过程中造成损坏。
3. 警告！ASM105xMPTool 程序工具页面的参数绝不能被更改，否则硬盘驱动器控制器更新软件会造成损坏。

升级软件的准备工作：
1. 准备一个备用硬盘。
2. 升级软件需要在Windows操作系统上运行。
3. TDAS设备中至少需要安装一个硬盘，以达到被控制器识别的目的。
4. 如果你只有一个硬盘，升级完成后，将其替换到另一个插槽，然后点击继续升级软件。

MPTool_programme工具下载：
https://download3.terra-master.com/Docu ... 20Tool.zip

升级步骤：
1. 进入MPTool_programme工具文件夹，双击打开ASM105xMPTool程序工具。
2. 点击页面中的锁定图标，在登录对话框中输入asmedia，点击确定。
3. 点击FW浏览器，MPTool_programme工具文件夹中的210830_D1_63_F7.bin。
4. 点击开始图标升级，注意！升级前，您需要打开TDAS并将其连接到计算机的USB端口。

5. 等待更新完成，显示PASS状态，所有硬盘控制器完成您准备使用的更新。

6. 升级所有硬盘插槽后，您的 TDAS 就可以使用了。
