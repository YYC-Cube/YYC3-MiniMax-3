# 如何将HDMI显示器连接到TerraMaster Thunderbolt 3存储设备？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=300

操作指引

适用机型：
TerraMaster TD2雷电3 / D2雷电3（D2-330）
TerraMaster D4雷电3（D4-330）
TerraMaster D5雷电3（D5-330）
TerraMaster D8雷电3（D8-330）

由于配备了DP接口和Thunderbolt 3接口，因此TerraMaster Thunderbolt存储设备最多支持3个屏幕的4K多屏显示。
displayconnection.png
只有一台带有HDMI接口的显示器，可以将其连接到TerraMaster Thunderbolt存储设备吗？ 当然，使用以下解决方案，您就可以将HDMI显示器连接到TerraMaster Thunderbolt存储设备了。

1.单独购买一个USB Type-C转HDMI适配器；
2.单独购买一个Displayport转HDMI适配器；
注意：针对Displayport转HDMI的转换器，部份Displayport转HDMI的转换器与TerraMaster设备不兼容。 当前没有兼容列表可供您参考。
