# 我能否通过远程/手机应用程序访问并查看我的监控摄像头画面？

**关键词：DDNS、TOS、TNAS、Web界面、APP、应用程序**

**解决方案：**

手机端App限制：
- TNAS mobile App不支持直接查看监控摄像头画面

变通方案：
1. 通过浏览器访问（推荐）：
   - 启用TNAS远程访问（TNAS.online或DDNS）
   - 通过手机浏览器（包括Safari、Chrome等）登录TOS Web界面
   - 打开 Surveillance Manager 即可查看摄像头画面
2. 电脑远程访问：使用电脑浏览器远程登录TOS，查看监控画面

注意：确保Surveillance Manager服务已启用，且摄像头已正确添加和配置
