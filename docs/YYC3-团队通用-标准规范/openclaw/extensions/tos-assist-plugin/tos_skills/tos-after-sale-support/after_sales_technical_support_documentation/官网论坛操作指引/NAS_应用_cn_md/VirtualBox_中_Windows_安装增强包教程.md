什么是 VirtualBox 增强包？
VirtualBox 增强包是一个可选的组件，它为 VirtualBox 虚拟机提供了额外的功能和改进。这个增强包通常包括对虚拟机硬件的支持和一些高级特性，以提升虚拟机的性能和用户体验。
例如：由于包含了对鼠标、显示和其他硬件的优化驱动，安装后可以显著改善鼠标在虚拟机中的表现。

安装方法
1、设置已经安装好的虚拟机，如果应用安装在卷1，则可选择/Volume1/@apps/virtualbox/share/virtualbox/ 中的 VBoxGuestAdditions.iso:


2、进入Windows 文件管理中的CD驱动器，根据系统架构选择对应的程序安装，Windows 11 可以安装 VBoxWindowsAdditions，安装后重启虚拟机并使用桌面控制程序重新连接。
