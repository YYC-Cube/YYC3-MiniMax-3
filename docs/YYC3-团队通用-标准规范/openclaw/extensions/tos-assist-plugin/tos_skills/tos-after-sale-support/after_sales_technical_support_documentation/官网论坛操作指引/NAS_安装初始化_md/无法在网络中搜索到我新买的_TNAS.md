# 无法在网络中搜索到我新买的 TNAS？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=2745&sid=df318c2657b676e1a07d8bad1baa14ba

适用型号：所有TNAS 型号

故障现象：
新购买的TNAS 设备并未安装系统，您首先要将新买的TNAS 设备经过初始化，并安装TOS 系统才可以正常使用。在初始化系统前，您需要获取到TNAS 设备的IP 地址，并在电脑浏览器（推荐使用谷歌浏览器或者苹果Safari）的地址栏中输入TNAS 设备的IP 地址以访问系统的设置页面才可以进行初始化。

由于某些原因，您可能无法在网络中搜索到TNAS 设备，即无法获得它的IP地址，从而无法进行初始化，如果这种事情发生，请您参照以下指引进行故障排除。如果您的TNAS 已经使用了一段时间，但突然在网络中搜索不到设备，多数情况是因为您的TNAS 断网或者死机了，您需要参考其他指引进行故障排除。

故障原因：
搜索不到设备的原因有多种，例如：设备硬件故障，系统未正常启动，网络未正确连接，TNAS 被防火墙或杀毒软件封锁。请参照以下指引逐一排除故障。

在排除故障前：
首先您需要依照官方的快速安装指引 将您的 TNAS 逐步安装设定好，确保您的TNAS 已经正确连接到网络，正确安装硬盘，并且已经正常开机。

设备故障排除：
请检查以下事项确保您的设备不存在故障，确保设备的引导系统已经正常启动。

1.  查看电源适配器是否正常工作。如果电源正常工作，适配器上的电源指示灯会长亮绿灯。
2.  设备是否正常通电。设备正常通电时，按下开机按钮，电源指示灯会亮起。
3.  检查设备线路是否工作正常。开机后，电源指示灯与硬盘灯会绿色长亮，网络指示灯会闪亮（有的型号网络指示灯在设备的背面）；
4.  检查设备引导系统是否正常启动。如果设备正常启动，开机的5秒钟后您应该会听见“滴” 的一声蜂鸣器响声。 开机 20 秒后，您应该听见 “滴，滴，滴” 三声蜂鸣器响声（只有未安装过系统的设备才会发出三声响声，如果已经初始化过，安装过系统的设备则不会发出这三声响声）。
5.  如果您自行添加了内存条，请将您添加的内存条移除后再尝试一次。
6.  排除是否由于硬盘故障导致系统无法启动。请移除所有硬盘，将系统重新启动后再尝试一次（即空机开机）。

如果以上事项均工作正常，说明您的设备不存在故障，引导系统已经正常启动，请参照后续的指引进行其他事项的排除。否则，请联系我们的客服进行进一步的故障排除或者更换设备。

网络故障排除：

1.  检查网线是否正确连接到路由器或者交换机。为了排除网线故障，您可以尝试更换一条网线后再试试。
2.  检查您的路由器是否启用了 DHCP 服务器。如果您的网络内没有正常工作的DHCP 服务器，TNAS 无法分配到IP 地址。
3.  检查你的电脑与TNAS 是否在同一个网络内。如果您的电脑与TNAS 连接到不同的路由器或者交换机下，您的设备将无法被搜索到。
4.  如果您的电脑或者网络中有设置了防火墙、安全系统或者杀毒软件，请检查您的TNAS 是否被这些软件封锁。如果有，您需要将您的TNAS 从封锁清单中移除；或者，您可以短暂停用您的防火墙或者杀毒软件，待初始化完成您的TNAS 后再重启启用他们。

尝试使用不同的搜索工具：
如果您已经完成上述事项的检查，并且全部事项均属于正常，您可以通过几种不同的方法来搜索您的设备。以下提供几种常用的方式，您可以分别尝试。

1.  在您的浏览器的地址栏中直接输入: http://tnas.local (该方法仅针对未初始化的设备有效，由于初始化后的设备名称已经被改变，该方法是无效的）。
2.  在您的 Windows 或者 macOS 电脑上安装TNAS PC 客户端，使用TNAS PC 客户端来搜索。推荐使用 TNAS PC 5.0.33 或者之后的版本。在安装 TNAS PC 客户端时，如果您是 Windows 用户，Windows Defender 提示您是否信任该软件时，您一定要选择 “信任”；如果您是macOS 用户，如果系统提示您“您安装的软件来自非信任的发布者”，您需要在macOS 的 “系统设置 > 安全与隐私” 中运行该客户端运行。 TNAS PC 5.0.33 for Windows OS  / TNAS PC 5.0.41 for macOS
3.  通过路由器来查找。您可以登录您路由器的管理页面，通过查找已连接的设备获得TNAS 的IP 地址。
4.  使用第三方工具 "Advanced IP Scanner"。下载 Advanced IP Scanner for Windows
