# TOS 网页一致显示加载中。

如果您是初次使用，可能是存储池 RAID 正在同步中，此时盘的读写 IO 占用很高，可能会影响系统的正常运行。（常见于 TOS5 及之前的版本和性能不佳的盘）您可以尝试重启或等待同步结束后重启以恢复访问。如果等待时间太长，不排除是盘异常或系统异常。您可以考虑重置系统，再观察下情况：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=423
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=241
  

如果您使用的是 TOS4，有可能是文件系统错误引起的，您可以尝试修复文件系统：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=2575
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=1691
  

如果您在登录终端方面遇到无法登录的困难，可以考虑重置系统，并在管理员初始化界面停留，使用默认的 admin/admin 登录，并切换为 root 账户。
