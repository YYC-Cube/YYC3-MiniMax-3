# Mac电脑用户如何访问TNAS的共享文件夹？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=264&sid=048e1debfe835733a17dfc037a28fa77

Mac电脑用户访问TNAS共享文件夹的方式有以下几种：

方式一: 通过TNAS桌面客户端访问。
点击文件管理，输入用户名及密码便可对TNAS的共享文件夹进行文件管理。用户可以选择以管理员（admin）的身份登陆，也可以选择其他用户身份登陆。

方式二: 通过IP地址访问。
在Mac电脑桌面上点击 前往 > 连接服务器,在服务器地址中, 输入afp://NAS的IP 或者smb://NAS的IP, 例如：afp:// 192.168.1.100 或者smb:// 192.168.1.100，点击连接。在下一个菜单中输入用户名及密码便可访问TNAS的共享文件夹。
