# 如何排查 TNAS 负载过高导致运行堵塞的问题？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4764&sid=91960374e52a8fba318a0aab4711ff91

适用型号
所有 TNAS

适用系统版本
TOS 5.1 或 TOS 6.0

故障现象
登录 TOS 系统后，明显感觉到系统卡顿，操作反应迟缓。打开TOS桌面看板显示为负载运行堵塞，然而CPU与内存使用率均处于正常水平，且在控制面板 > 系统信息 > 进程 查看中，也未发现任何异常高的资源占用进程。

故障原因
系统负载过高可能引发运行阻塞，主要原因涵盖以下关键指标：CPU 使用率、内存占用率、网络I/O、磁盘I/O以及磁盘性能。一旦这些指标中的任何一项出现异常，均有可能导致系统发生阻塞。

问题定位与对策
当TOS的CPU 使用率和内存使用率均为正常范围，可从以下几个方便进行排查原因。

1、查看磁盘 I/O 的使用情况，前往  TOS控制面板 >> 系统信息 >> 资源监控 >> 磁盘 I/O，查看磁盘I/O时，需要对磁盘进行读写操作（如通过SMB协议，从PC往NAS中拷贝文件）。普通HDD的I/O速度为150-280MB/S，SATA SSD的I/O速度为550MB/S，NVMe SSD I/O速度为3500MB/S。

2、磁盘性能检测，以保障磁盘的健康状况。前往 TOS控制面板 >> 存储管理 >> 磁盘 >> 更多>>性能测试，查看IOPS、吞吐量、延迟的值是否常（各项指标可参考硬盘官网提供的数据）。

3、检查网络 I/O 的使用情况，前往 TOS控制面板 >> 系统信息 >> 资源监控 >> 网络 I/O，查看网络上行与下行速度时，需要对网络接口要有操作（如通过SMB协议，从PC往NAS中拷贝文件等）

4、若经过以上所有排查步骤仍未能确定系统堵塞的原因，请联系我们的客服部门预约技术工程师进行远程诊断与分析。
