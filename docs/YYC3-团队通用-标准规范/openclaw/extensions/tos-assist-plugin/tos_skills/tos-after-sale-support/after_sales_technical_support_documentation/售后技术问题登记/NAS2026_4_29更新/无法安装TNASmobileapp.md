# 无法安装TNAS mobile app.

**关键词：DDNS、TOS、TNAS、APP、SMB、WebDAV**

**解决方案：**

系统要求：
- iOS：15.6 及以上版本
- Android：11.x 及以上版本

若设备系统版本不满足要求：

替代方案（通过其他方式访问TNAS）：
1. 使用浏览器（包括手机浏览器）访问TNAS的Web管理界面
2. 使用支持SMB协议的第三方文件管理App：
   - ES文件浏览器（ES File Explorer）
   - Solid Explorer
   - CX File Explorer
   - Amaze File Manager
3. 通过WebDAV或FTP协议访问（需在TOS中启用相应服务）
4. 若需远程访问：配置DDNS或TNAS.online，通过浏览器远程访问

注意：第三方App无法提供TNAS mobile的全部功能（如一键备份、监控查看等）
