# 使用 TNAS PC 映射网盘失败

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=504&sid=2830252e3f49fda663c79a41b721ea52

**关键词**：PC客户端、tnas pc、映射驱动器、电脑客户端、网络驱动器

---

故障排除

适用机型：
TNAS 设备

如果您使用 TNAS PC 的“映射网盘”没能成功，请按照以下步骤进行排查： 
1. 检查 SMB 服务是否已启用。请转到 TOS 控制面板–网络服务–文件服务– SMB/CIFS服务，重启该服务。稍作等待后再尝试映射网盘。
2.检查TOS登录密码中是否有英文单引号和双引号，如果存在请修改密码再尝试映射网盘。
3. 输入账号密码认证时，勾选“记住我的凭据”，否则映射的网盘会在重启电脑后消失。
4. 请检查您对该文件夹是否有读写权限，可以在TOS控制面板-共享文件夹-编辑中查看和修改权限。
5. 前往Windows-控制面板-凭据管理，删除已记住的TNAS凭据，再尝试映射网盘
6. 如果以上步骤未能解决，请使用 SMB 访问TNAS，右键选择一个文件夹，从右键列表中选择“映射网盘”。
