# 我的F2 210F4 210安装TOS4.2.05或更高版本时，一直会卡在80%！

原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=636

故障排除

适用机型：
F2-210、F4-210

适用版本：
TOS 4.2.05及之前版本

在安装4.2.05系统版本时，或在安装过4.2.05后安装其他版本，安装会重复执行，卡在80%无法完成。
解决方法：
保持 TNAS 为开机状态。
1.根据机型下载以下文件；
下载机型为 1G 内存的文件：https://dl.terra-master.com/cn/firmware.img
下载机型为 2G 内存的文件（F4-210 2G内存版）：https://dl.terra-master.com/en/firmware.img
2.使用终端工具Windows10 点击Windows+R 输入cmd打开；MAC电脑则使用terminal；
3.输入scp并按回车，需要终端服务器已内置命令集(如果不支持，将无法进行以下操作步骤)；
4.输入方法为：
scp 文件放置的路径 root@192.168.1.100:/tmp/  再输入密码
例子：scp  C:\Users\Administrator\firmware.img  root@192.168.1.100:/tmp/
图片1.png
5.再使用终端工具登录NAS的设备终端SSH 如putty
6.登录连接NAS 设备终端后，输入cd /tmp/  按回车
7.再输入 up.sh  按回车
图片2.png
8.等待内核刷新完成，约十五分钟.
