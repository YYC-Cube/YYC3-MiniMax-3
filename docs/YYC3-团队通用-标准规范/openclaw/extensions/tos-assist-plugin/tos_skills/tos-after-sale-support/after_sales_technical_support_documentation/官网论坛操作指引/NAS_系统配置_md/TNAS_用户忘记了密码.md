# TNAS 用户忘记了密码？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=265&sid=91960374e52a8fba318a0aab4711ff91

操作指引

适用机型：所有 TNAS 型号

管理员及普通用户：
忘记密码可以使用注册了的密保邮箱重置密码，请点击TOS登录页面的“忘记密码”, 在弹出的对话框中输入用户名和密保邮箱，使用验证码按指引完成密码重置。如果是普通用户，请联系您的管理员帮你重置密码。

无法获得验证码？
如果您是管理员，而且没有设置密保邮箱或密保邮箱无法收到验证邮件，这种情况下您只能重装 TOS 系统了。重装系统一般不会影响硬盘中的数据，但为了安全起见，强烈建议您提前备份数据。

重装步骤如下：
1.  先将 TNAS 设备关机，并拔出所有硬盘；
2.  再将设备空机开机（不要插入硬盘）；
3.  在电脑上运行 TNAS PC，使用 TNAS PC 搜索您的TNAS 设备。从列表找到名为 TNAS的设备，点击"登录"；
4.  在系统提示您未检测到硬盘时再插入所有硬盘，点击"重新检测"；
5.  选择安装新的 TOS 系统；
6.  根据提示完成 TOS系统的安装；
7.  设置管理员用户新的密码及密保邮箱，点击确认完成；
