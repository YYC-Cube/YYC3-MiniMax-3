# TOS 4 较老版本的系统更新说明

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=968&sid=df318c2657b676e1a07d8bad1baa14ba

由于更新较快，最新版本的TOS系统与较老的版本已经发生了很大的变化，如果直接将较老版本的TOS更新到最新版本有可能会出现失败，部分功能与应用无法兼容。如果您的系统属于较老的版本，请参照以下内容采用分步逐级更新。

x86型号：
F2-220、F2-221、F2-420、F2-421、F4-220、F4-221、F4-420、F4-421、F5-220、F5-221、F5-420、F5-421、F8-421

当您的TOS系统版本低于TOS4.0.00时：
由于你的TOS系统太旧，请备份数据，然后安装新版本的TOS系统。
https://forum.terra-master.com/cn/viewt ... f=85&t=628

当您的TOS系统版本处于TOS4.0.XX---TOS4.1.00之间时：
您的当前版本 --> 4.1.03-->4.1.27--> 4.1.31-->自动更新  分步逐级更新；

注意事项：
由于TOS系统版本跨度太大，更新过程有可能数据丢失的隐患，请提前备份一下相关资料；更新之后，应用需重新安装才能使用；
更新完成后，如部分文件夹无法显示，请前往TOS控制板》共享文件夹》高级》恢复共享文件夹；
更新TOS4.1.03，停留在73%时，请耐心等待10分钟左右，再刷新页面。

arm 210型号：
F2-210、F4-210

当您的TOS系统版本低于4.1.07时：
 您的当前版本 -->  4.1.07 --> 4.1.27  --> 4.1.32 -->4.2.08-->自动更新到最新版本（4.2.xx），分步逐级更新；

当您的TOS系统版本低于4.1.26时：
 您的当前版本 -->  4.1.27  --> 4.1.32 --> 4.2.08 --> 自动更新到最新版本（4.2.xx），分步逐级更新；

注意事项：
由于TOS系统版本跨度太大，更新过程有可能数据丢失的隐患，请提前备份一下相关资料；更新之后，应用需重新安装才能使用；
更新完成后，如部分文件夹无法显示，请前往TOS控制板》共享文件夹》高级》恢复共享文件夹；
