# 哪些能做阵列，哪些不能?怎么做阵列，做了阵列有什么注意事项，比如能不能热插拔

答：身自带USB系列支持RAID型号：D2-320/D5Hybrid（HDD1/2槽位）/ D8Hybrid（HDD1/2槽位）/D5-300/D5-310

本身自带雷电系列支持RAID型号：TD2 THUNDERBOLT 3/ TD5 THUNDERBOLT 3/ TD16 THUNDERBOLT 3/D8-332

无自带RAID软件型号：D4-320/D6-320/D9-320/D4-320U，这些型号本身不支持RAID功能，但是能支持第三方RAID软件，例如Windows存储空间、MacOS RAID助理、TrueNAS、Proxmox Virtual Environment 8.3 系统中使用外置的USB设备创建ZFS存储池、飞牛系统、麒麟系统_版本2303、统信专业版2500
