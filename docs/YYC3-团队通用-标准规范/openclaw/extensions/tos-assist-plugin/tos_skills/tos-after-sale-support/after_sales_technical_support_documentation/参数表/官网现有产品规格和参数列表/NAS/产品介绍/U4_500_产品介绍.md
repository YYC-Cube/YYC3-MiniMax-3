# U4-500 一体化备份服务器

## 铁威马BBS商用备份套装

### 核心特点

- **第十二代强劲处理器**：\
  U4-500 1U四盘位NAS服务器搭载酷睿 i3-1215U
  处理器（6核8线程，最高睿频4.4GHz），提供商用级性能表现。

- **新一代 DDR5 内存**：\
  配备 8GB DDR5 内存，确保多任务流畅运行，轻松应对高负载工作需求。

- **NVMe 加速性能**：\
  配备双 M.2 NVMe
  插槽，结合超级缓存技术显著提升存储效率，实现更快的备份与数据访问速度，是性能导向型中小企业的理想之选。

- **先进硬件加速技术**：\
  集成英特尔超核芯显卡（1.1GHz）与 AES-NI
  硬件加密引擎，实现安全高效的数据处理加速。

- **双万兆网络连接**：\
  配备双 10GbE 端口，提供 20Gbps 聚合带宽，并支持 SMB
  多通道技术，实现极速数据传输。

- **企业级存储性能**：\
  可实现 2090MB/s 顺序写入与 450MB/s 4K 随机读写性能，完美适配 4K
  视频制作及虚拟化等高要求应用场景。

- **灵活 RAID 配置**：\
  支持 RAID 0/1/5/6/10、TRAID 及 TRAID+
  阵列模式，支持在线容量扩展且无需停机。
