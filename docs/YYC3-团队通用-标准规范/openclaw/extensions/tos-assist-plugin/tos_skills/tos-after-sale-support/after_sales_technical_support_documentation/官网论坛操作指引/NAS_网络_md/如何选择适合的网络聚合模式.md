# 如何选择适合的网络聚合模式

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3582&sid=51493c53a160f99b97633ae2f702b6b5

网络聚合（Bond）：用于将多个物理网络接口捆绑在一起，形成一个逻辑上的虚拟接口，通过聚合可以增加网络吞吐量、提高负载均衡和故障容错能力。

适应性负载均衡：
不需要特别的交换机支持的通道，根据每个slave的负载情况选择slave进行分配外出流量。接收负载均衡是通过ARP协议实现的，如果正在接受数据的slave出故障了，则另一个slave接管失败的slave的mac地址。

IEEE 802.3ad动态链接聚合：
需要支持IEEE 802.3ad动态链路的交换机，采用LACP协议，并且所有成员共享相同的速度和双工设置。
注意：启用 IEEE 802.3ad 的步骤根据交换机的不同而有所变化。您应该查阅交换机说明文档，确定启用交换机中的 LACP 必须执行的起始步骤。

XOR 平衡策略：
用于在聚合组的成员链路之间分配数据流量，它基于异或（XOR）操作来确定数据流量应该通过哪个成员链路进行传输。聚合组的成员链路按照预先规定的顺序编号，通常从 0 开始。XOR 运算的结果被映射到这些编号上，决定了传输路径。此模式提供负载平衡和容错能力

活动-备用：
此模式只有一个接口是只为活动，其他的接口都处于备份状态，如果活动中的接口出现故障，则备用的接口将替换为聚合组中活动的接口。

根据不同的使用场景，您可以合适的聚合模式来满足您的需求，在配置网络聚合时，请确保参考官方文档或相关指南，以确保正确实施并获得最佳性能和稳定性。
