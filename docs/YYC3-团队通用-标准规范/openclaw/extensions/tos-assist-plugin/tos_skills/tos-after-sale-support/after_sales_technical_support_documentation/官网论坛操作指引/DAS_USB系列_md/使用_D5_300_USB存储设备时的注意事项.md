# 使用 D5 300 USB存储设备时的注意事项

注意事项

适用型号:
D5-300

如果您是 TerraMaster USB 存储设备的新用户，请注意以下问题:
1.  请勿在访问硬盘时将硬盘拔出；
2.  该设备不支持热插拔。因此，在每次更换硬盘之前，请先从计算机安全弹出设备；
3. 在关闭设备或与计算机断开连接之前，请确保先将其卸载并安全弹出。否则会存在数据丢失的风险；
4. 当您关闭电脑、休眠电脑、弹出USB设备或拔下 USB 接头时，设备将自动进入休眠模式；当您再次访问硬盘或连接USB设备时，设备将退出休眠模式。
5.  特别注意:设备支持热备盘功能。创建 RAID 后，所有不参与 RAID 的其他硬盘将被视为热备盘。一旦 RAID 的硬盘出现故障，其他硬盘将作为备用盘添加到 RAID，并且该硬盘上的所有数据都将丢失。因此，请不要将数据存储在独立驱动器中！
