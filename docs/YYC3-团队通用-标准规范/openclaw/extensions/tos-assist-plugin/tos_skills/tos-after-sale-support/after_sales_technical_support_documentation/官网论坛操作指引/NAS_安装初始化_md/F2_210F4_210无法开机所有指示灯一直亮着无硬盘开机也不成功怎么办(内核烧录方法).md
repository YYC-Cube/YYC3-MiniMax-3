# F2-210 / F4-210无法开机，所有指示灯一直亮着，无硬盘开机也不成功怎么办？(内核烧录方法)

原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1219

故障现象
ARM 设备升级TOS系统后，使用TNAS PC客户端无法搜索到TNAS 设备，且TNAS设备上的所有指示灯常亮。

原因
1.TOS系统升级不成功，导致TNAS设备的内核软件升级不完整。
2.在安装和升级TOS系统时，停留在98%为内核升级，但进程中断或者设备断电情况，导致内核未升级成功，设备开机异常

对策
需要安装内核，设备才能正常使用

适用机型:F2-210、F4-210

TNAS 设备为空机(无硬盘)状态下操作

TNAS设备内核软件安装的方法：
1.下载以下文件
下载机型为 1G 内核文件：https://dl.terra-master.com/cn/firmware.img
下载机型为 2G 内核文件（F4-210 2G内存版）：https://dl.terra-master.com/en/firmware.img
2.将一块U盘重新格式化为 FAT32 文件系统；
3.将firmware.img文件放至到U盘内；
4.把U盘插入到 TNAS 设备背部的USB 接口；
5.将TNAS设备接入路由器上（能访问到互联网）；
6.接通电源，按电源键开机；
7.等待自动安装，静止放置约15分钟左右;
8.安装完成后，TNAS设备将自动关机;
9.最后再按电源键开机，重新安装TOS系统。

备注:
1..安装内核过程中，请勿断电和关机;
2.U盘可用容量不可小于15MB，文件系统必须使用FAT；
3.内核安装失败，请更换另外一个USB接口，再做尝试；
4.少数设备接通电源后自动开机，不需要再按电源键开机。
5.安装内核过程中，请勿断电和关机。
6.若安装过 TOS 4.2.06及之后版本，请将”firmware.img“更改为”firmware_1g.img“ 或者“openwrt-rtd1295-nas_spi-rtk-spi-8M-initrd-sysupgrade.bin”
