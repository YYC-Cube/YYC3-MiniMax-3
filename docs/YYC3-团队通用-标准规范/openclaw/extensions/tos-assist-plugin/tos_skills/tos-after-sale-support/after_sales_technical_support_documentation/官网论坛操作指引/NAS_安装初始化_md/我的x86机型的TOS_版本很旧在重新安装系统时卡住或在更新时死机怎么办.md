# 我的x86机型的TOS 版本很旧，在重新安装系统时卡住，或在更新时死机怎么办？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=628&sid=cd797fee55a7adc920bb07134fd62706

操作指引

适用机型(x86)：
F2-220、F2-420、F4-220、F4-420、F5-220、F5-420、
F2-221、F2-421、F4-221、F4-421、F5-221、F5-421、F8-421、
F5-422、F8-422、
F5-225

适用版本：
TOS4.x，TOS3.x

在安装最新 TOS4系统或重装 TOS4系统时，由于部分X86设备InitBoot版本过低，在安装界面可能会出现卡在11%或55%的情况。若遇到该问题，请按照以下步骤尝试解决：

1. 在没有硬盘的情况下开机，在初始化界面的“右下角”或“左下角”找到Initboot版本；

2. 根据自己的Initboot版本，选择适合的安装版本：

Iniboot版本在V3.2以下：需要联系售后技术支持远程处理

Iniboot版本在V3.2 - 3.8：可安装 TOS_4.1.03https://dl.terra-master.com/cn/TOS_S2.0 ... 03_294.ins

Iniboot版本在V4.0 - 4.5.1：可安装 TOS_4.1.27https://dl.terra-master.com/cn/TOS_S2.0 ... 301431.ins
(安装4.1.27版本可以更新您的U盘引导系统,从而可以安装更高的TOS版本.
由于4.1.27不兼容旧版本的非 LVM 存储结构,安装完成4.1.27后,建议立即关机并继续重装下一个版本,而不要在4.1.27设置账号并使用.)

Iniboot版本在V4.5.5 - 4.8.6：可安装 TOS_4.1.31https://dl.terra-master.com/cn/TOS_S2.0 ... 061157.ins

然后您可以重装到最新的 TOS 4.2.x 版本。

3. 在安装了合适的版本后，Initboot也会随之更新，此时，如果需要再次安装更高版本的系统，可以重复1、2步骤。
