
## 产品型号

D2-320

## 故障现象

连接Window11台式机，拷贝大文件的时候就会掉盘，硬盘直连主板的SATA口就不会出现这种问题，有提示usb弹出，过一会又自动连接，使用原装数据线，也用过其他家的线，试了主板的后置c口和前置c口，都会出现这个问题。看了任务管理器，只要硬盘占用到100，就会掉盘，然后文件就打不开了，数据指示灯就边常亮，不闪烁了.目前还可以怎么排除验证，前2天使用没有问题，第3天才出现的

报错：无法访问 F:\banjing2cmjingduyanzheng\0.5cm 0.1 10cm，指定不存在的设备。

## 排除方法

排除方法；
可能是电脑 USB 接口信号偏弱导致，建议按以下方法排查：
1.先与客服确认，是否使用官方最新 USB-C 同轴线材。
2.可在电脑 USB 接口外接USB HUB 扩展坞转接后再尝试使用。
