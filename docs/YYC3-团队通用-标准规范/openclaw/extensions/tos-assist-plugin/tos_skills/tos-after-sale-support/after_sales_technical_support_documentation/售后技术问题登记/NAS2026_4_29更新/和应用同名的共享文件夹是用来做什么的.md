# 和应用同名的共享文件夹是用来做什么的?

**关键词：TOS、控制面板、共享文件夹**

**解决方案：**

与应用同名的共享文件夹是应用安装时自动创建的数据目录。

用途说明：
- 存储该应用的配置、数据库、用户数据等文件
- 例如：安装WordPress会创建"wordpress"共享文件夹，用于存储网站数据

重要注意事项：
1. 不要手动删除此文件夹，否则可能导致应用无法正常运行或数据丢失
2. 如需卸载应用并清理数据：
   - 先前往 TOS Web > 应用中心，卸载对应应用
   - 应用卸载后，再前往 TOS Web > 控制面板 > 共享文件夹，删除对应文件夹
3. 建议定期备份这些应用数据文件夹，避免数据丢失
