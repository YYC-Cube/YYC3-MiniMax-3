## 核心特性

### 强劲硬件配置

- 搭载英特尔 N95 四核四线程处理器（基准频率3.4GHz/睿频加速）
- 集成 0.75GHz UHD 核芯显卡
- 配备 8GB DDR5 4800MHz 内存（非ECC，最高可升级至32GB）
- 双2.5G以太网端口
- 双M.2 NVMe SSD缓存插槽

### 应用性能跃升

- 搭载强劲处理器与DDR5内存，实现较前代产品140%的性能飞跃
- 应用加载提速90%
- 文件与照片检索加速40%
- 数据库响应提升50%
- 网页PHP处理性能提升60%
- 以无缝高负载表现全面提升工作流效率

### 高速连接能力

- 配备双2.5GbE接口，实测线性传输速度达283MB/s
  - 测试环境：4×18TB NAS专用硬盘组建RAID 0
- 链路聚合可实现5Gb网络带宽
- 完美支持多用户高并发访问
- 双USB 3.2 Gen2 10Gbps接口使NAS与外部设备间数据传输迅捷如飞
- 支持RAID 0/1/5/6/10/JBOD/单盘及TRAID等多种阵列模式

### 便捷 M.2 SSD 安装

- 采用侧滑式盖板设计，可快速简易安装固态硬盘
- 手拧螺丝的加入使安装过程轻松无忧
- 配备免工具硬盘托盘，硬盘安装无需额外工具
- 结合创新的 Push-Lock 锁定机制，插入硬盘即自动固定
- 有效防止意外松动或脱线问题
