# Thunderbolt 3设备在Mac Studio电脑上使用的注意事项

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3223

适用型号
D4 Thunderbolt3, D5 Thunderbolt3, D8 Thunderbolt3, D16 Thunderbolt3

现象及对策
如果您的Thunderbolt 3设备在Mac Studio（MAX）电脑上使用出现无法识别硬盘的故障，请注意以下事项。

1.因为存在个别用户并不知道Mac Studio（MAX）正面两个是USB-C端口，误理解为Thunderbolt 4端口，所以您连接Thunderbolt 3设备在USB-C端口是无法正常识别硬盘的。

2.Mac Studio有两个版本，MAX/ULTRA，ULTRA版本正面才具有Thunderbolt 4端口。

3.如果您是Mac Studio（MAX）用户请将Thunderbolt 3设备连接到背面Thunderbolt 4端口。
