# 铁威马 T12-450 产品介绍

## 产品概述

**T12-450**  
**为高速存储而生**

T12-450采用Intel Atom C3558R四核处理器，主频高达 2.4GHz，16 GB DDR4 双通道内存 (最高可扩展至 32 GB)，配备双 SFP+ 10Gb光纤接口，双2.5GbE接口，通过网络聚合Link Aggregation，更可提供高达20Gb的传输带宽。T12-450还配备双M.2 NVMe SSD插槽，结合铁威马Hyper Cache SSD 缓存加速技术，可加倍提升传输性能。T12-450专为需求高速存储的用户而开发，能满足4K 影像编辑、虚拟化、数据库等应用对存储性能的苛刻要求。

---

## 核心特性

### 高速存储性能

- **强劲处理器**：Intel Atom C3558R四核处理器，主频高达 2.4GHz
- **大容量内存**：16 GB DDR4 双通道内存 (最高可扩展至 32 GB)
- **高速网络接口**：
  - 双 SFP+ 10Gb光纤接口
  - 双2.5GbE接口
  - 网络聚合Link Aggregation，提供高达20Gb传输带宽
- **SSD缓存加速**：双M.2 NVMe SSD插槽，结合Hyper Cache SSD 缓存加速技术
- **专业应用支持**：满足4K 影像编辑、虚拟化、数据库等应用对存储性能的苛刻要求

### 团队协同作业

- **万兆网络搭建**：多台Windows/ Mac工作站可同时连接T12-450
- **高效协同**：多轨4K素材在线剪辑、特效制作、视频合成、镜头片段导入输出
- **提升效率**：大大提升工作效率，大幅缩减项目制作时间

### 全新一代操作系统

- **TOS 5系统**：搭载全新一代的操作系统TOS 5
- **功能增强**：与上一代系统相比，新增50余项功能，600多处改进
- **全面升级**：满足更多专业业务需求，响应速度、安全性、易用性均有重大提升

### 充沛的数据存储空间

- **大容量支持**：支持最大20TB的硬盘，总容量可达240TB
- **海量存储能力**：
  - 9000万张高清照片
  - 4800万份工作文件
  - 12万部高清电影
  - 1200万首无损音乐
- **集中备份管理**：将散落在各处的数据集中备份到TNAS中管理
- **数据安全保障**：避免硬件损坏、勒索病毒等原因导致数据丢失

### 独有Hyper Cache SSD 缓存加速技术

- **铁威马专利技术**：独有的 SSD 缓存加速技术
- **多种缓存模式**：提供多达 3 种缓存模式供选择以适应不同的使用需求
- **SSD磁盘阵列**：为 SSD 创建磁盘阵列以增加缓存速度与安全性
- **性能提升**：可提升100% 的存储性能
- **高效可靠**：打造更高效可靠的混合型存储

### 小型化紧凑式设计

- **结构优化**：通过结构优化，大大减少空间占用
- **体积小型化**：实现产品体积小型化
- **灵活摆放**：立式与卧式两用设计
- **适用场景**：适应空间有限小型商用顾客的使用需求

### 弹性化存储空间管理

- **TRAID技术**：TerraMaster RAID 的简称
- **自动管理**：自动组合磁盘空间、硬盘故障冗余保护、自动扩容
- **智能配置**：无需用户手动配置，系统根据硬盘属性自动完成配置
- **优化方案**：为用户提供优化、灵活、弹性的磁盘阵列管理解决方案
- **新手友好**：尤其适合对磁盘阵列配置不精通的新用户

### 跨平台的文件服务

- **主流协议支持**：SMB、NFS、SFTP/FTP、AFP、iSCSI、WebDAV
- **权限管理**：具备用户、用户组及文件目录的多种权限管理
- **全面兼容**：全面满足各种网络环境下的跨平台文件服务需求
