# 如何保护自己免受基于加密的勒索病毒的侵害？

如何保护自己免受基于加密的勒索病毒的侵害？

随着病毒感染的迅速传播，恶意软件感染的风险仍在不断上升。最近，我们目睹了一些针对加密的勒索病毒针对个人文件，甚至是基于网络的设备攻击案例。遗憾的是，仅仅依靠防毒软件并不能确保您的数据可以免于遭受攻击，您需要立即采取多种行动，以避免对您的重要数据造成威胁。

我们建议您采取以下对策
1. 及时更新您的计算机操作系统到最新版本；
2. 在计算机、TNAS设备和路由器上安装防病毒软件，以帮助您检测和抵御恶意威胁；
3. 谨慎打开电子邮件附件或单击来自未知来源的文件，提防带有隐藏文件扩展名的可疑文件，例如“ .pdf.exe”
4. 恶意软件通常针对使用RDP（远程桌面协议）的计算机。不使用远程访问时，请禁用RDP、SSH 和Telnet；
5. 为所有用户设置高安全级别的密码；
6. 禁用系统默认管理员帐户，重新创建一个新的管理员帐户，并设置一个高级密码；
7. 启用防火墙，仅允许信任的IP地址和端口访问您的设备; 避免使用系统默认的 5443(HTTPS)与 8181(HTTP)端口，更改为其他任意端口(5001-65535)；
8. 在您的TOS 控制面板上启用自动IP阻止功能，以阻止尝试登录失败次数过多的IP地址。
9. 备份数据是应对恶意攻击的最佳方法；始终备份数据，至少一个备份到另一台设备。强烈建议采用3-2-1备份策略；

如果不幸的是，您发现您的数据已被勒索病毒感染
1. 立即断开计算机和TNAS设备的Internet连接；
2. 恢复数据之前，请彻底清除电脑系统和TNAS中的病毒感染；您需要将TNAS恢复为出厂设置并完全格式化所有硬盘；
