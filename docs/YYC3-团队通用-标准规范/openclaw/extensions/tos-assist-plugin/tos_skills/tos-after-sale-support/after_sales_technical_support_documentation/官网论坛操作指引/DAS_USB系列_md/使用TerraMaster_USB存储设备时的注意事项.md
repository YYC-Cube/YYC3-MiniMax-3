# 使用TerraMaster USB存储设备时的注意事项

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=495

注意事项

适用机型:
D2-310
D5-300C
D5-300

如果您是TerraMaster USB存储设备的新用户，请注意以下问题:
1.  在按住重置按钮5秒钟后，硬盘上的数据将被删除。 请谨慎操作；
2.  请勿在访问硬盘时将硬盘拔出；
3. 该设备不支持热插拔。因此，在每次更换硬盘之前，请先从计算机安全弹出设备；
4.  在关闭设备或与计算机断开连接之前，请确保先将其卸载并安全弹出。否则会存在数据丢失的风险；
5.  当您关闭电脑、休眠电脑、弹出USB设备或拔下USB接头时，设备将自动进入休眠模式；当您再次访问硬盘或连接USB设备时，设备将退出休眠模式。
