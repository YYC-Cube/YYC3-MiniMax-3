# TNAS 是否能继承读取来自其它系统或其它品牌 NAS 的盘的数据？

由于不同设备类型和不同品牌 NAS 的盘的存储结构存在差异，一般无法继承读取盘数据。

满足以下所有条件，将其他品牌 NAS 的硬盘插入 TNAS 后，无需格式化即可直接读取数据，核心依赖 TOS 6.0 的直连挂载功能。

1. **TOS 系统版本**：必须为 TOS 6.0 及以上（这是直连挂载功能的基础，TOS 5 及更早版本不支持）；
   
2. **硬盘配置**：来自其他品牌 NAS 的硬盘为单盘模式 (仅支持挂载 Single 类型磁盘，不支持挂载 RAID 阵列磁盘)。
   
3. **文件系统**：当前 TNAS 支持挂载的文件系统非常广泛，包括 FAT、FAT32、NTFS、EXT2、EXT3、EXT4、ExFAT、Btrfs、HFS+ 等。
   
4. **硬盘状态**：硬盘无物理损坏、无坏道，且未被原 NAS 系统加密。
   

**具体操作步骤**

1. **安全卸载硬盘**：先关闭原品牌 NAS 设备，等待电源指示灯熄灭后，取出目标硬盘；
   
2. **插入 TNAS 设备**：将硬盘插入 TNAS 的硬盘插槽（若为M.2 NVMe SSD，需先关闭 TNAS 再插入，SATA 硬盘支持热插拔的型号可直接插入）；
   
3. **登录 TOS 系统**：通过电脑浏览器登录 TNAS 的 TOS 管理界面（输入 TNAS 的 IP 地址，输入管理员账号密码）；
   
4. **直连挂载硬盘**：进入【控制面板 → 存储管理器 → 磁盘】，在列表中找到刚插入的硬盘，点击【更多】按钮，选择 ”挂载磁盘”；
   
5. **访问数据**：挂载成功后，进入【文件管理】，即可看到挂载的硬盘目录，直接访问、复制其中的数据（注意：挂载磁盘文件系统格式为 FAT32、NTFS、exFAT 格式不支持设置权限，权限默认为：allusers。）。
