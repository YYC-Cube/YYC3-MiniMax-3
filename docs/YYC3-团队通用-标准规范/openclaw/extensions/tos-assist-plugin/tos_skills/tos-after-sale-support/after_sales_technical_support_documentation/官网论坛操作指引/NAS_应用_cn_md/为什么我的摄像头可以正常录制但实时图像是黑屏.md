# 为什么我的摄像头可以正常录制，但实时图像是黑屏

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=4215&sid=b265ad2ea5bccea440907c924ea82b46

---

适用版本：
TOS 5、TOS 6

故障现象：
在使用 TNAS 的 Surveillance Manager 应用成功添加摄像头后，虽然摄像头能够正常录制并保存录像文件，且录像回放无异常，但在实时预览摄像头画面时，出现了黑屏现象。


解决办法：
1.首先，请检查通过浏览器登陆 Surveillance Manager 时，是否使用的 https（默认端口5443）地址，需要修改为 http（默认端口8181）地址进行登录。

1.png

2.其次，请检查摄像头的编码格式是否为 H.265，需要将编码格式修改为H.264。
