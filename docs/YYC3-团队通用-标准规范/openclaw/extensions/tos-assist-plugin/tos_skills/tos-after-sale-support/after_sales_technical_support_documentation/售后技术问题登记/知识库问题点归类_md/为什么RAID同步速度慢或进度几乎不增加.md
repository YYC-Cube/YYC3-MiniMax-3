# 为什么 RAID 同步速度慢或进度几乎不增加？

很有可能是盘存在异常，建议您检查下盘的情况。关于检查盘的方法，请参考：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=1125
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=773
  

您也可以尝试收集一份系统报告发给我们检查，也许我们能帮您发现什么。TOS4/5/6 系统报告收集位置：TOS Desktop > Technical Support > Report Issues
