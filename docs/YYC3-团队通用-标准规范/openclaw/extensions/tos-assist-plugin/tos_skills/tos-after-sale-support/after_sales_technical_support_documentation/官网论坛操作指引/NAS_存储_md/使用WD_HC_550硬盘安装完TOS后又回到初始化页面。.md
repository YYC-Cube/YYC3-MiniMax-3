# 使用WD HC 550硬盘安装完TOS后，又回到初始化页面。

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3629&sid=2853efb328304e05736fc85f61407238

故障排除

适用机型
所有 TNAS 型号

问题分析
若用户使用WD HC 550系列硬盘，且硬盘的FW为233版本，在TNAS设备上安装完TOS系统后，重新会再次进入到初始化界面。我们发现FW233版本的WD HC 550系列硬盘在TNAS上使用时普遍存在问题.请您选择其他兼容型号或者选择FW680版本的WD HC 550系列硬盘.
