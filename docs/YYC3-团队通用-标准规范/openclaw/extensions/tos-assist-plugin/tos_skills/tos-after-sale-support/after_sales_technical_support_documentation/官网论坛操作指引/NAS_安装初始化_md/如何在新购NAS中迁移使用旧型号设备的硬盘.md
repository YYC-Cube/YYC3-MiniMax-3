# 如何在新购NAS中迁移使用旧型号设备的硬盘

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4603&sid=df318c2657b676e1a07d8bad1baa14ba

适用版本: TOS4/5/6

适用机型：

ARM机型：F2-210、F4-210、F2-211、F2-212、F4-211、F4-212、U4-212

Legacy启动X86机型：

F2-220、F2-221、F2-420、F2-422、F4-220、F4-221、F4-420、F4-421、F4-422、F5-220、F5-221、F5-420、F5-421、F5-422、F8-421、F8-422

UEFI启动X86机型：

F2-223、F2-423、F4-223、F4-423、F4-424、F4-424 Pro、F4-424 Max、F6-424、F6-424 Max、F8 SSD、F8 SSD Plus、U8-500 Plus、T6-423、T9-423、T9-450、T9-500 Pro、T12-423、T12-450、T12-500 Pro、U12-423、U12-500 Plus

故障原因：因旧设备故障或性能不足需购置新NAS，用户关心旧硬盘能否在新设备上直接使用。

使用场景与解决方案

场景1：同型号更换

直接将旧硬盘插入同型号的新NAS中即可。

场景2：ARM机型间互换

F2-210、F4-210间可直接互换硬盘至同型号新NAS；F2-212、F4-212、U4-212间可接互换硬盘至同型号新。

场景3：Legacy启动X86机型间互换（TOS 4.2.44至TOS 5.1.145）

列表中指定的Legacy启动X86机型间，若TOS版本符合要求，可直接互换硬盘。

场景4：UEFI启动X86机型间互换（TOS 6及以上）

列表中指定的UEFI启动X86机型间，若TOS版本为TOS 6及以上，可直接互换硬盘。

场景 5：从 ARM 机型更换至 X86 机型使用

您可以将列表中指定的 ARM 机型的硬盘卸下，并安装到已搭载 TOS 5/6 系统的 X86 机型中。完成安装后，只需重启 X86 机型，即可直接访问并读取原 ARM 机型硬盘上的所有数据。

重要提示: 迁移后，若计划对 X86 机型进行 TOS 系统的升级，请务必确保在关机状态下，先从 X86 机型中移除原 ARM 机型的硬盘。然后升级或重装 TOS 系统，仅限原X86机型上安装过系统的硬盘。操作完成后，您可按原步骤重新安装 ARM 机型的硬盘，以继续访问其上的数据。

场景6：其他情况

若不符合上述场景，需备份数据后，在新NAS上重新安装TOS系统方可使用旧硬盘。

注意：
1、若安装过程中提示格式化或删除数据，请立即停止操作。
2、若硬盘系统分区为2G，重新安装TOS系统将删除数据。请通过“TOS > 控制面板 > 系统信息 > 总览”检查“/”项下的系统分区可用空间，并提前备份数据。
