# 我安装 TNAS mobile 的手机丢失了，如何进行OTP二次验证

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=4573&sid=b265ad2ea5bccea440907c924ea82b46

**关键词**：2FA、APP登录、otp、tnas mobile、二次验证、双因素认证、手机端、手机访问、移动端、验证码

---

适用版本：TOS 5/6

适用机型：所有 TNAS 型号

问题现象：
当我安装 TNAS mobile 的手机丢失了，且该手机已绑定 OTP（One Time Password）功能，我该如何重新登录我的 TNAS 呢？

解决方法：
若您在启用 OTP 功能时绑定了密保邮箱，您可以通过该邮箱接收 OTP 验证码来登录 TNAS 系统；若未绑定密保邮箱，则需要重装 TOS 系统来重新访问您的 TNAS。

操作步骤：
1、当您尝试登录 TOS 系统并遇到需要输入 OTP 验证码的提示时，请在验证码输入页面点击“移动设备已丢失”，系统将自动向您绑定的密保邮箱发送一封含有 OTP 验证码的邮件：


2、请登录您的密保邮箱，使用邮件内的验证码完成 OTP 验证。如果验证码超时失效，请重新发送。为了保障您的账户安全，成功登录后建议您立即解绑 OTP 或使用您的新手机重新绑定 OTP 。

注意：一个账号的 OTP 二次认证服务只能绑定一台手机（TNAS mobile ）, 一台手机（TNAS mobile ）可以绑定多个 OTP
