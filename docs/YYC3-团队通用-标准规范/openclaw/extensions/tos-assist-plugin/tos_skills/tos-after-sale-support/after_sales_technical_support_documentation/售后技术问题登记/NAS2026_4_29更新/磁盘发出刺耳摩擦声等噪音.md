# 磁盘发出刺耳摩擦声等噪音.

**关键词：TOS、TNAS、控制面板、HTTPS、怎么判断硬盘噪音**

**解决方案：**

噪音判断与处理：

正常噪音（无需担心）：
- 大容量机械硬盘（4TB及以上）运行时会有一定噪音
- 读写时磁头寻道声、马达旋转声属正常现象
- 可尝试调整TNAS放置角度或垫减震垫降低噪音

异常噪音（需检查）：
- 尖锐摩擦声、敲击声、异常嘎吱声
- 建议检查工具：https://forum.terra-master.com/en/viewtopic.php?t=1125
- 检查步骤：
  1. TOS Web > 控制面板 > 盘 > SMART检测，查看硬盘健康状态
  2. TOS Web > 控制面板 > 盘 > 坏块扫描，检测物理坏道
  3. 对比互联网上相同型号硬盘的噪音样本，确认是否异常
- 若确认为异常噪音：建议备份数据并更换硬盘，避免数据丢失
