# WIN10电脑映射的网络驱动器重启电脑或TNAS设备消失？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=139&sid=048e1debfe835733a17dfc037a28fa77

WIN10电脑映射的网络驱动器在重启电脑或TNAS设备后消失？

您的WIN10 电脑有可能未保存用户凭据。请尝试以下对策：

1.前往电脑的控制面板》凭据管理器》Windows Credentials选项,找到TNAS对应的IP地址并移除。
1.jpg
2.点击“重新添加凭据”选项，然后输入TNAS设备的IP、用户名、密码，点击“确认按钮即可。
