# 将一块来自其它设备的盘放入TNAS, 但无论是修复,迁移,扩容都不起作用.

**关键词：TOS、TNAS、无法识别、**

**解决方案：**

原因：来自其他设备的硬盘可能含有特殊的启动分区或头部信息，TNAS无法识别或操作。

排查步骤：
1. 检查新盘：该盘可能含有其他NAS/设备的特殊分区，建议：
   - 使用磁盘工具（如Windows磁盘管理、DiskGenius等）删除或清除所有分区
   - 清空后重新插入TNAS尝试
   - ⚠️ 注意：清除分区会删除所有数据，请先备份
2. 若新盘确认无问题：可能是TNAS内已有硬盘异常
   - 检查TNAS内硬盘健康状态（SMART检测）
   - 尝试逐一排查哪些盘可能导致问题
3. 若问题持续：联系人工客服，提供详细操作步骤和错误信息
