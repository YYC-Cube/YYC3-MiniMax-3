# F2 210F4 210 内存使用率偏高

故障现象
F2-210/F4-210产品安装TOS系统后，不做任何操作，提示内存的使用率持续高达50%。

原因
GPU 占用了部分显存，需要释放该内存。

适用机型:F2-210、F4-210

释放内存操作方法

1.下载文件
机型为 1G 内存需要下载的文件：http://dl.terra-master.com/cn/firmware.img
机型为 2G 内存需要下载的文件：http://dl.terra-master.com/en/firmware.img
2.将该文件传到TNAS设备的public目录下
3.使用root帐号通过SSH协议登录TNAS后台
4.将上传的文件复制到TNAS的/tmp目录下，其操作的命令为  mv /mnt/md0/public/firmware.img /tmp/
5.再输入  up.sh，按回车
6.等待5-10分钟,直到显示[root@TNAS-00129F ~]#，表示执行完成。
7.重启TNAS。

备注：
1.如您有安装多媒体服务器的应用，释放内存之后此应用将无法使用。如您想继续使用多媒体服务器应用，请勿操作。
2.释放内存的操作过程大约需要5-10分钟，请确保不要断电或强行关机。
