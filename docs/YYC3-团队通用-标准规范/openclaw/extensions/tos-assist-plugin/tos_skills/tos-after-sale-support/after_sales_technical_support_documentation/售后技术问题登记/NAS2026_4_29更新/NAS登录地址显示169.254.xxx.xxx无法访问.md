# NAS登录地址显示 169.254.xxx.xxx, 无法访问.

**关键词：IP地址、TOS、TNAS、控制面板、HTTPS、169.254**

**解决方案：**

原因：网络环境中无DHCP服务器，TNAS无法获取到有效IP，自动分配了IP地址（169.254.x.x）。

解决方法：
- 中文教程：https://forum.terra-master.com/cn/viewtopic.php?t=1315
- 英文教程：https://forum.terra-master.com/en/viewtopic.php?t=1224

简要步骤：
1. 检查路由器是否开启DHCP服务（建议开启）
2. 或为TNAS设置静态IP：TOS Web > 控制面板 > 网络 > 网络接口 > 编辑 > 静态IP
3. 确认网线连接正常，路由器LAN口工作正常
4. 重启TNAS和路由器后重试
