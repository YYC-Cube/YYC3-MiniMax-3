# 无法使用智能电视或电视盒子查看TNAS上的媒体文件？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3596&sid=51493c53a160f99b97633ae2f702b6b5

故障排除
适用版本
TOS 5.1.X

故障现象
由于某些原因，您可能无法在智能电视或者电视盒子中搜索到 TNAS 设备或者无法正常查看 TNAS 上的媒体文件。如果这种事情发生，您可以参照以下指引进行故障排除。

原因分析
搜索不到设备的原因有多种，例如：系统服务未启动，权限或索引未配置成功，网络未正确连接，设备没有自动搜索的功能。请参照以下指引逐一排除故障：

a. 相关系统服务未启动
根据您的智能电视或者电视盒子支持的协议检查以下事项，以确保相关系统服务已经正常启动。
1、打开 Multimedia Server 应用，检查是否已经选择“已连接”的 LAN 来启用 DLNA/UPnP；前往 TOS > 控制面板 > 网络服务 > 媒体索引，检查是否已经将需要查看的的共享文件夹添加至媒体索引。在启用多媒体服务器并等待索引完成后，就可以使用 DLNA/UPnP 搜索 TNAS 设备并查看媒体文件。
2、前往 TOS 控制面板 > 文件服务 > SMB，查看 SMB 是否已启用。
如果启用 SMB 后仍无法发现 TOS 共享文件夹目录，可以在 SMB 设置界面取消启用“对没有权限的用户隐藏共享文件夹”。
如果想不需要账号密码即可查看媒体文件，你需要前往TOS 控制面板 > 用户 > 编辑 guest 用户 > 取消停用 guest 用户。
3、前往 TOS 控制面板 > 文件服务 > NFS，查看 NFS 是否已启用。
4、前往 TOS 控制面板 > 文件服务 > FTP，查看 FTP 是否已启用。
5、前往 TOS 控制面板 > 文件服务 > WebDAV，查看 WebDAV 是否已启用。

b.权限或索引未配置成功
1、使用 DLNA/UPnP 设备无法正常查看部分媒体文件时，请尝试重新添加共享文件夹至媒体索引并重建索引。
2、使用 SMB、FTP、WebDAV 无法正常查看媒体文件时，请前往 TOS 控制面板>用户>编辑用户的共享文件夹权限。
3、使用 NFS 无法正常搜索和查看媒体文件时，请前往 TOS>控制面板>共享文件夹>编辑共享文件夹权限>设置共享文件夹 NFS 权限。设置映射规则时可选择“映射所有用户为超级用户”和“映射所有用户为 guest ”。如果选择“映射所有用户为 guest ”后部分媒体文件无法正常查看，可以编辑文件的 guest 用户权限。

c.网络未正确连接
1、TNAS 或者电视盒子 IP 与其他设备冲突，尝试修改为未使用的 IP 地址。
2、检查 TNAS 和电视盒子的网络连接情况。

d.设备没有自动搜索的功能
部分电视盒子或者播放器无法自动搜索设备，需要手动添加访问地址、账号和密码。

补充说明
以上就是搜索和播放 TNAS 设备媒体文件的故障排除方法，在以上故障排除过程中，如果您需要协助，请与我们的客户人员联系。
