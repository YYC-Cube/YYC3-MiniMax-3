# 如何解决TDAS设备数据访问缓慢、硬盘无故休眠及唤醒失败等问题？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=2765

适用机型:
D2-310
D2-320
D2-330
D2-340
D4-300
D4-320
D5-300C
D5-300
D5 Hybrid
D6-320
D8 Hybrid
D9-320

故障现象：
在windows或mac电脑正常使用时，TDAS设备出现数据访问缓慢、硬盘无故休眠、硬盘无法唤醒等现象。

故障原因：
因为TDAS设备具有随系统休眠功能，受到PC系统下达的休眠指令，使TDAS设备硬盘进入休眠状态，所以可能会遇到数据访问缓慢，硬盘无法唤醒故障原因。

故障排除：

Windows

前往 控制面板>电源选项>更改计划设置>更改高级电源设置>硬盘，将"在此时间后关闭硬盘"设置分钟选择“0”

macOS

适用于：Mac mini/ iMac/Mac Studio/Mac Pro
前往 系统设置...>能源, 将"显示器关闭时，防止自动进入睡眠"设置为“打开”

适用于：MacBook Air/ MacBook Pro
前往 系统设置...>电池>选项...，将"使用电源适配器供电且显示器关闭时，防止自动进入睡眠"设置为“打开”

注意事项：
1.设置完成后请将Mac和TDAS重新启动后再继续使用。
2.TDAS 设备的睡眠模式由系统定义,在个人电脑端，你可以通过操作系统对其进行设置（设定 TDAS 睡眠计划或关闭 TDAS 睡眠功能）。
3. 请按照上述故障排查方法，解决您 TDAS 设备出现的相关问题。在排查故障过程中，若您还需要进一步的帮助，欢迎随时联系我们的技术团队。
