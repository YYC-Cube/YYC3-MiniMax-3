# TNAS 硬盘无法休眠？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=439&sid=91960374e52a8fba318a0aab4711ff91

故障排除

适用机型：所有机型

如果您的硬盘在预设时间内一直处于空闲状态，它们将进入休眠。但是某些条件（包括卷状态，服务，应用程序）将阻止您的TNAS进入休眠模式或不时将TNAS从休眠模式唤醒。

重要须知
对于新设置的文件系统，大约需要24到48小时才能为btrfs文件系统执行完日志和balance操作，而对于ext 4文件系统则需要大约12到24个小时的时间来进行延迟初始化，在此期间硬盘将无法休眠，所需的实际时间取决于硬盘容量。如果您已将大量文件复制到TNAS，则创建日志与balance将花费更长的时间。要了解有关日志和balance的更多信息，请访问https://wiki.archlinux.org/index.php/Btrfs
在硬盘休眠期间，硬盘指示灯将保持长亮；
要确认硬盘是否处于休眠状态，请用手触摸设备主体。如果您不感到任何震动，则您的硬盘可能已经处于休眠状态。

阻止硬盘休眠的原因有：

卷状态
卷处于降级或崩溃状态；
还未创建卷；

服务
DDNS域名解析；
LDAP：当您的TNAS充当LDAP客户端时；
文件服务：启用SMB / AFP / NFS后，任何SMB / CIFS广播数据包都可能会阻止系统进入休眠状态，包括在同一网络上运行的Windows资源管理器；
NTP：使用NTP服务与其他网络设备同步时；
缩略图和索引：升级后生成缩略图或重新索引多媒体文件时；
Windows Media Player：在LAN中启用Windows Media Player的网络共享服务时；
IPv6：启用IPv6后，您的TNAS可能会从休眠状态中唤醒；
VPN客户端启用；
如果许多并发进程需要内存交换（RAM使用容量已超过内存容量，并且硬盘暂时用于读/写操作缓存），则TNAS无法休眠；

应用
云同步；
DNS服务器；
下载应用：Transmission，qBittorrent，Aria 2；
Docker；
邮件服务器；
媒体服务器/ DLNA媒体服务器；
Plex媒体服务器；
Emby媒体服务器；
代理服务器；
VirtualBox虚拟机
VPN服务器；
WebDAV服务器；
第三方应用程序：运行任何第三方应用程序时；
其他
USB设备：将任何USB设备连接到TNAS时。

注意：
1、如果您不想禁用上述任何应用程序或服务，但仍希望节省能源，您可以设置定时开机/关机。
2、如果按照上述排查步骤操作后，硬盘仍然未处于休眠状态，请在 TOS 桌面 > 技术支持 > 问题反馈中填写相关信息，并生成报告。然后将报告发送至 support_cn(at)terra-master.com，我们会尽快分析原因，并通过邮件回复您。
