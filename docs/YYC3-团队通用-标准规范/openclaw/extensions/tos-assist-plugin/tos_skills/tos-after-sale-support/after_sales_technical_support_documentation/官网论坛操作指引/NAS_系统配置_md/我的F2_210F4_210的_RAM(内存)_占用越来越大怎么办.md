# 我的F2 210F4 210的 RAM(内存) 占用越来越大怎么办？

适用版本
TOS 4.x

适用机型
F2-210，F4-210

故障现象
有用户反馈 F2-210和 F4-210型号在使用两个月左右就可能出现运行阻塞的情况，且观察到名为 msgcenter 的进程占用较高。
该 msgcenter 是重要的消息提醒功能，经观察，存在缓慢增加 RAM 占用的问题。

解决方法
由于各方面原因,暂时无法通过发布新版本修复,可以设置一个定期重启 msgcenter 进程的计划任务,重置它的占用。
1.登录 SSH，切换到 root 权限
登录方法：viewtopic.php?f=87&t=1511

配置方法A
2a.输入以下指令打开计划任务配置文件
代码： 全选vi /etc/crontab/root

3a.输入“i”进入编辑模式，在最下下方新的一行中加入以下信息：
代码： 全选0 8 * * * /etc/init.d/S99msgcenter restart
（每天8点重新启动msgcenter服务）

4a.按下“Esc”退出编辑模式,再按下“:”，输入“wq”，最后按下“Enter”退出计划任务配置文件

配置方法B
2b.输入以下指令将计划任务的配置文件 root 复制到在 TOS 网页可见的目录：
cp /etc/crontab/root  /mnt/md0/public/

3b.在 TOS 文件管理的 public 文件夹下载 root 文件，使用文本工具打开，并在最下方新的一行中加入以下信息：
代码： 全选0 8 * * * /etc/init.d/S99msgcenter restart
（每天8点重新启动msgcenter服务）

4b.删除文件管理 public 目录下的 root 文件，将编辑好的 root 文件重新上传到文件管理的 public 目录下

5b.输入以下指令将旧的 root 文件替换为新的 root文件：
代码： 全选cp /mnt/md0/public/root /etc/crontab/
