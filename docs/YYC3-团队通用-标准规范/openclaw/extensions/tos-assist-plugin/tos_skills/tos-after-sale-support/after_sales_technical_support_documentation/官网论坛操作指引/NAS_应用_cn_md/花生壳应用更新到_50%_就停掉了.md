# 花生壳应用更新到 50% 就停掉了

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=543&sid=2830252e3f49fda663c79a41b721ea52

**关键词**：DDNS、内网穿透、动态域名、域名解析、花生壳、远程访问

---

故障排除

适用机型：
TNAS设备

如果您在更新花生壳应用时出现进度一直停留在50%时的情况，您可以按照以下步骤手动进行修复：
1. 使用 ssh 登录 TOS，先删除 /etc/init.d/daemon_oray，再前往 TOS应用中心上更新或者卸载应用；
2. 如果您点击了更新或者卸载，请先执行第一步的操作，再删除 /tmp/scripts_run/remove-oray，然后就可以正常更新或卸载了。
