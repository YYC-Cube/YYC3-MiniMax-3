# TNAS 识别不出 USB 盘。

可能是您的 USB 设备使用着不被支持的文件系统格式，或者存在软件 RAID 结构导致无法识别。您可以考虑备份数据, 然后重新格式化 USB 设备.

- **TOS4**: 支持识别 EXT4, NTFS, FAT32, exFAT.
  
- **TOS5**: 支持识别 EXT4, NTFS, FAT32, exFAT.
  
- **TOS6**: 支持识别 FAT, FAT32, NTFS, EXT2, EXT3, EXT4, ExFAT, Btrfs, and HFS+.
  
- **TOS7**: 支持识别 FAT, FAT32, NTFS, EXT2, EXT3, EXT4, ExFAT, Btrfs, and HFS+.
