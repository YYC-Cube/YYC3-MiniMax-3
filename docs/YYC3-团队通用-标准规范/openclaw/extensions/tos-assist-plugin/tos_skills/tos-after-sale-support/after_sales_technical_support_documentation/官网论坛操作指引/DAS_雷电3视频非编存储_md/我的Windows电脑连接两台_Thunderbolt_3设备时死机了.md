# 我的Windows电脑连接两台 Thunderbolt 3设备时死机了？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=478

故障排除

适用机型：
TerraMaster D4 Thunderbolt 3（D4-330）
TerraMaster D5 Thunderbolt 3（D5-330）
TerraMaster D8 Thunderbolt 3（D8-330）

如果您的 Windows电脑在连接两台及以上 Thunderbolt 3设备时出现死机现象，请尝试以下解决方案：

1.待Windows电脑启动完成后，再开启或连接 Thunderbolt 3设备。
2.采用菊花链拓扑方法：在将第一台 Thunderbolt 3设备的第一个雷电接口与 Windows 电脑连接后，再将第二台 Thunderbolt 3设备的第一个雷电接口与第一台 Thunderbolt 3设备的第二个接口连接。
3.采用菊花链拓扑方法后，Windows 电脑依然出现死机现象？请尝试在将第一台 Thunderbolt 3设备的第一个雷电接口与 Windows 电脑连接后，将第二台 Thunderbolt 3设备的第二个雷电接口与第一台 Thunderbolt 3设备的第二个接口连接。
