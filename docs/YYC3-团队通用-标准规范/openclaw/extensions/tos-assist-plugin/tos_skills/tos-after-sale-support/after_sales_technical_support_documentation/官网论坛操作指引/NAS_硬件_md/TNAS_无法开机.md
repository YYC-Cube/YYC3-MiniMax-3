# TNAS 无法开机？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=2805&sid=ff7bc9dc8c8215f8ab568c189aad116e

适用型号：所有TNAS 型号

故障现象：
如果您的TNAS 已经正常使用了一段时间，但是在断电、重新启动、搬家后无法再开机；按下电源开关后，电源灯与硬盘灯均保持熄灭或亮起一会儿后熄灭。

原因分析：
正常使用的TNAS 如果突然无法开机，有以下几种可能：

1，用错电源适配器；
2，启动程序出现故障；
3.  另外安装了不兼容的内存条或者内存条安装不当；
4.  主板损坏；

解决对策：
请尝试以下对策

1，请确保您使用的是铁威马原厂电源适配器；
2，假如您自行另外安装了内存条，因为系统检测新的内存需要花费较长的时间，开机后请等待2分钟；如果仍旧无法开机，请尝试将内存条取出再尝试一次；
3，请尝试将设备拆开，移除主板上的电池，过几分钟后再将电池装回，然后再尝试一次；
4.  如果以上对策均无效，估计是主板出现故障了，请联系铁威马客服提供售后维修服务；
