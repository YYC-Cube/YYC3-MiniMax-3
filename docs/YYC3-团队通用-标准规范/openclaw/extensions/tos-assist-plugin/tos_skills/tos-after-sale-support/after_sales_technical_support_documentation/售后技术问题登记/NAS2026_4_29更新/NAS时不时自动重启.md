# NAS时不时自动重启.

**关键词：TOS、TNAS、控制面板、自动重启、NAS突然重启**

**解决方案：**

自动重启可能由多种原因引起，请按以下步骤排查：

排查步骤：
1. 检查电源供电：确认电源线连接牢固，尝试更换电源线或电源适配器
2. 查看系统日志：TOS Web > 控制面板 > 日志，搜索重启时间点的错误记录
3. 检查定时任务：TOS Web > 控制面板 > 系统 > 任务计划，确认是否设置了定时重启
4. 排除过热保护：检查TNAS通风是否良好，清理灰尘，确认风扇正常运转
5. 检查内存：参考Row 44进行内存测试，排除内存故障
6. 检查硬盘健康：TOS Web > 控制面板 > 盘 > SMART检测，排除硬盘故障导致的系统崩溃

若以上步骤无法解决问题：
→ 联系人工客服，提供系统日志以便进一步分析
