# T12-500 Pro 产品介绍

## 产品概述

**T12-500 Pro**  
**一体化备份服务器**  
**铁威马BBS商用备份套装**

高性能备份服务器：T12-500 Pro NAS 搭载酷睿 i7-1255U 处理器（10核12线程，最高睿频4.7GHz），集成动态频率1.25GHz的锐炬Xe显卡，支持AES-NI硬件加密。配备16GB DDR5内存与双万兆以太网端口，性能强劲。双M.2 NVMe插槽通过超级缓存技术提升存储效率，成为中小型企业高性能备份解决方案的优选。

---

## 核心特性

### 高性能备份服务器

- **强劲处理器**：酷睿 i7-1255U 处理器（10核12线程，最高睿频4.7GHz）
- **集成显卡**：动态频率1.25GHz的锐炬Xe显卡
- **硬件加密**：支持AES-NI硬件加密
- **大容量内存**：16GB DDR5内存
- **高速网络**：双万兆以太网端口
- **SSD缓存**：双M.2 NVMe插槽通过超级缓存技术提升存储效率
- **优选方案**：中小型企业高性能备份解决方案

### 20Gb极速传输

- **双万兆端口**：配备双万兆以太网端口
- **聚合带宽**：提供高达20Gbps聚合带宽
- **SMB多通道**：借助SMB多通道技术
- **卓越性能**：
  - 2090MB/s顺序写入速度
  - 450MB/s 4K随机读写性能
- **流畅处理**：确保图像与视频处理流畅无阻
- **适用场景**：完美适配影视制作、后期处理及高要求虚拟化环境

### 灵活存储解决方案

- **多种RAID配置**：支持单盘、RAID 0/1/5/6/10
- **大容量设计**：12盘位设备
- **硬盘兼容性**：
  - 12块3.5英寸SATA机械硬盘
  - 2.5英寸SATA机械硬盘
  - 固态硬盘
- **超大存储**：最高存储容量达288TB（以24TB硬盘为例）
- **先进技术**：搭载铁威马TRAID/TRAID+技术
- **在线功能**：支持在线扩容、数据迁移与冗余磁盘配置
- **文件系统**：可选用ext4或Btrfs文件系统
- **轻松扩展**：通过铁威马USB DAS磁盘阵列轻松扩展存储空间
