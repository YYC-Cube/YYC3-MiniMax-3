# DAS创建RAID读取速度低排查方法

单块硬盘单盘模式测试读取速度是否正常，可能部分硬盘不兼容RAID或者硬盘兼容性问题

DAS创建RAID模式之后读写速度慢的排除方法；

机械硬盘本身速度不快；

电脑USB接口上5GB测试条件，JBOD/RAID1/单盘模式：200/280MB/秒之间，RAID0模式翻倍：380MB/秒。

电脑USB接口上10GB测试条件，JBOD/RAID1/单盘模式：200/280MB/秒之间，RAID0模式翻倍：560MB/秒。

DAS创建RAID模式方法；

D2-320；https://support.terra-master.com/quickguide/steps?product=D2-320&page=18

D5 Hybrid；https://support.terra-master.com/quickguide/steps?product=D5%20Hybrid&page=19

速度参数：

因为采用了USB3.2 Gen2协议，D2-320 提供10Gbps的数据传输带宽，安装2个硬盘时实际读/写速度可高达521MB/s (同时读/写Seagate Eoxs 22TB X2 RAID 0)，安装2个硬盘时读取速度可达1075MB/s（SAMSUNG 870QVO 1TB SSD X2 RAID 0）。

设备无法休眠

RAID1或者RAID5，一块硬盘坏了，另外买了一块换上，为什么不自动重建

RAID同步时需要使用同品牌同容量的硬盘进行同步，小于原RAID的使用硬盘会无法同步，例如；使用2块2TB硬盘创建RAID1模式时，需要使用2TB硬盘同步，不能使用1TB硬盘同步。

重启电脑，组的RAID为什么消失

答：一般TDAS自带的硬件RAID模式，不会出现这种问题，可能使用第三方的RAID软件会出现，这是属于第三方软件问题。

用第三方软件检测出健康状况不佳，如何知道是哪块硬盘不健康

答：TDAS设备中有槽位命名，或者根据硬盘分区命名来判断。

RAID driver安装不成功的排查方法，特别是windows没有指引如何安装RAID driver
