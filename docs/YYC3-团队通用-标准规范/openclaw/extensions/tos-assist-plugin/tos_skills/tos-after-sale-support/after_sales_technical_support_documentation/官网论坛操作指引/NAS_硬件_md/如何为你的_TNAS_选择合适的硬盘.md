# 如何为你的 TNAS 选择合适的硬盘？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=864&sid=ff7bc9dc8c8215f8ab568c189aad116e

使用指引
如何为你的 TNAS 选择合适的硬盘？

适用机型: 所有 TNAS 型号

适用 TOS 版本: 所有版本

由于 TNAS 设备通常需要7x24小时不间断工作，对硬盘的可靠性要求较高，只有满足特定规格的硬盘才适用于 TNAS，特别是当您需要组建 RAID 时。如果您在 TNAS 中使用不推荐的或不健康的硬盘，可能会导致您的设备故障、崩溃，甚至可能面临数据丢失的风险。

请务必根据兼容性列表来选择您的硬盘! 如果您需要确认您的硬盘是否健康，请参考硬盘检测指南。

如果您需要在 TNAS 中组建 RAID，建议使用同一品牌的型号、容量相近的硬盘。
