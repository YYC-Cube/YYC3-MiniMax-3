# TNAS 产品支持什么型号的无线网卡？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4598&sid=ff7bc9dc8c8215f8ab568c189aad116e

适用机型：
所有 TNAS 机型

适用版本：
TOS 4/5/6

支持型号：
TNAS 设备的标准配置仅支持有线网络连接。然而，为了满足用户在不同场景下的使用需求，用户可自行选购适配的 WI-FI 适配器来连接无线网络。其 WI-FI 适配器仅支持搭载瑞昱（Realtek）RTL8812AU 和 RTL8812BU 芯片的产品。

注意事项：
1.	兼容性：请购买兼容推荐的无线网卡型号。
2.	安装配置：按照无线网卡的说明书进行安装，并在 TOS 系统中进行相应配置，以确保无线网卡能够正常工作。
3.	性能稳定：无线连接稳定性逊色于有线连接，如在无线连接情况下遇到速度慢或掉线等问题，请切换至有线网络验证排查。
