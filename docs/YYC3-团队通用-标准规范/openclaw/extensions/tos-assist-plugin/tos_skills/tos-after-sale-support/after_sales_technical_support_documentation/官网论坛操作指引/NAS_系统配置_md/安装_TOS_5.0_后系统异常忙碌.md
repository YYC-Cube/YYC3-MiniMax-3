# 安装 TOS 5.0 后系统异常忙碌？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=2853&sid=91960374e52a8fba318a0aab4711ff91

适用型号：所有 TNAS

适用系统版本：TOS 5.0 或之后的版本

故障现象
TNAS 从TOS 4.x 更新到 TOS 5.0 后，系统异常忙碌，CPU占用率很高，硬盘一直在读写，时不时会收到 “系统运行阻塞” 的消息通知。

原因分析
1. 媒体索引在运行。TOS 5.0 新增了媒体索引功能，系统自动为您硬盘里的文件与多媒体创建数据库。如果您的文件数量较多的话，预计要花费1～2 天时间。媒体索引期间会占用大量系统资源，同时要不停读写硬盘。

2. AI 运算在运行。如果您在TOS 5.0 中安装了 Terra Photos 应用程序，并启用了人脸识别与宠物识别等智能识别功能，AI 智能运算会占用大量系统资源，CPU 占用率会很高，硬盘会一直忙碌。如果您的照片数量很多的话，花费的时间也会很长。通常识别一张照片中的人脸或者宠物需要耗时5～20秒（依照照片大小），也就是说，如果您的TNAS 中存有几万张照片的话，AI 运算将可能持续一个星期。

3. 有备份任务或者同步任务在运行。

4. 受到挖矿病毒感染。

对策
1.  创建媒体库可以方便您未来的使用，您可以耐心等待它完成，也可以关闭媒体索引。如需关闭媒体索引，请前往 “控制面板 > 媒体索引” 将该功能停用；

2.  AI 运算一旦启动，暂时无法停止，您需要耐性等待它完成；

3.  如果您确认您即没有进行媒体索引，也没有启用Terra Photos 中的人脸识别，也没有运行备份任务。请前往 “控制面板 > 系统信息 > 进程” 中查看是哪一个进程在占有您的资源。如果发现有名称很长很奇怪的进程在占有系统资源，请联系客服排除是否是您的设备被挖矿病毒感染。
