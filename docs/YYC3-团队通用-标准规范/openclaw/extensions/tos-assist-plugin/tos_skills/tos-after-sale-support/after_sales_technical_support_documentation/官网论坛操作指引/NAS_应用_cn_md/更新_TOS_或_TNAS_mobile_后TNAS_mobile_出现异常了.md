# 更新 TOS 或 TNAS mobile 后，TNAS mobile 出现异常了

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=2114&sid=b265ad2ea5bccea440907c924ea82b46

**关键词**：APP登录、tnas mobile、手机端、手机访问、移动端

---

适用机型
所有 TNAS 型号

原因分析
有时，由于 TOS 的更新中包含与 TNAS mobile 相关的内容，在更新一端后，需要更新另一端才能适配使用，通常您可以在更新说明中获悉版本适配的相关提示。

解决方法
如果在更新 TOS 后，TNAS mobile 出现异常，请更新 TNAS mobile 到最新版本；
如果在更新 TNAS mobile 后，TNAS mobile 出现异常，请更新 TOS 到最新版本。
