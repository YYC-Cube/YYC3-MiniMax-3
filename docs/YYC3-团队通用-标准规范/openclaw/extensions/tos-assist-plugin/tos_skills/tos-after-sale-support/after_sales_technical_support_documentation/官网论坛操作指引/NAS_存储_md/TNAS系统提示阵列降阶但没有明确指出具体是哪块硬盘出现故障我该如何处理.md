# TNAS系统提示阵列降阶，但没有明确指出具体是哪块硬盘出现故障，我该如何处理？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4745&sid=2853efb328304e05736fc85f61407238

适用版本:
TOS5

适用机型：
所有机型

故障现象：

存储池页面显示阵列降阶，但没有明确指出具体是哪块硬盘出现故障，存储池详细信息显示所有硬盘均正常连接。

故障原因：

由于阵列中某个硬盘故障，导致阵列无法正常工作，这可能是由于硬盘老化、物理损坏、连接问题等多种原因引起。

解决方法：

一、登录SSH

首先，您需要通过SSH登录到您的TNAS设备。登录方法请参考以下链接：https://forum.terra-master.com/en/viewtopic.php?t=2350

二、检查阵列状态

输入 cat /proc/mdstat 查询阵列中是否有硬盘异常，例如图中显示sdd4[4](F)，其中的'(F)'表示硬盘故障。如果没有'(F)'，则表示硬盘正常。

三、查看故障硬盘槽位信息：

输入cat /var/cache/diskinfo/sdd（将sdd替换为您在上一步中找到的异常硬盘盘符）来查看该硬盘在NAS中的槽位信息。例如下图中”HDD4 ”，表示该硬盘位于TNAS第4个槽位。

四、更换故障硬盘：

在关机状态下更换故障硬盘，新插入的硬盘要求为同品牌同容量的硬盘，或者使用同品牌容量大于原数据的硬盘。同时，您可以使用专业的硬盘检测工具对故障硬盘进行全面的检测，检查硬盘是否存在坏道、物理损伤或其他异常。
