# TNAS 正在不断地循环地启动重启。

请先尝试在不安装任何盘的情况下启动，看看是否能正常运行而不会自动重启。

如果能保持正常运行并成功打开初始化网页，说明这是软件或系统方面的故障。您可以考虑重置 TOS 以恢复正常运行。

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=423
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=241
  

如果也不能正常运行，说明是硬件方面的问题。

您可以考虑拆卸设备来清理灰尘。然后使用电子清洁剂处理按钮。如果您有硬件技术人员或朋友，也可以更换开/关按钮。
