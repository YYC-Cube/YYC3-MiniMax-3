# 远程连接无法挂载网络共享文件夹。

TNAS. Online 仅支持 TNAS PC、TerraSync、TOS 网页和 TNAS mobile 等 TOS 专有的连接，不支持 SMB 等文件服务。如果您想远程挂载网络共享文件夹：

1. 在 TNAS 或路由器（也许有）上设置 VPN 服务器，远处的电脑加入这个 VPN 服务器，然后像在局域网内一样映射文件共享。（如果是通过 TNAS 的 VPN 服务器，请在连接 VPN 服务器后使用虚拟 IP 连接 TNAS 的文件共享）关于在 TNAS 设置 VPN 服务的方法：
   
    - **[EN]** https://toshelp.terra-master.com/web/#/en/VPN_Server
      
    - **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=2821
      
    - **[CN]** https://toshelp.terra-master.com/web/#/cn/VPN_Server
      
    - **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=1900
    
2. 映射 FTP/SFTP/WebDAV 端口，用 RAIDrive/ZeroTier/Tailscale 等工具把远程文件夹映射到文件资源管理器，虽然不是 SAMBA 文件共享，但用起来可以像 SAMBA 共享一样。
