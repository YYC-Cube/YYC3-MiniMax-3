# 铁威马 D16 Thunderbolt 3 产品介绍

## 产品概述

D16 Thunderbolt 3 是一款桌面专业级雷电非编存储设备，专为视频制作、影视后期等专业应用场景设计，提供闪电般的传输速度和海量存储空间。

## 核心特性

### 闪电般的速度！

- 配备双雷电3(Thunderbolt 3) 40Gbps接口
- 采用硬件RAID控制器
- RAID 0阵列模式下，实现高达2817 MB/秒的传输速度
- RAID 6阵列模式下，实现高达2480MB/秒的传输速度

### 快如闪电般的视频工作流

D16 Thunderbolt 3 的速度可以大大缩短后期制作工作流中几乎所有任务所需的时间。

- 在很短时间内，从Blackmagic®电影摄像机中摄取数小时的原始素材并将其放入Adobe® Premiere® Pro
- 编辑ProRes 422 (HQ)、ProRes 4444 XQ以及未压缩高清10位和12位视频的多个数据流
- 对于包含了大量高清剪辑的大项目，缩略图和预览渲染的响应会快得多

### 紧凑型设计

- 采用紧凑设计，节约大量空间
- 更适合小型影视制作团队与桌面空余紧张的设计师使用
- 专门设计了方便搬动的提手，增加外出制作、demo演示与项目交付的便利性

### 安静至上

- 采用高品质的静音风扇
- 对设备内部结构进行了专门优化，有效增加设备内部风压，降低硬盘工作温度
- 大大降低设备部件与硬盘的共振
- 即使在满负荷的工作环境下，D16仍然能保持令人满意的低噪音

### 超大存储容量

- 16个盘位，支持3.5寸SATA硬盘及2.5寸SSD
- 总存储容量可高达288TB
- 能让专业人员轻松应对大容量存储需求的挑战

### 良好的可扩展性

- Thunderbolt 3允许您通过单根线缆以菊环链的方式将多达六台设备与计算机相连
- 最多可以将六台D16 Thunderbolt 3连接起来
- 可为计算机提供惊人的超过1PB容量

### 兼容Thunderbolt 3和Thunderbolt 2（仅限Mac）

- 在具备Thunderbolt 3和Thunderbolt 2端口的Mac电脑上，也可以体验D16 Thunderbolt 3的快速传输速率
- Apple的Thunderbolt 3 (USB-C)转Thunderbolt 2适配器（单独出售）可让D16 Thunderbolt 3与采用之前几代Thunderbolt技术的Mac实现轻松连接

### 提供最智能的工作空间

- Thunderbolt 3的视频带宽是上一代的两倍
- D16 Thunderbolt 3配备高清DP数字接口和两个Thunderbolt 3接口
- 可以将两个4K显示器或单个5K显示器通过菊链连接到D16 Thunderbolt 3
- 利用两个4K显示器，可将一个显示器专门用于显示时间表，另一个显示器专门用于预览4K画面
- 甚至可以通过Thunderbolt 3连接对兼容笔记本电脑进行供电

### 多种阵列模式

- 支持RAID 0、1、5、6、50、10和JBOD阵列模式
- 适应多种应用需求
- 为数据安全性提供了重要的保障
- 能最大效率地使用存储容量
