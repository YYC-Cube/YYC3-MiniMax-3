# TOS4 升级 TOS5 系统是否会丢失数据？

首先请确认您的 HDD 的分区结构是否是属于 TOS4 的旧分区格式，还是能适配 TOS5 及以上版本的新分区格式。通过这个来确定能升级的版本。

如果通过重新安装 TOS 从 TOS4.2.44 升级到 TOS 5.0.176，一般不影响数据。但以防万一，我们依然建议您尽量备份数据。

如果想升级到更高的 TOS5 版本，由于分区格式的限制，很可能会升级失败或因为重新格式化而丢失数据。

一般情况下，通过合适的更新包升级 TOS 并不会影响或丢失数据，但为了以防万一，如果您有条件，我们依然建议您备份数据。

**通过重新安装升级系统时:**

- 初始化引导系统页面如果是 V4.x.x 版本标识，安装 TOS 时提示“删除/格式化”一般针对的是系统分区而不影响数据分区，您可以继续下一步。在完成 TOS 安装并重启后，如果有存储初始化的“创建/格式化/删除”提示，请不要继续操作以防止丢失数据。
  
- 初始化引导系统页面如果是 V5.x.x 版本标识或没有版本标识，任何“删除/格式化”的提示都涉及数据清除，请不要继续操作以防止丢失数据。
