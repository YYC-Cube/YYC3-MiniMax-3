# TNAS 的IP 地址显示为 169.254.x.x，且无法访问？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=1315&sid=51493c53a160f99b97633ae2f702b6b5

适用机型：全系列 TNAS

现象
TNAS PC客户端能够搜索到TNAS，但显示的IP地址为169.254.x.x时，无法访问。这种情况通常发生在网络环境中没有DHCP服务器时，导致TNAS设备获得的IP地址是169.254.x.x。

解决对策

1. 启用路由器的DHCP功能，让TNAS设备获得正确的IP地址。使用TNAS PC重新搜索TNAS的IP，并点击“登录”或“修改IP”为TNAS设置正确的IP。修改IP时，请使用各个系列型号的默认密码:
x86 机型的默认密码是 admin
arm 210机型的默认密码是 Admin123
arm 212机型的默认密码是 admin

2. 绝大部分的路由器均具有DHCP 服务器功能，若您的局域网环境无法使用或启用DHCP 服务器，您需要通过电脑手动为您的TNAS 设置IP 地址。请通过网线将TNAS直接与电脑连接，并按照以下步骤操作（以Windows操作系统为例）：

(1) 右击电脑桌面右下角的网络图标，选择“打开网络和共享中心”(Open Network and Sharing Center)。

(2) 选择“更改适配器设置”(change adapter settings)。

(3) 右击网卡并选择“属性”，然后双击“Internet 协议版本 4”(Internet Protocol Version4)。

(4) 您需要确认您的电脑网口已经配置了有效的IP 地址，该IP 地址不可以为 169.254.x.x，也不可以为空！否则，请选择“使用下面的IP地址”，并为电脑网口设置一个 IP，如：192.168.1.x。

(5) 在TNAS PC 客户端中选中您的 TNAS，点击“修改IP”，将TNAS 的IP 地址修改为与电脑处于同一网段的IP 地址，例如：192.168.1.x。修改IP时需要输入管理员的初始密码，x86机型的初始密码是admin，arm210机型的初始密码是Admin123,arm212机型的初始密码是admin。

注意：使用TNAS PC 修改的IP 地址是一个临时的IP 地址，在您成功为TNAS 配置完系统后，您需要手动配置一个固定的IP 地址。

(6) TNAS IP 修改成功后，点击“登录”，页面将跳转到系统初始化页面，请根据初始化引导页面完成系统安装与配置。完成系统安装后，前往 “控制面板 > 网络 > 接口”，选择网口并点击“编辑”，将“自动获得网络设置”改为“使用下面手动设置”，将 IP 地址设置为 192.168.1.x，然后点击“应用”。网络配置完毕！
