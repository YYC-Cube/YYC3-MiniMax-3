# 铁威马 D6-320 产品介绍

## 产品概述

铁威马D6-320是一款6盘位USB外接硬盘盒，专为需要大容量存储和高速数据传输的用户设计。

## 核心特性

### 高速传输性能

- 采用USB3.2 Gen2协议，提供10Gbps数据传输带宽
- 6个硬盘同时读写时，实际读/写速度可高达1016MB/s (WD Red 8TB x 6)
- 单硬盘读取速度可达510MB/s（WD Red 1TB SSD x 1）

### 超大存储空间

- 支持安装多达6个硬盘
- 支持最大硬盘容量高达22TB（更大容量硬盘尚未验证兼容性）
- 最大可提供132TB（22TB x 6）存储空间
- 备注：D6-320不提供阵列功能，仅支持单盘工作模式。如需组建阵列，需借助第三方软阵列管理工具

### 硬盘兼容性

- 兼容3.5寸SATA硬盘
- 兼容2.5寸SATA硬盘
- 兼容2.5寸SATA SSD
- 备注：不兼容的硬盘可能导致设备连接中断、速度慢、无法识别硬盘，购买前请务必查询铁威马硬盘兼容性列表

### 接口兼容性

- 采用USB Type-C接口
- 配备USB Type-C to Type-C线一根（长度1米）
- 兼容多种电脑接口：USB 3.0/USB 3.1/USB 3.2/Thunderbolt 3/Thunderbolt 4

### 热插拔支持

- 支持热插拔功能
- 可在设备开机情况下更换硬盘
- 数据转移更加方便

### NAS存储扩展

- 可连接到铁威马NAS的USB接口
- 通过铁威马TOS可在D6-320上创建阵列与存储池以扩展NAS存储空间
- 备注：仅在运行TOS 5.1系统或以上版本的铁威马NAS才支持该功能

### 智能节能

- 支持硬盘智能休眠功能
- 可跟随电脑系统休眠
- 有效减少硬盘工作时间，降低硬盘电机消耗，延长硬盘使用寿命

### 安全保护

- 采用电源保护设计
- 当接入错误电源时，设备将启用自动保护机制
- 防止设备与硬盘因电源错误而损坏

### 散热设计

- 采用全金属机身紧凑式结构设计
- 通过结构优化减少空间占用，实现产品体积小型化
- 采用立式与卧式两用设计，适应空间有限的小型商用环境

### 自动备份功能

- 支持TPC Backupper Windows PC备份工具
- 可将Windows PC上的文件夹、磁盘分区备份到铁威马USB设备或NAS网络存储服务器
- 支持增量与差异备份策略
- 兼容Windows 8/8.1/10/11系统
