# T12-423 产品介绍

## 产品概述

**T12-423**  
**专业级存储解决方案**

12盘位 T12-423 NAS 存储适用于需要高性能存储解决方案的中小企业用户。高性能意味着用户可以轻松处理高负载任务，同时多种企业级备份解决方案可确保存储数据安全，防止潜在的数据丢失风险。

---

## 核心特性

### 专业级存储

- **12盘位设计**：专为中小企业用户设计
- **高性能存储**：轻松处理高负载任务
- **数据安全保障**：多种企业级备份解决方案
- **风险防范**：防止潜在的数据丢失风险

### 强劲硬件配置

- **高性能处理器**：N5105/5095 四核 2.0GHz CPU
- **大容量内存**：8GB DDR4 内存（可扩展至 32GB）
- **高速网络连接**：双 2.5-Gigabit 以太网端口
- **链路聚合支持**：最高支持 5 Gbps 传输速度
- **专为中小企业设计**：满足高性能存储需求

### 超大存储容量

- **最大原始容量**：240TB（20 TB 硬盘 x 12）
- **硬盘兼容性**：
  - 3.5" SATA HDD
  - 2.5" SATA HDD
  - 2.5" SATA SSD
- **RAID支持**：RAID 0/1/5/6/10
- **在线功能**：支持在线扩容和在线迁移
- **SSD缓存加速**：内置 M.2 2280 NVMe SSD 插槽
- **性能提升**：大幅提升磁盘阵列的存储效率

### 多重备份方案

- **集中备份**：CentralizedBackup
- **双重备份**：DupleBackup
- **快照保护**：Snapshot
- **云同步**：CloudSync
- **数据安全**：多种备份应用共同提升数据安全性

### 一体化解决方案

- **文件存储服务器**：轻松搭建文件存储服务
- **邮件服务器**：支持邮件服务器部署
- **网页服务器**：可搭建网页服务器
- **FTP服务器**：支持FTP服务器配置
- **数据库服务**：支持MySQL数据库
- **CRM系统**：可部署CRM系统
- **开发环境**：支持Node.js及Java虚拟机
- **商业应用**：支持众多其他商业应用
