# T9-450 产品介绍

## 产品概述

**T9-450**  
**专为高速存储打造**

9盘位 NAS 服务器 T9-450 搭载 Atom C3558R 四核处理器，主频高达 2.4GHz。它还配备 8GB DDR4 双通道内存（可扩展至 32GB）；双 SFP+ 10GB 光纤接口；以及双 2.5GbE 端口，通过 Link Aggregation 提供高达 20Gb 的传输带宽。此外，T9-450 配备双 M.2 NVMe SSD 插槽和 TerraMaster 的 Hyper Cache SSD 缓存加速技术，可提升 NAS 的整体性能。

---

## 核心特性

### 专为高速存储打造

- **强劲处理器**：Atom C3558R 四核处理器，主频高达 2.4GHz
- **大容量内存**：8GB DDR4 双通道内存（可扩展至 32GB）
- **高速网络接口**：
  - 双 SFP+ 10GB 光纤接口
  - 双 2.5GbE 端口
  - Link Aggregation 提供高达 20Gb 传输带宽
- **SSD缓存加速**：双 M.2 NVMe SSD 插槽和 Hyper Cache SSD 缓存加速技术
- **性能提升**：显著提升 NAS 整体性能

### 同时团队合作

- **万兆网络构建**：多台 Windows/Mac 工作站可同时连接到 T9-450
- **协同操作**：多轨 4K 素材在线编辑、特效制作、视频合成、镜头片段导入输出
- **效率提升**：大幅提升工作效率，缩短制作时间

### 丰富的数据存储空间

- **大容量支持**：最多支持 9 个 20TB 硬盘
- **最大容量**：最大内部原始容量可达 180TB
- **硬盘兼容性**：
  - 3.5 英寸和 2.5 英寸 SATA 硬盘
  - 2.5 英寸 SATA 固态硬盘
- **RAID支持**：支持 RAID 0/1/5/6/10
- **海量存储能力**：
  - 6000 万张高清照片
  - 3600 万份工作文档
  - 8 万部高清电影
  - 800 万个可下载音乐文件
- **集中备份管理**：将各设备数据备份到 T9-450 进行集中管理
- **数据保护**：为数据丢失提供额外保护

### 独有Hyper Cache SSD缓存加速技术

- **TerraMaster专利技术**：独有的 Hyper Cache SSD 缓存加速技术
- **多种缓存模式**：提供三种不同的缓存模式，满足不同使用需求
- **SSD磁盘阵列**：可为 SSD 创建磁盘阵列，提升缓存速度和安全性
- **性能提升**：可将存储性能提升高达 100%
- **高效可靠**：提供更高效、更可靠的混合存储

### 丰富的备份解决方案

- **多种备份应用**：
  - 集中备份
  - 双重备份
  - 快照
  - CloudSync
  - TerraSync
  - Rsync 备份等
- **数据保护**：为用户提供丰富的数据备份和保护方案
- **可视化界面**：采用可视化用户界面
- **可靠技术**：确保用户数据的安全可靠
