# 使用 Virtualhere 共享USB打印机

**链接**：https://forum.terra-master.com/cn/viewtopic.php?t=797&sid=b265ad2ea5bccea440907c924ea82b46

**关键词**：USB共享、USB服务器、USB设备共享、virtualhere、远程USB

---

操作指引

适用机型：所有 TNAS 型号

适用 TOS 版本：所有版本

共享 USB 打印机操作步骤：
1.通过 TNAS 的 USB 接口与打印机连接；
2.登录 TOS，进入应用中心，安装 Virtualhere 应用。作为服务端，该应用没有图形界面，安装完成后服务将自动启动；
3.登录电脑，请根据电脑的操作系统下载 Virtualhere 客户端：https://www.virtualhere.com/usb_client_software；
4.打开安装好的 Virtualhere 客户端后，会自动搜索本地服务器；
5.连接搜索到服务器后，会列出包含打印机在内的所有USB设备；
6.右击打印机，选择“Use this device”,此时设备显示已连接；
7.Windows 电脑进入设备管理器，选择显示出的打印机设备安装对应型号的驱动；
8.驱动安装完成后，就能在电脑设备和打印机列表中看到对应的打印机了。
