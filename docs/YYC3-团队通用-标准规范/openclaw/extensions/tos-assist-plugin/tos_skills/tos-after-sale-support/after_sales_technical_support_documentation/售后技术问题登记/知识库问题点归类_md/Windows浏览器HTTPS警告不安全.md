# Windows 浏览器 HTTPS 警告不安全。

这是正常情况，现代浏览器严格遵循 PKI（公钥基础设施）信任链机制，仅默认信任由全球权威机构签发并验证的 SSL/TLS 证书。显示不安全是因为浏览器判断访问地址没有加密，。因此浏览器会依据安全策略拦截并发出警示。而非数据传输本身存在风险。局域网使用 IP 访问显示不安全是正常现象。我们的证书是针对 TNAS. Online 的访问地址，使用 TNAS. Online 远程访问的时候就会显示正常

**解决对策：**

- **方案 A：忽略警告，继续访问**
  
    在警告页面点击 “高级” → “继续前往”或 “接受风险并继续”。
    
- **方案 B：使用 TNAS. Online 域名远程访问**
  
    在 TOS 中启用服务：控制面板 > 网络服务 > 远程访问>TNAS. Online, 启用 TNAS. Online 远程访问功能
    
    使用分配的 TNAS ID 访问：`https://您的ID.tnas.online` 或 `https://tnas.online/您的ID`。
    
- **方案 C：修改电脑 Hosts 文件**
  
    Windows 操作步骤：
    
    以管理员身份打开文件：`C:\Windows\System32\drivers\etc\hosts`
    
    在末尾添加一行（abc 可替换为任意字符）：`192.168.1.100 abc.tnas.link`
    
    保存文件，浏览器访问 `https://abc.tnas.link:5443`。
    
- **方案 D：上传自定义证书**
  
    操作：
    
    1. 购买或申请 SSL 证书（相关域名提供商会提供相关服务）
       
    2. 绑定自有域名或 DDNS 域名 (相关步骤可咨询域名提供商）.
       
    3. 并在 TOS 证书管理中上传配置。
    
- **方案 E：在路由器内配置自定义 Hosts**
  
    在支持添加自定义 Hosts 的路由器内，配置相关自定义 Hosts，即可实现局域网内所有设备访问都不显示该警告。具体支持情况及配置入口咨询路由器厂家技术支持。
