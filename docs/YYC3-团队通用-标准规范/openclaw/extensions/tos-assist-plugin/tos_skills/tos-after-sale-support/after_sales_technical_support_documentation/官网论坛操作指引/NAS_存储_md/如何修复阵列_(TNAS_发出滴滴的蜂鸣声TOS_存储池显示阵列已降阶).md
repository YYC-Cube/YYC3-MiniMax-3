# 如何修复阵列 (TNAS 发出滴滴的蜂鸣声，TOS 存储池显示阵列已降阶？)

故障现象
TNAS 发出“滴滴”的蜂鸣声，TOS 桌面消息通知中弹出阵列降阶通知，存储池界面显示“阵列已降阶”。

适用型号
铁威马所有 NAS 型号

原因与对策
TNAS 设备中有磁盘发生故障，导致阵列缺失。请按照以下对策修复阵列：
1.登录 TOS 系统，前往桌面>消息通知，查找并确定出现故障的磁盘。
2.短按电源按钮关闭 TNAS。等到电源指示灯熄灭，将故障的磁盘取出，插入一块新的磁盘，新增加的磁盘容量需大于或等于现有存储池中最小磁盘的容量。
3.短按电源按钮开启 TNAS。前往 TOS 控制面板>存储管理>存储池>编辑>阵列修复>选择硬盘>确认设置，直至阵列同步完成。阵列同步需要的时间为1T容量需花费约4小时，以此类推。

备注：
适用阵列修复类型有：TRAID、TRAID+、RAID1、RAID5、RAID6、RAID10。
