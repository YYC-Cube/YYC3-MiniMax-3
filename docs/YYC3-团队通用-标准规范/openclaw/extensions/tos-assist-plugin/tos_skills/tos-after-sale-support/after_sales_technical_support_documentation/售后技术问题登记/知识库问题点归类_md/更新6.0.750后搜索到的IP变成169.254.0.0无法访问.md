# 更新 6.0.750 后搜索到的 IP 变成 169.254.0.0，无法访问。

**原因：**

TOS6.0.750 采用了新的网络工具，如果更新 6.0.750 前启用了 SPC，那么更新后将导致 IP 变成 169.254.0.0，无法访问。

该问题已经在较新的 TOS 版本得到了修复。

**解决对策 1：**

通过 SSH/Telnet 服务或 DHMI 显示器登录终端，

1. 执行指令给权限：
   
   
    ```bash
    chsmack -E /lib/systemd/systemd-networkd
    ```
    
2. 执行指令重启网络服务：
   
   
    ```bash
    systemctl restart systemd-networkd
    ```
