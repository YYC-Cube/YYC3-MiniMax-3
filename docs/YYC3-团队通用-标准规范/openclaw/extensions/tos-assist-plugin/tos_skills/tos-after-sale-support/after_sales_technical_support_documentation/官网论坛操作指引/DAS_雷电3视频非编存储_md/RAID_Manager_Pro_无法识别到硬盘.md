# RAID Manager Pro 无法识别到硬盘

故障排除

适用机型：
TerraMaster D4 Thunderbolt 3（D4-330）
TerraMaster D5 Thunderbolt 3（D5-330）
TerraMaster D8 Thunderbolt 3（D8-330）

RAID Manager pro是TerraMaster Thunderbolt 3设备的硬件阵列控制器的配置工具。如果要创建硬件阵列，则需要在计算机上安装RAID Manager pro。

需要用户名和密码才能运行RAID Manager Pro
用户名：RAID
默认密码：hpt
登录后即可更改密码。

如果已将硬盘安装到TerraMaster Thunderbolt 3设备中，但是RAID Manager pro无法识别硬盘，请尝试以下解决方案：

1.您的计算机上尚未安装RAID控制器驱动程序，请下载并安装TerraMaster Thunderbolt 3设备；
Windows：https://download2.terra-master.com/T327 ... or_Win.zip
Mac：https://download2.terra-master.com/T3_R ... 211116.zip
2.从兼容驱动器列表中选择推荐的硬盘。https://www.terra-master.com/cn/compatibility/
