# Plex/Emby/Qbittorrent/aria2/Web Server/Jellyfin 等 app 无法访问共享文件夹或无法将其设置为目标目录。

从 TOS5 开始，一些应用需要权限对共享文件夹目录进行读写，请编辑应用用户权限以允许应用访问响应的共享文件夹。

- **TOS5**：前往 TOS 网页-控制面板-用户组，编辑名为”media“的用户组，打开”权限“，勾选对目标共享文件夹的权限，应用修改。
  
- **TOS6/7**：前往 TOS 网页-控制面板-共享文件夹，编辑目标共享文件夹，打开”应用用户（Application Users）“，编辑权限，应用修改。
