# F2-210 / F4-210 安装系统时页面出现异常

原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=3772

适用机型：F2-210 F4-210

适用版本：TOS 4.X

故障现象：空机开机时，登录页面异常，例如：页面持续空白，无响应、安装过程页面出现空白框没有提示文字.......  即使清除浏览器缓存或换浏览登录，问题依旧

故障原因：引导系统中页面文件异常或损坏

解决方法：

1、空机开机登录，通过SSH 登录您的TNAS。 https://forum.terra-master.com/cn/view ... 79&t=1511

2、执行以下指令

进入php7-all.tar文件所在目录：
代码： 全选cd /mnt/bootdev/

删除有问题的php7-all.tar文件：
代码： 全选rm -rf php7-all.tar

下载php7-all.tar文件：
代码： 全选wget http://download2.terra-master.com/php7-all.tar

重启NAS：
代码： 全选reboot
