# D1 SSD Pro 产品介绍

## 产品概述

D1 SSD Pro 是一款80Gbps超高速SSD外接盒，专为专业创作者设计，重塑8K工作流，提供极速直剪体验，告别等待。

## 核心特性

### 重塑8K工作流：极速直剪，告别等待

- 为专业创作者提供自由，实时剪辑多轨12K素材
- 工作流程流畅无阻，体验轻松无延迟

### 全铝合金双鳍片设计

- 最大化散热表面积
- 确保SSD在8K高强度剪辑中持续保持峰值性能
- 无过热降频之忧

### 80Gbps 持续带宽

- 提供自由的创作环境
- 实时剪辑多轨12K素材
- 工作流程流畅无阻，体验轻松无延迟

### 释放自由的速度

- 坚固铝制外壳内迸发 7061MB/s 的精英级速度
- 完全自由驾驭最繁重的 8K 工作流
- 无拘无束的创作体验

### 广泛兼容

- 原生支持 Thunderbolt 5/4/3 及 USB4/3.2
- 即插即用，兼容 macOS、Windows 与 Linux 系统
- 助力团队无缝协作

### 智能状态指示灯

- 即时视觉诊断
- 白色灯光代表 Thunderbolt/USB4 高速连接
- 橙色灯光代表标准 USB 连接
- 一目了然，随时掌握连接状态

### 静音散热

- 无风扇设计结合全铝机身
- 实现安静高效的散热
- 保持峰值性能，无噪音干扰

### 无限创意的力量

- 通过实时直连剪辑的自由与高达 8TB 的扩容能力
- 重新定义您的 8K 工作流
- 完全掌控最具挑战性的项目，创作无界
