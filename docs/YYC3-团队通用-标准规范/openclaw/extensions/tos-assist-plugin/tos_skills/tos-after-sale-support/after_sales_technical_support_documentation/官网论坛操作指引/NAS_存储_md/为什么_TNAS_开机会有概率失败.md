# 为什么 TNAS 开机会有概率失败？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4044&sid=2853efb328304e05736fc85f61407238

适用机型
F2-220、F2-221、F2-223、F2-420、F2-422、F2-423、F2-424
F4-220、F4-221、F4-223、F4-420、F4-421、F4-422、F4-423、F4-424、F4-424 Pro、U4-111、U4-423
F5-220、F5-221、F5-420、F5-421、F5-422
T6-423
F8-421、F8-422、U8-111、U8-420、U8-423、U8-450、U8-322-9100、U8-522-9400、U8-722-2224
T9-423、T9-450
T12-423、T12-450、U12-420、U12-423、U12-322-9100、U12-722-2224
U16-420、U16-322-9100、U16-722-2224、U16-722-2288
U24-612、U24-722-2224

适用版本
所有 TOS 版本

故障现象
启动 TNAS 服务器时，出现有概率启动不成功的现象，启动不成功时有以下三个现象：
1. 按下电源键后大约3至5秒听到嘀一声，后面再也没有听到嘀嘀声。
2. 通过 TNAS PC 客户端搜索不到 TNAS，路由器上也无法查找到 TNAS 设备的 IP。
3. 当 TNAS 连接 HDMI 显示器时，会显示“UEFI、boot”相关错误。

原因分析
TOS6之前的系统，TNAS设备内的所有硬盘都含有TOS系统。TNAS启动时，会随机择TNAS设备内的其中一块硬盘的启动，当被选中的硬盘系统有损坏或缺失时，启动失败；当被选中的硬盘系统良好时，启动正常。导致TOS系统损坏可能是文件系统错误、异常断电、异常关机等原因引起。

解决方法
1. 测试并定位启动失败的盘。
逐一安装硬盘到 TNAS 设备中，确保每次仅有一个硬盘被安装，然后启动TNAS设备。
使用 TNAS PC 或路由器搜索 TNAS 设备。如果能成功搜索到，则表明当前安装的硬盘能够正常启动 TNAS。
若无法通过 TNAS PC 或路由器搜索到 TNAS，则说明当前安装的硬盘启动失败。
对每个硬盘重复以上测试步骤，直至找出启动失败的硬盘。

2.修复启动失败的硬盘。
首先，在不安装任何硬盘的情况下启动 TNAS。
一旦启动成功，插入一个已知能够正常启动的硬盘。
使用 SSH 连接 TNAS，并以 root 用户身份登录（默认密码为 admin）。详细步骤可参考链接：https://forum.terra-master.com/cn/viewt ... =87&t=1511
SSH 登录成功后，插入启动失败的硬盘。
等待约3分钟，确保 TNAS 能够顺利识别新插入的硬盘，然后运行以下指令修复启动分区：
代码： 全选mkdir /mnt/sdbboot
mkdir /mnt/sdcboot
mount /dev/sdb1 /mnt/sdbboot
mount /dev/sdc1 /mnt/sdcboot
cp –r /mnt/sdbboot/* /mnt/sdcboot/
umount /mnt/sdbboot
umount /mnt/sdcboot

3.恢复正常使用：
将所有硬盘插回 TNAS 并重启 TNAS 以恢复正常使用。
