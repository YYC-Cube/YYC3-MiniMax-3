# TOS4重装系统后, 文件管理上找不到文件夹, 网络磁盘没有权限. 但Volume是有占用的.

**关键词：网络磁盘、TOS、共享文件夹、**

**解决方案：**

原因：TOS4重装系统后，共享文件夹权限被重置为无权限。

解决步骤：
1. 前往 TOS Web > 控制面板 > 共享文件夹
2. 找到无法访问的共享文件夹，点击「编辑」
3. 切换到「权限」选项卡
4. 为您的用户账号添加「读写」或「只读」权限
5. 保存设置后，重新访问该共享文件夹

说明：
- TOS4重装系统会重置所有共享文件夹权限为默认值（无权限）
- 需要手动为每个共享文件夹重新设置权限
- 建议记录原有权限配置，以便重装后快速恢复
