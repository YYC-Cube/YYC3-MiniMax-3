# TNAS的操作系统安装在哪里？

**关键词：TOS、TNAS、SSD、M.2、NVMe、或高性能硬盘上**

**解决方案：**

TOS（TerraMaster Operating System）安装位置：
- 安装在您指定的目标硬盘的头部系统分区中
- 类似于macOS和Windows，系统安装在硬盘的特定分区
- 至少需要1块硬盘才能安装TOS
- 安装TOS的硬盘将被写入系统分区，部分空间无法用于数据存储

说明：
- 建议将系统安装在SSD或高性能硬盘上，提升系统响应速度
- 支持将系统安装到M.2 NVMe SSD（如果机型支持）
- 系统盘可以迁移或增加（需满足类型一致等条件，详见系统迁移相关说明）
