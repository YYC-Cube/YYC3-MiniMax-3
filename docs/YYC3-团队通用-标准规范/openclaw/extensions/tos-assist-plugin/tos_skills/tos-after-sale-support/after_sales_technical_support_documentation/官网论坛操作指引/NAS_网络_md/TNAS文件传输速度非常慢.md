# TNAS文件传输速度非常慢？

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=266&sid=51493c53a160f99b97633ae2f702b6b5

故障排除

适用机型：所有TNAS 型号

如果您的TNAS与电脑之间的数据传输速率大大低于正常速率，请尝试以下故障排除：
确保TNAS与电脑之间是千兆网络连接。如果您没有千兆路由器或交换机，则可以尝试直接在TNAS和电脑之间连接网络电缆，以检查低数据传输速率是否是由路由器或网络交换机引起的；
确保您的网络电缆是CAT5/e标准，并且没有被折断或接触不良。您可以尝试使用另一根网线查看问题是否仍然存在或已解决；
如果您的电脑连接到无线网络，请尝试使用有线网络再次测试数据传输速率；
检查您的TNAS状态；如果您最近设置了TNAS并创建了新卷，则对新卷的系统检查可能会消耗系统资源。请到TOS中的控制面板以检查卷的状态；
确保TNAS中安装的硬盘运行正常。不健康的硬盘可能会导致速度慢；
确保TNAS上没有运行资源密集型任务。在资源监视器中检查CPU和驱动器利用率，或转到“控制面板”以停止除您需要运行的服务以外的所有其他服务；
检查电脑的性能；电脑的CPU和存储性能可能会影响文件传输的速度。您可以尝试使用不同的电脑传输文件；
电脑故障。如电脑受到病毒侵略或电脑网卡出现故障，均会影响数据传输的速度；
