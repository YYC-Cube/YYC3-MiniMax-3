# 210 变砖。无盘状态下启动也无法搜索到 TNAS 和打开初始化网页。

请尝试通过 SSH 登录终端。（默认账号 root，默认密码 admin）如果能登录终端，说明很可能只是页面文件损坏，请参考这个修复：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?t=5250
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?t=3772
  

如果你甚至无法登录终端，说明内核损坏，请参考这个修复：

- **[EN]** https://forum.terra-master.com/en/viewtopic.php?f=76&t=696
  
- **[CN]** https://forum.terra-master.com/cn/viewtopic.php?f=85&t=1219
  

如果修复无效，可以尝试重新烧录内核：https://support.terra-master.com/faqs/tnas_faq_TOS_update/Why_is_my_F2_210_F4_210_TNAS_device_bricked_after_TOS_update
