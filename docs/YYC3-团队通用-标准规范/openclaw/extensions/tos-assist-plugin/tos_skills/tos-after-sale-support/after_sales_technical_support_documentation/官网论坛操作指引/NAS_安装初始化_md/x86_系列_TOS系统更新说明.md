# x86 系列 TOS系统更新说明

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4655&sid=df318c2657b676e1a07d8bad1baa14ba

适用型号
x86 系列的 TNAS（请在更新前查看更新说明中的具体适用机型）。

注意事项
1. 虽然理论上更新不影响硬盘数据，但请务必提前备份重要数据。
2. 请认真仔细阅读每个版本的更新说明及注意事项，确保您的硬件和系统版本兼容。
3. 请必须按以下更新顺序更新，跨版本更新有可能会更新失败或更新后功能异常。

更新说明
TOS 系统版本更新较快，最新版本与旧版差异较大。直接从旧版更新至最新版可能导致更新失败或部分功能不兼容。为降低风险并保持系统稳定，须遵循以下顺序逐级手动更新：

更新顺序：TOS 4.2.44 → TOS 5.0.93 → TOS 5.0.176 → TOS 5.1.24 → （TOS 5.1.145---6.0.229）→ TOS 6.0.530 →TOS 6 最新版本

可以根据您的TOS 版本选择对应的逐级更新方法（更新方法中有更新包下载链接）：
1、当 TOS 版本低于 TOS 4.2.44 时，需要先将 TOS 更新至TOS 4.2.44
2、当TOS 版本是 TOS 4.2.44 时，不能通过升级的方法升级到TOS5.0 ,只能安装 TOS 5.0
3、当TOS 版本介于 TOS 5.0.93---TOS 5.0.176 之间时，需要先将 TOS 更新至 TOS 5.0.176
4、当TOS 版本是 TOS 5.0.176 时，需要将TOS 更新至 TOS 5.1.24。
5、当TOS 版本介于 TOS 5.1.24---TOS 5.1.145 之间时，需要先将 TOS 更新至 TOS 5.1.145
6、当 TOS 版本是 TOS 5.1.145---TOS 6.0.229 时，需要先将TOS 更新至TOS6.0.530

其他：
1、TOS 6.0.420 --- TOS 6.0.500 测试版需在 TOS 控制面板中检测更新，先将版本更新至 TOS 6.0.500 正式版才能进行后续更新。
2、TOS 6.0.500 及以上版本可通过 TOS 控制面板在线检测更新。若无网络，可前往铁威马官网下载中心下载最新的 TOS 更新包。
