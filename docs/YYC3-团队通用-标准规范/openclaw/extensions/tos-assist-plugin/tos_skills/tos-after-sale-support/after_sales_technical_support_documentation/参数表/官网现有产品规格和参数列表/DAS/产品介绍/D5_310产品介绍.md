# 铁威马 D5-310 产品介绍

## 产品概述

D5-310 是一款高性能5盘位硬盘盒，采用USB 3.1 Gen 1高速传输协议，为用户提供大容量存储和灵活的RAID配置选项。

## 核心特性

### 高速传输性能

- 采用USB 3.1 Gen 1高速传输协议
- 理论传输速度为5Gbps
- 实际读写速度可高达220MB/秒
- 一个1GB的文件仅需约4秒即可完成传输
- 极大地缩短办公时的等待时间，显著提升工作效率

### 多种RAID模式支持

- 支持5种RAID模式：RAID5、RAID0、RAID1、RAID10、SINGLE(独立单盘模式)
- 用户可根据具体的应用场景和需求自由选择RAID模式
- 满足不同安全等级要求

### 110TB超大存储空间

- 具有强大的存储扩展能力，可支持安装多达5个硬盘
- 单个硬盘最大容量高达22TB（注：更大容量的硬盘兼容性尚待验证）
- 最高可提供110TB（22TB x 5）的巨量存储空间
- 充分满足各种大规模的存储需求

### 兼容多种硬盘

- 支持多种类型的硬盘，包括3.5寸SATA硬盘、2.5寸SATA硬盘以及2.5寸SATA SSD
- 注意：为了确保设备的稳定运行和最佳性能，请务必注意选择与设备兼容的硬盘
- 不兼容的硬盘可能导致设备连接中断、速度降低或无法识别硬盘
- 在购买前，强烈建议查阅铁威马的硬盘兼容性列表，以确保硬盘与D5-310完美匹配

### 安装硬盘更方便

- 硬盘支架引入革命性的免工具设计，使硬盘装卸变得前所未有的简便
- 采用铁威马创新的Push-lock设计，只需轻轻一推，硬盘便能稳固锁定
- 有效防止脱落或掉线，确保数据的稳定传输
- 极大地提升硬盘更换的效率，安装一块硬盘仅需数秒

### 接口兼容性强

- 采用USB Type-C接口，并随附一根1米长的USB A to C线
- 能够与多种电脑接口无缝连接，包括USB 3.0、USB 3.1、USB 3.2、Thunderbolt 3以及Thunderbolt 4
- 为用户提供稳定高效的数据传输体验

### 支持RAID热备盘

- 当产品配置为RAID1/5/10模式时，可以为阵列添加一个热备盘
- 确保在RAID组中任何单一磁盘发生故障的情况下，热备盘能够即刻替代故障磁盘
- 有效降低数据丢失的风险，为数据安全提供坚实保障

### 风险警告提示

- 当RAID阵列出现缺失情况时，系统会触发蜂鸣器持续发出"嘀嘀"的报警声
- 表明RAID阵列当前处于不完整状态，需要及时采取措施进行修复
- 确保数据的完整性和系统的稳定性

### 广泛兼容多种操作系统

- 实现真正的即插即用，无需安装任何驱动程序
- 支持Windows 7/8/10/11、Windows Server、Mac OS、Linux Ubuntu、麒麟V10 SP1等多种操作系统
- 完全兼容USB协议，可与电脑、电视、服务器、机顶盒等各种设备连接使用
- 为用户提供极大的便利性和灵活性

### 扩展NAS的存储空间

- 经过铁威马专业团队的精心适配和优化，可顺利连接到铁威马NAS的USB接口
- 借助铁威马强大的TOS系统，用户可以在D5-310上轻松创建阵列与存储池
- 有效扩展NAS的存储空间，满足不断增长的数据需求
- 注意：此功能仅适用于运行TOS 5.1系统或以上版本的铁威马NAS设备

### 硬盘智能休眠

- 具备硬盘休眠功能
- 当设备安全脱离电脑、电脑进入休眠或关机状态、以及USB线被拔除时，硬盘会自动进入休眠状态，同时风扇停转
- 有效减少硬盘的工作时间，降低硬盘电机的损耗
- 显著延长硬盘的使用寿命，更好地保护硬盘资产

### 上电恢复功能

- 具备电源上电恢复记忆功能，能够智能应对不同断电情况
- 当设备正常关机后，若市电恢复，设备将保持关机状态
- 若设备因异常断电而关机，则在市电恢复时，设备会自动启动
- 非常适合与各种服务器、NAS等设备连接，实现无人值守的自动化管理

### 智能温控风扇

- 搭载创新的MCU_PWM智能温控风扇系统
- 能够根据硬盘的实时温度动态调节风扇转速
- 超越传统硬盘盒采用的固定风扇转速模式
- 避免硬盘温度较低时风扇仍维持不必要的高转速
- 实现更为高效且节能的散热管理

### 安全保护

- 采用先进的电源保护设计
- 一旦用户错误地接入了不匹配的电源，设备将立即启动内置的保护机制
- 有效防止电流过大或电压不稳对设备及硬盘造成损害
- 让用户在使用D5-310时更加安心，无需担心因电源问题而导致的损失

### 自动备份

- TPC Backupper是一款非常友好的Windows PC备份工具
- 通过TPC Backupper的定时备份功能，可将Windows PC上的文件夹、磁盘分区备份到铁威马USB设备或者NAS网络存储服务器上
- 只需将设备连接电脑，安装TPC Backupper客户端并设置好定时备份任务，即可开始自动备份
- 这个简单可靠的备份解决方案可让您更专注于工作，而D5-310会在背后为您保护重要数据
- TPC Backupper支持增量与差异备份策略，可运行于Windows 8/8.1/10/11
