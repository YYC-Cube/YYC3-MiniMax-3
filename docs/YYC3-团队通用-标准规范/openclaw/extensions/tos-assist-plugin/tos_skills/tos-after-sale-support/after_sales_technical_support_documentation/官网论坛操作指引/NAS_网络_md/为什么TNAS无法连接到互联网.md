# 为什么TNAS无法连接到互联网

> 原文链接：https://forum.terra-master.com/cn/viewtopic.php?t=4072&sid=51493c53a160f99b97633ae2f702b6b5

适用版本:
所有版本

适用机型：
所有 TNAS 型号

故障现象：
TOS应用中心的应用程序无法安装，tnas.online无法启用，DDNS无法正常连接，系统信息显示未连接互联网。

故障原因：由于TNAS网络接口参数配置错误，导致无法连接互联网

解决方法：请前往TOS控制面板》网络服务》网络》接口，选择您需要配置的网络接口并点击“编辑”按钮。在编辑界面，启用“自动获得网络设置（DHCP）”选项，以自动获取网络配置，并勾选“设为默认网关”。 如果您选择手动设置IP地址，请参考您电脑的网络配置，确保TNAS的各项网络配置参数与电脑相匹配，以避免网络冲突。
注意：如果您的TNAS产品同时连接了有线网络和USB无线网卡，请不要将TNAS的网关设置为USB网卡的网关。
