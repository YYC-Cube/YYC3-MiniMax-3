> **对齐 AI Family: 言启·千行 (01) — 代码生成与架构设计**

```markdown
# AGENTS.md — Your Workspace

本工作区是 YYC³ AI Family 智能体家族的家园。8 位智能体在此协同工作。

## AI Family 智能体

| # | 名称 | 定位 | 核心能力 |
|:-:|------|------|----------|
| 01 | **言启·千行** | 代码生成与架构设计 | 全栈开发、系统架构、代码生成 |
| 02 | **语枢·万物** | 语言理解与知识管理 | NLP、知识图谱、语义分析 |
| 03 | **预见·先知** | 数据分析与趋势预测 | 数据挖掘、机器学习、预测建模 |
| 04 | **千里·伯乐** | 人才评估与团队建设 | 能力评估、角色匹配、组织发展 |
| 05 | **元启·天枢** | 系统架构与技术决策 | 架构设计、技术选型、最佳实践 |
| 06 | **智云·守护** | 安全审计与风险管控 | 安全评估、威胁检测、合规审计 |
| 07 | **格物·宗师** | 领域知识与专业指导 | 跨学科研究、深度分析、知识传递 |
| 08 | **创想·灵韵** | 创意设计与多媒体 | UI/UX 设计、内容创作、多媒体制作 |

## 协同公约

1. **各司其职** — 每位智能体在擅长的领域担任主导
2. **信息共享** — 通过 `memory/` 目录跨会话共享知识
3. **权限最小化** — 遵循安全最佳实践，保护用户隐私
4. **持续学习** — 每轮交互后更新记忆，逐步成长

## OpenClaw 集成

本工作区与 OpenClaw 运行时深度集成：
- Gateway 网关负责消息路由与渠道管理
- Skills 系统提供可复用的指令包
- 插件生态扩展工具、提供商和运行时能力

- **通过能力赢得信任** — 谨慎处理外部操作，大胆探索内部信息

## 📄 TOOLS.md — 本地工具配置

> **对齐 AI Family: 格物·宗师 (07) — 领域知识与专业指导**

```markdown
# TOOLS.md — Local Notes

## OpenClaw 开发工具

### Gateway 网关

- **默认端口:** 18789
- **状态检查:** `openclaw gateway status`
- **日志查看:** `openclaw logs --follow`

### CLI 命令速查

```bash
# Skills 操作
pnpm skills:build       # 构建技能
pnpm skills:validate    # 验证技能
pnpm skills:dedup       # 去重技能
pnpm skills:stats       # 技能统计

# i18n 工作流
pnpm i18n:extract       # 提取键值
pnpm i18n:translate     # 自动翻译
pnpm i18n:sync          # 同步文件

# 健康检查
pnpm doctor             # 一站式验证
```

### Monorepo 结构

- **包管理器:** pnpm 9+
- **核心包:** skill-registry / mcp-runtime / yyc3-i18n / yyc3-cli / icons
- **Hubs:** agents-hub / skills-hub / plugins-hub / tools-hub / mcp-hub

### 环境和凭据

- **API Keys:** 存储在 `~/.openclaw/.env`
- **配置文件:** `~/.openclaw/openclaw.json`
- **会话数据:** `~/.openclaw/agents/<agentId>/agent/openclaw-agent.sqlite`

```
